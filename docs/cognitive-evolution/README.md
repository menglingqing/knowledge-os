# 认知演化记录 / Cognitive Evolution Log

此目录用于每 20 天回顾一次重要对话与项目工作，保存**认知变化**，而非聊天流水账。每份记录区分用户决策、方法假设、实测证据与待验证问题；不自动把候选原则晋升为核心规则。

## 维护约定

1. 每期覆盖一个清晰的时间窗口，优先提炼新认知、修正认知、方法、项目决策、失败与下一步问题。
2. 领域知识以现有方法论与案例目录为准，本目录提供时间线和跨领域连接，避免重复复制。
3. 对“待验证”的技巧保留证据状态，避免将助手判断、用户偏好和模型效果混为一谈。
4. 需要修改核心规则时，单独走知识评估、验证和用户确认流程。
