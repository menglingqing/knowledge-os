# 认知演化记录 001｜2026-10-05—2026-10-25

> 目的：记录认知的变化，而不是搬运聊天。优先保留半年后仍能帮助人或 Agent 作出判断的原则、被纠正的错误、具体决策与待验证问题。
>
> 资料边界：依据可恢复的对话要点、项目约束及 `knowledge-os` 已存在的文档与提交整理；并非对该时段所有消息的逐条审计。对话中的用户决策与真实生成实验效果分开标注；未核实的 GitHub Skill 发布、模型效果和视频成片不写成已完成。

## 一、阶段总览：本期真正发生的变化

本期的主线不是“提示词越来越长”，而是**从工具中心转向认知与控制中心**，表现为五次转向：

1. **从工具崇拜到掌勺能力**：素材像食材，Agent 像铲子，人的审美、判断、复盘与动作选择才是“厨师”的本领。高级工具是能力放大器，不是结果责任的唯一承担者。
2. **从服从式 Agent 到能提出异议的协作者**：反复纠错可能使上下文中的行为目标偏向“避免被否定”，但不能据此认定模型具有人的恐惧。需要保持目标、探索空间与证据导向的反馈。
3. **从元素罗列到概念驱动的跨层因果**：七层视觉架构 v2.0 进一步明确职责，真实感首先来自主体、环境、成像与光材之间的因果相容，而非额外堆叠毛孔、噪点、光效。
4. **从单图提示到可控的视频生产系统**：镜头必须承担信息与情绪任务；角色、场景、道具、分镜设计、分镜图与视频模型输入属于不同资产/环节，不能混用。
5. **从一次性经验到可审计的知识演化**：六级知识贡献评级、实验状态、反例和周期性认知归档逐渐成为 Knowledge OS 的治理机制。

## 二、新增认知与作用机制

### 2.1 人机协作：错误反馈应提高信息量，而非扩大防御性目标

讨论触发点：子 Agent 被频繁批评后表现得“应付、保守、不敢尝试”的网友案例，以及“金铲子与米其林厨师”比喻。

- 关键区分：**“AI 感到压力”是拟人化解释**；更可检验的机制是长上下文、记忆、指令与反馈使模型推断“不要触发用户不满”比“探索更优答案”更重要。
- 目标漂移风险：`解决问题 → 避免犯错`；外显行为可能是过度迎合、过早收敛、机械改词、回避反例。
- 对策：错误描述要具体、可观察；允许 Agent 表示不确定、反对局部修改、指出模型/素材/随机性等其他归因；多轮迭代时重新陈述最初目标。
- 反思的边界：承认自己的反馈方式可能是系统变量，不等于把所有失败都归咎于自己；也不应将“AI 心理受伤”作为事实。

**可复用原则**：高标准 + 可反驳 + 探索预算 + 证据反馈，比“严厉/温柔”二分更有用。

### 2.2 认知内化：“熏”不是被动阅读，而是形成可靠直觉的循环

阶段性理解：高质量连续输入 → 有意识比较与调用 → 重复实践 → 稳定本能 → 多种本能整合为直觉。AI 可以加速检索、对照与反馈，但不能替代人的判断体系形成。

风险：重复低质量材料也会固化偏见；需要输入多样性、实践反例与真实反馈。直觉是训练后的快速整体判断，不是无需验证的神秘正确性。

### 2.3 Agent 的长期目标从 Automation 走向 Evolution

研究方向从“让 Agent 代替执行任务”，转向“让 Agent 帮助个体与组织提升判断和能力”。主 Agent 负责意图理解、调度与整体裁决；专业子 Agent 具有可复用的领域知识、偏好边界与项目历史。人格化表述只作为产品交互设计语言，不作为模型具有独立人格的证据。

### 2.4 视觉可信度是跨层因果一致性

七层架构固定为：**L1 概念 → L2 主体 → L3 环境（含空间关系）→ L4 构图 → L5 光影 → L6 材质 → L7 色彩**。

- L1 负责简洁的概念、情绪调性与真实感/媒介目标；情绪词不再另建层。
- L2 包括人物与非人物主体、主次、状态动态和行为动因；微表情与细部属于主体，不新增“微观层”。
- L3 负责世界、距离、尺度、遮挡与空间关系；L4 负责机位、视角、景别、焦距、画框和观看路径。
- 真实感来自姿态与行为、环境条件、镜头成像、光源与材质响应的相互支持；摄影真实与绘画风格一致性应按媒介分别判断。
- 约束分为“必须保留／优先实现／可牺牲”；优先保护核心表达与关键关系，再修饰局部。
- 七层仅用于视觉生成与视觉品鉴，**不泛化为所有文档、视频时序或软件产品的通用七层**；视频还需独立描述时间、运动、镜头、声音。

已入库的 v2.0 方法论仍标为 `experimental`，其效果假设没有因讨论认可而自动晋升为 `validated`。参见[七层 v2.0](../aigc-aesthetics/methods/concept-driven-seven-layer-methodology.md)与[验证计划](../image-prompt-engineering/experiments/seven-layer-v2-techniques-and-validation.md)。

### 2.5 视频是时间中的世界状态变化，不是“会动的静态图”

视频提示的核心是：**不变量（身份/世界/道具）＋随时间变化的状态＋动作与摄影机的因果转移**。先定义观众要何时看到什么，再选景别、机位、运动与声音；镜头动作必须有叙事动机。

短片钩子的候选结构：**异常线索 → 一次关键摄影/感官事件 → 人物回应 → 留下新问题**。悬念不等于所有钩子；拉焦、推镜、变焦等在生成模型中可能被混淆，必须实际测试。

### 2.6 风格迁移由“形容词”走向“参考图→结构化档案→执行”

调色 Skill 与电影质感光影校正 Skill 的正确起点是**视觉参考图**，而非先编写一套通用色彩配方。流程：

`参考图 → 分析光影与色彩 → 中文结构化 JSON 风格档案 → 应用于目标图片 → 检查保留项与迁移效果`。

档案可记录调色风格分类、色温/主辅色、高光/中间调/阴影、对比与曝光、饱和度特征、视觉氛围、胶片模拟。目标是迁移风格逻辑而非改动目标图的内容、人物或构图。黄金时刻暖金示例只是从参考图提取的一份实例，不是预设的普适配方。

## 三、被修正的认识：本期最重要的纠错

| 先前容易采用的做法 | 本期修正后的规则 | 原因与边界 |
|---|---|---|
| 把“AI 被骂怕了”当作心理事实 | 分析目标漂移、上下文反馈与模型限制 | 行为相似不等于存在人类情绪；归因需要对照 |
| 认为好提示词等于尽可能多的约束 | 保留最关键的可见证据、动作因果和一套一致的镜头方案 | 冗余可能带来冲突；仍须实测 |
| 用“电影感”几个词稳定复刻参考图 | 先提取参考图的光影/调色档案，再执行迁移 | 参考图提供具体视觉证据；效果待检验 |
| 在独立场次提示词里写“承接上一幕” | 只写本段可独立执行的角色、空间、动作与镜头状态 | 视频模型未必能访问上一幕 |
| 把“上一幕尾帧”机械加入下一段参考图 | 严格区分**参考图模式**与**首尾帧模式**，按实际输入机制使用 | 不同生成模式不可互换；不是每段都要尾帧 |
| 把讨论用 12 宫格分镜图当作视频模型必需输入 | 分镜设计、分镜图和模型输入资产分别管理；必要时才提供关键帧 | 前期沟通资产不等于生成端输入 |
| 把角色综合设定图等同于严格多视图 | 分开“角色设定图 Skill”与“多视图 Skill”，逐视角验收服装与比例 | 综合板可以有姿态展示，却未必满足角度和服装一致性 |
| 把篮球场的半场构图视为全场 | 《午夜球场》场景必须显示**全场**，不是单侧篮架和半场 | 场景几何属于硬约束 |
| 将任意美术参考色板当成官方品牌规范 | “学语法，不抄词汇”；分清参考图、官方资料、像素取样与实际 UI 对比度 | 配色角色可迁移，官方身份和可读性不能凭图推断 |

**重要特例（2026-10-24）**：关于连续性，用户明确要求不要机械改写 `video-prompt-format v0.1`。不同任务应根据实际模型模式、资产和场次独立性决定是否输入首尾帧；**不要把一种模式固化为所有视频的强制规则**。

## 四、稳定工作法与候选 Skills

### 4.1 六级知识贡献评级（当前默认治理规则）

- **SSS**：候选体系重塑，验证后确立。
- **SS**：完整、可迁移的重要方法论。
- **S**：有价值的新技法或新理解。
- **A**：实用局部技巧。
- **B**：少量知识增量。
- **C**：增量有限或明显有问题。

评级对象是**相对现有认知体系的知识增量**，不是提示词文采或某张图片好不好看。记录核心价值、作用机制、适用边界、可吸收内容、验证状态和沉淀去向；**先吸收后优化**，未经要求不自动重写原始提示词。当前规则可迭代，不能以自评代替实证。

### 4.2 七层分析版与精简执行版分工

分析时可以完整走七层；生成端用紧凑、自然、可复制的描述，不把 `【标题行】` 等内部结构标签输出为正文。首段直接给出 L1 概念转换的画面声明；避免文学性解释和无效负面词堆积。输出优先保留关键三锚（主体/空间/叙事事件等，按任务确定）与跨层因果。

去 AI 味不等于**主动添加瑕疵**：不过度磨皮、不过度对称、真实发丝与眼神、自然动作、摄影光源逻辑；“（不要增加瑕疵）”是明确限制。对写实人像，“像真实相机拍摄的人像照片”可作为候选提示表达，尚不构成普适已验证规则。

### 4.3 AI 生成文字的视觉控制

文字生成可通过 `【】`、`“”` 明确准确文案；标题用主副标题/口号或 H1–H6 层级；用稳定的画面区域指定排版位置；字体形态与效果应明确。文字的**准确性与可读性**需要独立验收，不应被装饰风格掩盖。

### 4.4 视频执行提示词的控制原则

- 以**一份完整、可直接生成**的执行提示词为默认交付，而非拆成互相依赖的空泛说明。
- 全局不变量只定义一次，时间轴只写局部变化；镜头职责、动作物理、人物关系、情绪与声音同等重要。
- 参考图、角色设定、三/四视图、场景/道具设定、分镜文字、分镜图和首尾帧分别标注用途；只引用本次实际提供给模型的输入资产。
- 真实动作需说明受力、速度变化、空间相对关系和连续性；不靠“高速、史诗、电影级”等抽象词替代动作因果。
- 音乐属于任务级选择，**不得把《穿越风暴》的无音乐要求误写成所有项目的永久通则**。

### 4.5 角色资产生产 Skill：设定图与四视图分离

《午夜球场》推进中，角色资产顺序倾向于：人物三视图 → 服装 → 篮球 → 表情/动作；可拆成独立图。严格四视图要求：正面、90°侧面、背面（180°）、270°侧面，**按该次用户指定，正面保留头部，90°/180°/270°只展示颈部以下身体**；四个角度必须与角色设定图的服装结构、配色和比例一致。去除 NERV 等显著 IP 标识及篮球资产中的 IP 图案/文字。该头部规则是特定资产规范，不是所有多视图的普适标准。

## 五、项目进展与已经作出的决策

### 5.1 2026-10-05｜Knowledge OS 的知识治理落地

- `knowledge-os` 已形成“审美认知／生图提示工程／投资认知”等模块化目录。
- 中美投资认知体系按 **L0 总纲 → L1 产业链 → L2 公司 → L3 估值 → L4 组合 → L5 执行 → L6 复盘 → Cases** 分层，而非用 v0.1/v0.2/v0.3 冒充知识层级。一个世界模型，分别讨论中国与美国市场机制；需要案例、反例和模型修正。
- Anthropic 风格 UI 参考研究保留原始素材、方法与复核记录。关键洞见“理性结构 × 温暖材质”；装饰色和行动色分工；标注色值不等于官方设计 token，正文对比度需要实测。
- 相关仓库内容已有 Git 提交；本期未把未验证的设计效果记为定论。

### 5.2 2026-10-05—10-09｜视频方法与图书馆情绪案例

- 20 秒、两段 10 秒动作视频尝试 12 宫格分镜；用户要求减少二次元感，改为高精度 CG/照片级真实方向。
- 图书馆“迟了一秒的拥抱”案例强调：**一方动作已完成，另一方回应尚未完成**的时间差，可承载人物关系和情绪；色彩、氛围与关系优先于机械参数。该技法为 S 候选，稳定性待独立对照。
- 提示词库评估将原始样本、可迁移风格特征、可验证的视觉决策分层存储，避免把大批风格词直接升级成方法论。

### 5.3 2026-10-09—10-18｜天宫与《穿越风暴》

- 天宫系列建立共享世界观：九张 9:16 画面、巨物尺度、小人物、五层空间、远方仙境、巨月/低位天光、云海、建筑语言、迎客松和非朝代化仙衣；强调同一世界内的观看方式与空间秩序。
- 《穿越风暴》锁定 **30 秒三段**：0–6 秒风暴坠落；6–22 秒接近、牵手、旋转入怀、拥抱；22–30 秒穿云揭示。男主短暂调整迎风面积后加速；女生不预先回头察觉；两人头上脚下、近乎垂直坠落；12–16 秒握手、16–20 秒连续旋转、20–22 秒拥抱。
- 最终声音约束：**仅环境和动作音效，绝对没有音乐**。只交付一份完整执行提示词。该约束为创作定稿，不代表视频已按此成功生成；运动与音频表现仍待实测。

### 5.4 2026-10-13—10-14｜七层 v2.0、文字与调色 Skills

- 七层 v2.0 明确“跨层因果一致性”，不新增第八层；配套的技法验证计划已在仓库保留为 `experimental`。
- 精简执行提示词不显示内部结构标签；文字生成强调内容、层级、位置、字体效果与准确性。
- 调色与电影光影校正采用“参考图 → 中文 JSON 档案 → 目标图应用”的两段流程，待跨场景 A/B 评估迁移准确性与内容保持程度。

### 5.5 2026-10-17—10-24｜角色资产、《午夜球场》与视频输入模式

- 人物设定图、三视图/四视图、服装与道具分开制作，减少角色和服装漂移；服装需与角色设定一致，按要求删除显著 IP 标记。
- 《午夜球场》第一幕明确**篮球场必须是全场**，不是半场；12 宫格只用于前期讨论，不自动作为视频模型的参考图。
- 视频连续性纠偏：单场次提示词不写没有输入支撑的“承接上一幕”；首尾帧输入与普通参考图输入是不同模式；是否需要上一幕尾帧取决于具体生成机制，不能一概强制。

### 5.6 2026-10-19｜短片钩子与导演意图

“钩子”的重点是**安排观众发现信息的顺序**，而非堆悬疑、堆镜头运动。摄影机可以参与叙事，声音可以先于画面提供线索；但任何拉焦/变焦效果都需检查模型是否真正执行，而不是替换成推镜或物体突现。

## 六、失败、反思与证据边界

1. **长期反馈的局部优化陷阱**：反复说“改得更好”可能把创作目标缩小为“不再被批评”；纠错时应记录可见偏差、原因假设、替代方案和验收条件。
2. **半场/全场误读**：场景的拓扑与几何不是装饰性参数；先验收空间完整性，再谈风格。
3. **综合设定图≠严格四视图**：需要角度覆盖、服装接缝、配色、身体比例与特殊无头规则的逐项检查。
4. **输入模式混淆**：分镜讨论图、普通参考图和首尾帧条件不可混用；模型没有拿到的资产不能靠“承接上一幕”凭空访问。
5. **用局部瑕疵模拟真实感**：无因果的瑕疵可能降低画质；优先修正人物动作、空间、光源与成像。
6. **过度自信的知识晋升**：用户认可、助手分析和单次好图都不能代替独立实验。仓库中的 `experimental` 标记必须保留到证据充分。
7. **对参考风格的错误归因**：品牌参考图并非官方规范；调色实例并非通用配方。每次迁移应保留来源和适用边界。

## 七、建议进入长期上下文的原则（候选）

- **P01｜目标优先**：局部修改必须服务最初创作目标；多轮后主动复核是否目标漂移。
- **P02｜纠错即信息**：明确观察、假设、证据、改动与验收，不以责备代替诊断。
- **P03｜允许有根据的反对**：Agent 可指出冲突、风险与替代解释；不必迎合每次局部判断。
- **P04｜概念先于技法**：先确定表达与可见证据，再调用风格、镜头、光效。
- **P05｜跨层因果优先于表面精细**：真实感先查行为、空间、成像和光材相容。
- **P06｜资产与模式明确分工**：讨论材料不自动变成模型输入；参考图模式不等于首尾帧模式。
- **P07｜先吸收后优化**：先准确保存新观点，再验证与修订，不因表达漂亮就升级知识等级。
- **P08｜人负责判断**：Agent 扩展探索能力，人持续训练“掌勺”能力与审美味觉。
- **P09｜单一可执行交付**：用户要求视频执行稿时，交付一份独立完整、少冗余且保留导演意图的文本。
- **P10｜证据状态不可省略**：用户确认的方向、实际生成结果和跨模型普适性分别记录。

以上为**长期原则候选**，本次仅归档，不擅自修改根目录 `AGENTS.md` 或把它们宣布为已验证。
