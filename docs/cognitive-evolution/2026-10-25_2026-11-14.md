# 认知演化记录 002｜2026-10-25—2026-11-14

> **本期主线**：从“写出更强的提示词”，走向“按创作阶段分工、用失败案例校正判断、通过可验证的 Skill 与插件形成导演式工作流”。
>
> **资料边界**：根据本期可恢复的对话记录、用户明确纠错与案例材料提炼。并非逐条审计所有对话；“已讨论/已确认”“助手曾报告提交”“实际仓库状态”“生成结果”“跨场景验证”不混为一谈。与第一期重叠的七层架构、Agent 目标漂移等仅记录新变化。

## 一、阶段性结论

本期出现了四次关键收敛：

1. **生成流程分阶段**：概念探索 → 成图品鉴与筛选 → 需要时七段式精修。完整提示词不是所有任务的默认起点；好图应优先保护。
2. **摄影与设计分工**：双联海报的摄影母图与巨字排版是两个不同的控制问题。摄影 Skill 负责真实摄影，双联海报 Skill 负责文字、遮挡和版式，先验收母图再设计。
3. **视频格式以最新 Skill 为准**：用户于 11 月 8 日明确将 `aigc-framework/skills/video-prompt-format/SKILL.md` v0.3 作为唯一有效输出规范，固定【基础设定】【氛围与画质】【画面内容】三段，旧版逐镜头重复标签模板废弃。
4. **知识吸收与产品能力闭环**：幻墨造像不应仅调用静态提示词模板，而应能检索认知框架、案例与反例，选择合适 Skill，进行作品品鉴与验证；知识价值评估采用轻量识别与确认后深评的混合触发。

## 二、新增认知

### 2.1 “生活细节”比风格词更接近真实感的源头

11 月初的陶艺工作室“小猫在湿陶泥留下爪印”、雨夜站台“旧票归掌”等案例，获得用户明确的真实感认可。共同机制不是单纯加颗粒或毛孔，而是**有动因的小事件、人物自然反应、物体接触关系与合理的成像条件**共同成立。

候选工作公式：生活观察提供细节 → 想象建立联系 → 审美决定取舍 → AI 负责表达。该公式适合作为创意指导，不应被当成保证真实感的实证定律。

### 2.2 约束越强不等于创作越好

11 月 3 日古风书阁人像提示词被认为控制力较强，但成图不够好看。**控制能力与审美结果是两个不同指标**。不能用“执行了更多细节”代替“画面真的有情绪、关系和美感”。执行版应保留氛围与色调，不可因精简而消除情绪张力。

### 2.3 超现实可信度来自统一的异常物理规则

《夜色托梦》V2 的光影、色彩和人物质感得到正面评价，但失重规则不统一、丝绸高光过于完美、构图重复。候选认知：**超现实可以违反日常物理，但画面内部必须自洽**。先设定异常规则，再检查人物、衣物、道具、环境是否共同服从；需要跨场景验证。

### 2.4 巨物尺度是证据链，不是单个形容词

Midjourney 神龙案例提示：压倒性尺度需由人物/建筑参照、空间层次、遮挡、光照范围、身体形态连续性共同证明。仅说“巨大、史诗级”不够。该认知可用于天宫、龙、建筑等题材，但具体比例与镜头仍需按场景验证。

### 2.5 海报的“漂亮”与“成功”必须拆开评价

双联海报即使视觉有冲击，也可能违反同一性、运动物理或用户题材。必须独立评价：结构合规、上下同一性、摄影真实感、器材/动作物理、视觉冲击、字体与遮挡融合、任务执行准确性。陶艺/小猫方向误生成滑雪画面，是**审美可能成功但任务执行失败**的反例。

## 三、被修正的旧做法

| 原做法/误区 | 本期修正 | 证据性质 |
|---|---|---|
| 每次都输出长篇完整执行词 | 默认概念探索，筛选后按需精修；明确要求完整时严格执行 Skill | 用户确认的流程 |
| “控制力强”即“画面好” | 分别验收约束遵循、真实感、情绪与审美 | 成图反馈 |
| 把角色设定图当人物三视图 | 严格输出放大的特写 + 正视、侧视、背视；特写占比显著提高 | 用户明确纠错 |
| 把双联海报当一次性综合生成任务 | 摄影生成 → 真实感验收 → 母图确认 → 字体设计 → 海报验收 | 用户确认的职责拆分 |
| 运动海报用近景与雪花制造速度 | 必须看得清运动器材、腾空/坡度/轨迹与地形尺度；单板双板不可混淆 | 失败案例归纳 |
| 用巨字透明叠穿主体制造破框 | 字体位于主体后方，前景肢体、器材、雪雾等依物理遮挡字形 | 用户确认的设计规范 |
| 使用旧视频提示词模板 | v0.3 三段式为唯一有效格式，旧版废弃 | 用户明确版本裁决 |
| 发现新知识即自动改写核心规则 | 轻量识别 → 候选评估 → 实验 → 用户确认后晋升 | 知识治理决策 |

**版本边界**：10 月末至 11 月初出现过七段式执行规范的多个版本记录；11 月 6 日用户固定了七段式精简执行结构。实际调用时以仓库现行 Skill 和用户最新明确约束为准，不能从历史摘要自行推断旧版本仍有效。七层视觉架构保持 v2.0，不新增第八层。

## 四、稳定方法论与执行规范

### 4.1 七段式精简生图执行规范

执行稿依次组织：①题材/画幅/一句话概念；②主体与空间；③前景→近景→中景→中远景→远景五层渐变；④镜头构图；⑤核心三锚；⑥光影；⑦色彩；另附 Negative。常规目标约 450–600 中文字，删除解释性散文，不输出“【标题行】”等内部标签。首段直接进入概念声明。

与七层视觉架构关系：七层是**分析与决策体系**，七段式是**生成端表达格式**；不可把两者当作互相替代。用户要求完整创作时，诗词/古文属于既有完整创作格式的必要内容，体裁按表达自适应，不能在精简时无故丢弃。

### 4.2 视频提示词 v0.3（2026-11-08）

唯一有效章节：
- 【基础设定】：画幅、主体、场景、时长、镜头数量。
- 【氛围与画质】：摄影风格、颗粒、色彩、对比、运动模糊、稳定性、镜头呼吸、焦点控制等。
- 【画面内容】：逐镜头时间、机位、景别、动作、物理细节、剪辑节奏；必要时才加入台词/音效。

禁止恢复旧版“每镜头重复运镜/台词/音效/质量/负向”等冗余模板。Seedance 对照实验中用户反馈新版控制力较强、输出较好；这是**单次实践反馈**，不是跨模型已验证结论。

### 4.3 双联海报

整体 **3:4 竖幅**，上下两张**等幅、各近 3:2 横幅**。上联：无字真实摄影；下联：同一主体、动作、场景、机位、光影的字体艺术重构。仅下联有巨型英文；字在主体之后，前景元素真实遮挡。视觉设计不能替代摄影本体的结构验收。

### 4.4 人物三视图

输出组成：**显著放大的角色特写 + 正面 + 侧面 + 背面**。特写是身份/面容核验区，不能缩成与其余视角等大的小头像；后三视图用于身体、服装与结构一致性验收。不要以普通角色设定板代替。

### 4.5 知识价值评估

维持 SSS / SS / S / A / B / C 六级知识增量评价。轻量识别不打断日常创作；发现可能改变核心方法论的重要知识时，提示用户并在确认后深度评估、验证、归档。**知识评级不等于事实验证**；未经确认不得悄悄替换核心 Skill。

## 五、项目与案例节点

### 5.1 真实摄影主线

陶艺工作室猫爪印、雨夜站台旧票归掌：正面案例，关键在生活事件与反应链。古风书阁：控制强但美感不足的对照。机车写真重新确立“人物为主体，机车为性格道具”，避免器械喧宾夺主。

### 5.2 双人关系电影海报

9 图试验呈现关系氛围，但部分画面像 MV 封面而非电影海报；第四张出现女士手臂穿帮。应在情绪张力之外检查人体结构与海报叙事性。用户要求后续逐张输出，而非九宫格；本期未据此宣称新一轮成图全部成功。

### 5.3 天宫与神龙巨物

天宫维持九张 9:16 的统一世界观、低位云海/天光、巨物尺度证据、五层空间和人物比例变化；不应把所有画面变成相同构图。神龙 MJ 案例中，连续蛇形身体与尺度锚点是可迁移候选技法，参数与模型效果仍待 A/B。

### 5.4 幻墨造像插件

用户希望插件与七层架构、知识库、案例库、失败案例和知识评估机制连接，升级为更有判断力的视觉导演协作者。候选 L0 导演决策是**工作流编排层**，不是给七层视觉架构增加第八层。讨论中的 v0.5 目标不能写成已完成的插件升级。

### 5.5 自媒体与知识输出

品牌统一署名 **MLQ.子卿**，不在末尾加中文句号；重点渠道 X 与微信公众号。公众号优先深度思考、案例和反思，X 简短表达创作意图。创作经验沉淀应从“提示词搬运”转向“学习→吸收→实践→验证→认知升级”。

## 六、失败与反思（保留反例）

1. **任务偏航**：陶艺/小猫被执行成滑雪，证明好看的画面也可能完全没完成任务。
2. **人体穿帮**：双人关系海报第四张手臂结构异常，审美评分不得覆盖结构硬错误。
3. **双联海报硬约束**：上下画幅不一致、主体/器材结构错误、透明穿字、运动器材不完整，均需独立判失败。
4. **角色特写过小**：模型倾向“漂亮的设定板”，而非满足身份核验目的的多视图。
5. **旧模板复活**：视频提示词格式被错误调用，表明版本治理与调用路由比“多写一份规范”更重要。
6. **审美空洞**：有控制无情绪；精简时丢失氛围、光影与色彩导致画面缺乏张力。
7. **知识过度晋升**：一次高分图片或一次实验不足以确立普适 Skill，必须保留适用范围和验证状态。

## 七、长期上下文候选原则

- **P11｜先判断阶段，再调用 Skill**：探索、执行、品鉴、排版、归档各有不同输入与交付。
- **P12｜成功母图保护**：局部设计改动不得无故重做已验收的主体、姿态和场景。
- **P13｜结构硬错误优先**：画面漂亮不能抵消人体、器材、同一性与任务目标的失败。
- **P14｜真实感依赖事件因果**：自然动作、反应、接触、空间与光学共同构成可信画面。
- **P15｜规范只保留最新有效版本**：显式废弃的旧模板不得因历史记忆重新出现。
- **P16｜Agent 可以诊断而不只是执行**：检索反例、识别冲突、给出证据和不同意见。
- **P17｜创作经验先验证再晋升**：区分个人偏好、案例观察、候选机制、可复现结论。

以上仅为候选归档，不自动修改根目录长期指令。

## 八、下一阶段值得继续追的问题

1. 概念探索→筛选→七段式精修，与“一开始就长提示词”相比，是否提升审美命中率并减少返工？
2. 摄影母图锁定后再做字体排版，是否显著改善双联海报的上下同一性、穿插遮挡和结构合规？
3. 人物三视图怎样以比例、面部清晰度、服装一致性量化验收，防止退化成角色设定板？
4. 视频 v0.3 在 Seedance 之外是否仍能稳定执行时间、镜头、动作与物理约束？如何做 A/B？
5. “生活事件/自然反应”与“泛化电影感词”对人像真实感的贡献如何分离验证？
6. 幻墨造像怎样实现真实的知识检索、Skill 路由、案例召回和用户确认式知识升级，而不只是把更多说明塞进系统提示？
7. 对超现实异常物理、巨物尺度、运动器材物理分别建立什么样的失败分类和测试集？
8. 公众号长文怎样将视觉案例、失败复盘和认知增量连成可供读者迁移的方法，而不是只展示作品？
