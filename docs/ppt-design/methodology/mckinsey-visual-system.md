# 麦肯锡视觉系统 · McKinsey Visual System

从一套麦肯锡风格生成提示词中提炼的商业视觉设计方法论，适用于 PPT 封面、咨询分析页、方法论图、信息图等场景。

## 概述

顶级咨询风视觉的本质不是"深蓝色 + 白底"，而是一套**信息架构先行的设计系统**：先判断页面用途（封面还是信息图），再决定信息密度、标题处理方式和图形角色。文字不是装饰对象，而是画面结构本身。

## 第一性原理：用途分流

封面与信息图是两种完全不同的物种，必须分流处理：

| | 封面逻辑 | 信息图逻辑 |
|---|---|---|
| 目标 | 一眼记住主题 | 一眼看懂结构 |
| 信息密度 | 低，留白充足 | 中高，但层级清晰 |
| 模块数 | ≤4 个元素 | 3–6 个模块 |
| 图形角色 | 服务标题，单一隐喻 | 即分析结构本身 |
| 常见错误 | 做成流程图/内容页 | 图标堆砌、模块拼贴 |

**核心洞察**：封面最常犯的错误是"内容页化"——把方法论、流程、数据都塞进去。封面只需要一个巨型核心词 + 一个商业隐喻 + 克制的标题系统。

## 三层标题系统

长标题必须自动拆成三层，而不是整句放大：

- **A 层 · 主视觉核心词**：2–8 个汉字（或 1–4 个英文词），画面最大元素，必须具备视觉隐喻改造空间
- **B 层 · 完整标题**：完整主题小字号保留在顶部/边缘信息栏，信息完整但不抢视觉
- **C 层 · 极简标签**：2–4 个英文分类标签（STRATEGY / MARKET INSIGHT / 2026…），作为版式系统的一部分

## 标题信息重构

主视觉文字必须"被设计"，让观众感觉**标题本身就是分析结构**。三个层次：

1. **结构重构**：拉伸、压缩、切割、镂空、错位、分层、模块化、路径化、阶梯化、矩阵化、空间化
2. **语义重构**：文字结构匹配主题含义——增长→上升/飞轮，转化→收敛/漏斗，战略→路径/分叉，风险→阈值/断层，机会→窗口/突破点，组织→层级/网络
3. **图文融合**：隐喻嵌入文字内部（图形穿过字形、漏斗藏在负空间、网格成为字的骨架），严禁"标题旁边放图标"式的图文割裂

## 15 个商业隐喻库

按表达意图选择唯一主隐喻，禁止多隐喻堆叠：

| 隐喻 | 表达 | 隐喻 | 表达 |
|---|---|---|---|
| 漏斗 | 筛选、转化、收敛 | 门槛 | 准入、风控、决策标准 |
| 路径 | 战略推进、方法论 | 窗口 | 市场机会、趋势入口 |
| 阶梯 | 升级、价值提升 | 防线 | 风险治理、安全边界 |
| 矩阵 | 定位、比较、优先级 | 断层 | 结构变化、代际转折 |
| 坐标 | 市场地图、风险收益 | 容器 | 价值承载、资源池 |
| 飞轮 | 增长循环、复利机制 | 罗盘 | 方向选择、长期定位 |
| 节点网络 | 系统协同、组织架构 | 数据流 | 信息流动、自动化 |
| 建筑结构 | 能力底座、治理框架 | | |

## 视觉基因

**配色**：白 / 深蓝 / 黑 / 冷灰为主；强调色（克制蓝、极少量橙/绿/红）只用于关键节点、风险点、价值点、决策点。禁止霓虹蓝紫、花哨渐变、高饱和广告色。

**字体**：现代无衬线（Helvetica 气质的西文 + 黑体中文）；封面主字可大但粗细克制，可用线条字、半镂空字、结构字。

**质感**：细线、极简网格、小型编号系统、页眉页脚、咨询报告式坐标标注——"报告感"来自这些版式细节，而非装饰图形。

## 信息密度红线

- 封面禁止：5 个以上模块、3 个以上图表、大段解释、完整流程拆解
- 信息图禁止：8 个以上模块、无层级文字、长段落、数据与图形无逻辑关系
- 通用禁止：商务小人、握手图标、卡通人物、机器人头像、科幻蓝紫背景

## 阅读路径（信息图）

必须存在唯一清晰的主叙事路径：从左到右 / 从上到下 / 从问题到方案 / 从输入到输出 / 从现状到机会 / 从机制到结果。

## 验收标准

> 即使去掉大部分装饰，核心结构仍然成立。

这九条标准中最可操作的一条：装饰可以去掉，结构不能塌。
