# 案例：DataAgent 公司母版 PPT（2025.12.31）

对企业级 PPT 母版的逆向设计分析。源文件 178MB、98 个版式，属"重版式系统"路线的企业母版，是研究**设计系统而非孤立页面**的样本。

> 原件未入库（超 GitHub 单文件 100MB 限制），详细数据笔记见 [ppt-design 仓库](https://github.com/menglingqing/ppt-design) 的 `references/notes/datagent-master-2025.md`。

## 设计系统拆解

**配色：明暗双轨**

- 主色深蓝 `#004080`，辅助蓝 `#00549F` / `#0066B3`，亮蓝 `#3399FF` 点缀
- 语义色克制：绿 `#2E7D32` 仅用于正向数据，红 `#CC0000` 仅用于风险
- **封面深蓝天白字，内容页白底深蓝天**——章节切换形成明暗节奏，翻页有"换气感"

**字体：中英分工**

- 标题：Arial Black / Saturday Sans + 阿里巴巴普惠体 3.0 SemiBold
- 正文：Arial + 阿里巴巴普惠体 3.0 Light
- 英文品牌词可超大号图形化（"DATAAGENT" 110pt），中文主张句次之

**版式：98 版的系统思维**

- 编号族版式（1_–52_）：每个编号含封面/标题正文/空白三件套，对应章节或品牌变体
- 目录页：左侧巨型"目录" + 4 列网格章节卡片
- 图片矩阵：Single 到 8-up，覆盖案例墙场景
- 双栏均分、Use Case 等业务场景版式

## 核心视觉锤：超大编号

目录/章节页的编号做到 150pt（标准 16:9 等效约 50pt），**编号本身就是装饰**——不需要额外图形，数字的字形就是视觉锚点。与麦肯锡方法论中"文字即结构"互相印证。

## 页脚三件套

「密级・公司名・网址」24pt 小字浅灰固定出现。规范感来自这种重复出现的版式纪律，而非单页创意。

## 学到的五条决策

1. 超大编号做视觉锚点，替代装饰图形
2. 明暗双轨交替，章节页与内容页形成节奏
3. 固定页脚系统建立专业感
4. 语义色只在数据场景出现，永不用于装饰
5. 英文品牌词图形化，与中文信息分层

## 与麦肯锡视觉系统的关系

本案例的配色基因（深蓝系 + 白底 + 克制语义色）与 [麦肯锡视觉系统](../methodology/mckinsey-visual-system.md) 高度兼容，可作为该方法论的落地参照：它证明了"超大编号""明暗双轨"在实际企业级产品中立得住。
