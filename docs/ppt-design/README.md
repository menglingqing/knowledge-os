# PPT 视觉设计 · PPT Design

面向商业演示场景的幻灯片视觉设计方法论与案例库，产出形态为 HTML/CSS 网页幻灯片。

核心命题：**高级 PPT 不是模板套用，而是"文字即结构、图形即分析"的视觉系统设计。**
