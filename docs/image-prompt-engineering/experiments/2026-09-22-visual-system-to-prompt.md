# 从视觉系统到生成提示词：2026-09-22 实验总结

这一天的讨论进一步确认：

> **提示词不是元素清单，而是视觉导演手记。**

它需要把“概念”和“关系”翻译成模型可执行的视觉约束。

## 一、视觉生成的顺序

推荐从上游到下游：

> 概念命题 → 视觉动词 → 身份锚点 → 空间关系 → 构图骨架 → 光影／材质／色彩 → 细节 → 负约束

不要一开始就堆：
- 镜头词；
- 风格词；
- 材质词；
- 画质词。

如果上游关系未确定，下游词越多，越容易互相打架。

## 二、七层架构的适用边界

七层架构：
- L1 概念层；
- L2 主体层；
- L3 环境层；
- L4 构图层；
- L5 光影层；
- L6 材质层；
- L7 色彩层。

它只用于**视觉生成执行**。

不用于：
- 普通文档；
- 知识可视化；
- 商业分析；
- 所有审美理论分类。

微表情、肤质、动作细部等应并入主体层，不另设“微观约束层”。

## 三、Concept 驱动，而不是 Style 驱动

例如 Dreamcore 夜景如果只写：
- night；
- bokeh；
- dark；
- high exposure；

很容易变成“夜景 Cos”。

应先写概念：
> 一个极小的发光生命信号，被巨大黑暗空间吞没。

再翻译成：
- 主体位于画面下方；
- 蜷缩／抱膝；
- 上方大面积黑场；
- 细节被曝光抹去；
- 只保留角色色；
- 地面少量反射；
- 远处密集虚焦光点。

这就是：
> **概念 → 可见证据**

## 四、IP 提示词优先写锚点

对已有角色，优先描述：
- 3–5 个身份锚点；
- 人格；
- 当前视觉动词。

不要试图重写整个角色设定。

更稳定的模板：

> 【角色身份锚点】  
> 【本张视觉动词】  
> 【空间／构图关系】  
> 【材质转译】  
> 【色彩编码】  
> 【版式／媒介】  
> 【需要避免的身份漂移】

## 五、跨风格提示词必须写“功能关系”

不推荐：
> 90s magazine + biomorphism + exoskeleton + swiss + psychedelic + ink

推荐：
> 外部世界保持 90s 高端生活方式杂志的秩序与版式；人物身体局部逐渐转化为半透明有机软体；金属矫形支架重新锁住软组织；Swiss 网格维持版面纪律；迷幻符号仅出现在异常区域，作为精神干扰层。

区别是：
- 前者是名词并列；
- 后者是系统分工。

## 六、系列提示词要区分固定 DNA 与开放变量

固定 DNA：
- 画幅；
- 信息层级；
- 色盘；
- 字体气质；
- 媒介；
- 主体识别策略。

开放变量：
- SUBJECT；
- ACTION；
- DETAIL；
- WORD；
- 单张视觉动词。

这可以显著提高系列一致性，同时避免“同一模板只换角色”。

## 七、从品鉴反推提示词的工作流

1. 找单一大势；
2. 找 Character DNA；
3. 确定 Macro / Meso / Micro；
4. 确定第一视觉锚点；
5. 确定主体与环境的空间关系；
6. 给每个风格／材质分配职能；
7. 转写为可见、可控制的描述；
8. 最后再补画质和媒介词。

## 八、执行检查

生成前问：
- 一句话能否说清画面为什么成立？
- 主视觉锚点是否唯一？
- 角色是否只保留真正必要的身份特征？
- 风格词是否都承担了具体职责？
- 构图是“关系描述”还是元素坐标堆砌？
- 系列中哪些变量固定、哪些变量开放？

生成后问：
- 第一眼是否仍是原设定的视觉锚点？
- 画面是否被次要细节劫持？
- 风格混搭是否变成拼贴感？
- 角色是否滑向无身份的漂亮图？
- 空间关系是否符合概念？

## 九、关于对抗式审核

不设为固定步骤。

只有出现以下情况时才开启：
- 关键假设未验证；
- 提示词内部冲突；
- 构图／身份／风格目标互相抢权；
- 模型已连续产生同一种失败；
- 存在足以改变设计结论的反例。

审核的目标是找到真正的控制瓶颈，不是为了制造“反对意见”。
