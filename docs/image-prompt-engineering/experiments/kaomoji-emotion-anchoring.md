# 颜文字情绪锚定法（Kaomoji Emotion Anchoring）

> 来源：[生图大师Agent](https://chatgpt.com/c/6ac77798-c77c-83e9-be55-d782d8ea5ea6)，2026-11-01 整理。
> 知识贡献评级：**A级·待验证**。评级表示值得沉淀的知识增量，不代表效果已获独立验证。
> 本条依据可读取的会话文字整理；未重新检视参考图片和生成结果，原作者来源、模型版本、参数与成图尚未归档。evidence 留空，不将会话反馈冒充可检查的实验案例。

## 定义与核心机制

在人物生图提示词中，将颜文字作为辅助情绪语义锚点，与人物风格及少量可观察动作描述结合，引导眼神、嘴角、头部姿态和手势围绕同一情绪协调生成。

机制假设：**情绪意图 → 表情联动 → 自然微动作 → 人物气质 → 观众感受**。颜文字可能提供紧凑的整体情绪线索，让模型补全微动作；这属于生成控制假设，不是已证实的模型内部机制。

实用组合：**真实感与人物风格锁定 + 颜文字情绪锚点 + 少量可观察动作约束**。创作者明确情绪目标与关键身体关系，允许模型探索微动作，再通过成图筛选判断。

## 三个例子

以下为可复用的提示片段，尚不是独立对照实验结果。颜文字没有固定、通用的动作含义，解释以当前作品情境为准。

- **`(//∇//)`：羞涩、心动。** 示例：“真人写实成年女性肖像，流露出(//∇//)般羞涩心动的情绪；轻轻低头却抬眼看向镜头，嘴角浅笑，一只手轻掩嘴角，皮肤与手势保持自然。”原会话提示词另含少许狡黠。
- **`(´∀｀*)`：愉悦、满足。** 示例：“真人写实成年女性肖像，流露出(´∀｀*)般愉悦满足的情绪；眼睑放松，温柔微笑，肩颈自然舒展，保留真实抓拍感。”原会话还强调微微慵懒。
- **`(„ಡωಡ„)`：古灵精怪。** 示例：“真人写实成年女性肖像，流露出(„ಡωಡ„)般古灵精怪的情绪；轻微侧视，嘴角带克制的狡黠笑意，指尖轻触脸颊，避免夸张表情包式五官。”

## 适用边界

适合真人肖像、美妆摄影、时尚人像、动漫角色及需要强化情绪的单人特写；这些是候选应用范围，尚不能声称全部验证有效。

不替代复杂肢体姿态、多人互动和精准表情的自然语言设计。真人摄影优先明确真实人物、镜头、肤质与摄影媒介，检查是否出现卡通化、夸张腮红、假笑或表情符号被画入画面等副作用。符号、情绪词与动作描述应相互一致；冲突时先澄清情绪目标。

## 实验反馈与限制

原会话助手记载，原作者展示过三种颜文字对应的真人肖像，并认为表情、手势与摄影氛围协调；本次未重新检查这些图片，因此仅保留为会话转述，不当作独立观察结论。

本轮对话输出三组完整真人摄影提示词，用户直接反馈：“确实会有一些帮助”。这支持继续研究和归档，但不足以证明因果效果。

三组提示词同时包含颜文字、情绪词与具体动作，无法分离颜文字的独立贡献；也未提供可复核的模型设置、完整输出记录和盲评。提示词宣称固定人物与风格，不等于成图已实现身份一致。三种情绪变体也不自动计为三个独立验证案例。

## 验证计划（待实施）

1. 固定人物身份参考、服装、场景、镜头、光影、画幅、模型及版本，保存完整提示词和可用参数；支持种子时采用配对种子。
2. 针对每种情绪设置三组：A 仅自然语言情绪与动作；B 仅颜文字情绪提示；C 颜文字与 A 的同一段简短描述结合。其余条件不变。A/C 对比用于判断加入颜文字的增益，B 用于探索独立表达能力。
3. 每组重复生成，保存全部成功与失败图，避免只挑最佳结果。随机呈现输出，在不知道组别时评价情绪可读性、表情自然度、动作协调性、身份一致性与审美完成度。
4. 记录收益、无改善、身份漂移、卡通化与无法判断情形。预先明确目标情绪，避免看图后更改解释。
5. 跨人物、跨情绪、跨写实／动漫风格复验，保留输入和输出链接，再重新评级。依[知识治理](../governance.md)，至少三个独立案例是晋升必要条件而非充分条件，最终由人类审阅裁决。

## 沉淀决策

**收录为 L2 主体层“人物表情与微动作”的可选候选技法；暂不升级七层视觉架构 v2.0，也不升级七段式生图 Skill。**

现有 L1 概念、L2 主体、L4 构图及执行版“主体与空间／核心三锚”已能容纳该方法，不新增层级、不设为每条提示词必填项。动作驱动情绪与情绪驱动动作可以互补，但其跨层协同仍需验证。
