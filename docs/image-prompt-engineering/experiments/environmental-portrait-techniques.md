# 环境人像视觉生成技法：从东方玄幻构图到可复用控制

> 来源：[分支 · 品鉴东方幻想构图](https://chatgpt.com/c/6ab73d9b-0830-83ee-98b0-d21cd81a9e99)中围绕最初环境人像达成的实践归纳；2026-09-26 整理。
> 本次依据会话结论整理，未重新检视原图；原图、生成参数与 A/B 输出尚未归档。以下为可执行的单案例经验，跨题材效果待验证，故保留 experimental。

**总纲：用空间建立关系，用视线推进叙事，用颜色赋予意义，用克制留下余韵。**

本页属于视觉生成实践技法库，服务于现有[七层架构](../methodology/seven-layer-architecture.md)，不新增层级。上游表达选择参见[如何转化为创作控制](../../aigc-aesthetics/methods/creative-control.md)。复用对象是人物与世界的关系，不是“巨月、白衣、古树”的元素组合。

## 十条技法：操作与验收

| 技法 | 如何执行 | 看图验收与边界 | 对应七层 |
|---|---|---|---|
| 1. 巨物定尺度 | 巨型背景体 + 可辨人物 + 极小远景参照；巨物承担尺度，人物承担情绪。可替换为神像、山体、穹顶或机械结构。 | 巨物是否建立大小关系而未抢走人物焦点？缺少尺度参照时，单写“巨大”不足。 | L2 主体、L3 空间 |
| 2. 位置即情绪 | 先选有关系意义的位置，再定姿态：高处边缘、门洞前、水岸或人群之外。 | 不依赖面部表情，能否看出人物与他物的距离、阻隔或归属？高处不必然等于孤独。 | L1 概念、L3 空间 |
| 3. 视线即叙事 | 明确人物看向哪个可辨对象，并使头部朝向与目标位置相符。 | 观众能否找到她在看什么？远景人像优先保证头身方向可读，不强求眼珠细节。 | L2 主体、L4 构图 |
| 4. 建立视线链 | 设计“主体 → 叙事物 → 环境 → 回到主体”：如人物、远灯、山谷、人物；用朝向、留白、明暗承接。 | 叙事物是否改变了对人物处境的理解？这是预期观看路径，需复看验证，不保证所有人按同一路径观看。 | L4 构图、L5 光影 |
| 5. 人物静、环境动 | 身体保持低动作幅度，把动态转移给风／衣／雾／水／光／影；每次选一两种次级现象，统一物理方向。 | 静态画面能否从衣褶、雾带或水纹读出时间？风是否把姿态、服装或焦点夸张到失控？ | L2 主体、L5 光影、L6 材质 |
| 6. 轻人重物 | 用薄纱、软衣等轻质感，对照黑岩、古构件或钢铁等沉重承托物；先定软硬、轻重主次。 | 人物的轻盈与底座重量是否同时成立，接触是否可信？白黑只是辅助，不等于材质重量。 | L6 材质 |
| 7. 遮挡制造真实空间 | 让前景树干、枝叶或构件切入巨物轮廓，形成前中后层，破除平面背景感。 | 是否读得出遮挡顺序，人物轮廓是否仍清楚？完整巨物也可用于图形化表达，遮挡不是强制规则。 | L3 空间 |
| 8. 暗框锁主体，负空间留给远方 | 暗前景围合人物，人物朝向一侧保留空旷，亮背景衬出轮廓；框景与留白分别负责聚焦和距离。 | 小人物是否仍容易找到？留白是否连接叙事目标？避免暗框过厚、四周封死或遮住目标。 | L3 空间、L4 构图、L5 光影 |
| 9. 颜色绑定语义 | 先定义颜色归属，再控制面积与亮度：本例冷色属于人物所在世界，少量暖灯指向远处人间。 | 暖色是否仍能指向特定事物，还是散落为装饰？颜色含义由当前情境建立，不预设红、金、青的通用含义。 | L1 概念、L7 色彩 |
| 10. 大世界、小情绪、七分表达 | 环境承担宏大，人物动作克制；用空间、物件、光线、视线和动作残留替人物表达，留给观众解释余地。 | 能否读出关系却仍有未说尽之处？“七分”是情绪留白的比喻，不是比例；克制不等于毫无叙事线索。 | L1 概念、L2 主体、L4 构图 |

这些技法按当前命题选用，不永久分 SSS／SS／S，也不要求一次全部叠加。动作戏、仪式海报等目标可以采用更强动作、居中或完整巨物。

## 从品鉴结论到 A/B 变量

以下均为**待实施的对照方案**，没有预设优胜结果。每组保留同一人物、场景、机位、画幅、模型版本及其余提示词；固定种子仅在工具支持时使用。先检查目标变量是否真正改变，再判断效果。

| 变量 | A | B | 重点观察 |
|---|---|---|---|
| 视线目标 | 人物看月亮 | 人物看远处灯火 | 在月亮与灯火都保留的条件下，关注点是否从奇观转向人与人间的关系？ |
| 巨物遮挡 | 完整巨月 | 前景切入巨月约 20% | 纵深是否增强，人物是否仍突出，月亮是否仍可辨？20% 是视觉估计的测试起点，不是精确配额。 |
| 动态来源 | 人物主动挥袖 | 人物静止，衣袖受风 | 生命感能否保留，表演感是否降低？尽量匹配袖幅与方向；姿态和布料是联动变量，不能把差异单独归因于某个词。 |
| 暖灯密度 | 密集暖灯 | 3–5 个暖点 | 人间信号是否更集中，远方是否仍可读？尽量固定灯区、色温与单灯亮度，记录总亮度随数量产生的变化。 |

**执行顺序：**

1. 写一句创作命题，选最影响它的一条技法，制作 A/B 提示词差异。
2. 保留完整输入与成图；条件允许时跨多个种子重复配对，避免只挑一张好图。
3. 对照检查：主体可辨、尺度与纵深、叙事目标可读、情绪集中；分别标记“改善／无改善／无法判断”并写可见依据。
4. 记录收益与副作用。模型未执行变量、或同时改变了其他关键条件时，标“无法判断”，先修正控制。
5. 将有效关系迁移到另一个题材继续验证；同一案例的多次生成不自动算多个独立案例。晋升遵循[知识治理](../governance.md)。

**最小记录模板：**

| 字段 | 填写内容 |
|---|---|
| 命题与技法 | 本轮要表达的关系、测试哪一条 |
| 输入条件 | 模型／版本、完整提示词、参考图、画幅、可用参数与种子 |
| A/B 差异 | 唯一计划改动、实际伴随变化、无法控制的条件 |
| 输出证据 | A/B 图片路径或稳定链接；随机重复的全部结果 |
| 判断与边界 | 可见收益、副作用、无改善或反例、下一轮只改什么 |

## 跨题材调用

保留关系职能，替换具体物件；以下是迁移设计，尚未生成验证。

- **科幻机库**：巨月换为船体，黑构件换为钢梁，远灯换为舷窗；静止工程师面对远处生活区，蒸汽承担动态。
- **山间旅人**：巨物换为山壁，白纱换为柔软雨披，暖灯换为村舍；岩脊定位置，风雨定时间，山谷留出距离。

调用骨架：**[人物]处于[有情绪意义的位置]，看向[叙事物]；[巨物与远景参照]建立尺度，[前景遮挡与暗框]组织纵深，[朝向一侧留白]延伸距离；人物保持[低动作状态]，[次级物理现象]承担动态；[轻／重材质]形成对照，[颜色]分别归属[概念]，让可见关系承担情绪。**

每次只展开当前命题需要的部分，再按七层检查一致性；提示词优先描述可见关系，不堆叠“孤独、史诗、高级”等评价词。
