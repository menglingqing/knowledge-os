## 本轮用户确认的创作原则

**先让概念成为画面，再判断画面是否需要优化；不是先用完整七段式把所有细节限制死。**

- 从视觉概念、主体关系和表达目的出发；七层架构仍作内部认知与品鉴工具，不新增第八层。
- 一般「给一版生图提示词」：默认**只给可复制的简练概念探索版**。常用结构是「精炼但有完整因果的场景叙事＋自适应诗词歌赋」，按需补充画幅、时代、媒介。古文体裁与句数不限；不预先写满焦距、五层景深、服装、光影和 Negative。
- 先生成与筛选，识别不可牺牲的构图、角色气质、光材和事件；**探索版足够好可直接定稿**。
- 用户明确要求「完整的生图提示词／七段式执行版」，或任务本身需要精确角色、复现、局部修图时，调用七段式执行。已有成图时尽量参考图/局部编辑，优先保护成功关系。
- 文字长度不是目标：对高精度设计可以长；对完整表达核心概念的探索提示词可以短。按「必须锁定／按需控制／刻意开放」区分变量，审查重复的姿势、表情和审美标签。

## 近期实践与正反证据

| 案例 | 用户观察与已知事实 | 可提炼方法／证据限制 |
| --- | --- | --- |
| 《青笼听雨》 | 两次重复尝试中，纯古文版较完整七段式更符合审美；旧胶片与数码成像呈现不同气质 | 诗文能高度凝练事件，长词可能过度固定；不是独立验证古文语法必然更优 |
| 《萤火未归》 | 诗文和七段式版本都好，用户更偏爱诗文 | 允许模型自由探索画面，完整执行依然可成功 |
| 《隔窗补月》 | 纯古文 A／只加现代世界 B 均较差，含简洁摄影成像的 C 最好；后来七段式首段＋诗文短版和完整版均好 | 现代媒介/世界边界有价值；不能将 C 优势归因于任一孤立词 |
| 《绯色旧梦》 | 多轮更详尽的优化未能复现原作的戏剧张力 | 必须先保护参考图的有效复杂性和人物气质，不能以精致替代魅力 |
| 《银色神谕》 | 一张 MJ 参考成图有不规则金属、陶瓷面甲和扶颊神态；后续详细七段式生成多张更趋向精致统一的机械瓷偶 | 原 MJ 提示词本身也长；跨模型/profile/词汇差异混杂，不能证明短词因果；避免把单张「偶然成功」全部固化为硬姿势 |
| 《佛眼·归枷》 | 用户明确反馈，简练探索版在满意结果**数量与每张细节**上均优于此前完整提示词 | 精炼场景＋诗文可清楚连接佛眼、红线、女子挣扎与冷天光；尚缺控制变量与全量样本统计 |

参考图片品鉴、用户的生成反馈、可复现的受控 A/B 是**不同证据等级**。没有重新读取每个实验的全部原图、种子、配置或样本统计，本记录只保留用户在对话中明确反馈的比较，不虚构数量、成功率或客观评分。

## 已获正面反馈的提示词：《佛眼·归枷》概念探索 V1

```text
3:4竖幅，东方玄学意境摄影写真。一位年轻成年中国女性身着灰白古衣，独立于幽暗的千年石窟之中。身后巨大的残破佛眼隐于阴影，静静俯视众生。万缕暗红因果丝线自四方延伸，缠绕她的双腕与肩身。她微微垂首，一手轻握腕间红线，神情清醒而悲悯，似已看透命数，却不肯向命运低头。冷白天光穿过石窟裂隙，照亮她的半张脸，余身沉入幽暗。画面庄严、孤寂、压抑而克制。

欲避天机入劫门，
佛眸无语照凡尘。
千丝缚尽前生债，
万般枷锁归吾身。
```

此提示词已经包含「创作目的／主体／世界／因果道具／动作与精神转折／必要光影」，但不硬编码镜头视场、人物占比、手的每个关节、佛眼具体模糊程度，适合先寻找艺术解法。

## Skill 分工与版本边界

- **七层 v2.0**：内部创作理解、跨层因果检查、品鉴和定位问题；**保持原版本与七层次序**。
- **概念探索 v0.2**：默认简练、单条可复制提示词；用户要求完整、分析、多版本除外。
- **七段式 v1.3**：显式完整执行、角色控制与参考图编辑；去掉常规字数目标，审查重复约束。用户要求固定七段式格式时保留中文标签与可选 Negative。
- **MJ Visual Director v0.2 / Digital Beauty Creator v0.1**：专项参数与身份工具，按需注入而不抢占普通生图入口。

该分工是**已确认的用户工作约定**；哪种格式在不同模型上取得更好图像，仍是需逐题验证的假设。

## 下阶段最小验证计划

1. **同模型同设置、同概念**：简练诗性叙事、简练白话叙事、七段式完整控制；记录模型版本、配置、样本、用户评价，比较最优图、样本分布和失败类型。
2. **单变量审核**：保持主旨与成像设定不变，分别去除反复出现的扶颊／低头／细节描述，观察构图与表情多样性是否恢复。
3. **精修优先原图**：从成功探索图出发，只修改可见缺陷；比较修改前后概念表现、身份、视觉冲击力和真实感，必要时保留原图、不再修改。

**当前决策**：先执行新的 Skill 路由与版本；知识增量为 S/SS 研究候选，**不因一次认可直接晋升为已验证的普适机制**。
