# 肖像提示词技法 · Portrait Techniques（实验记录）

> 来源：2026-08-18 花钿古典肖像提示词的多轮迭代与双助手交叉评审。
> 本文件全部为 experimental——单案例观察与未经对照实验的假设，不构成规律。

## 1. 观察记录（单次成图直接可见）

原始提示词经某模型一次生成后的直接观察（不推测模型内部原因）：

- 情绪、人物位置、主色关系、明显动作得到较强响应
- 画幅未按正文执行（正文 2:3 → 出图 16:9；原因为生成参数/平台默认/后期裁切之一，未定）
- 花钿花型响应（五瓣红花），但"贴肤手绘哑光"质感未稳定实现（更接近带高光的装饰物）
- 未呈现伦勃朗三角光；单眼对焦不可确认
- 整体更像数字电影帧，而非 Portra 400 静态胶片肖像
- 发丝与披帛动态被显著强化（是否由"风"词导致，未做对照，不定论）

**初步倾向（待验证）**：语义明显的大结构指令响应强；精密参数与小物件材质响应不稳定。

## 2. 假设（待对照实验）

| # | 假设 | 状态 |
|---|------|------|
| H1 | 镜头参数语言（50mm、f/1.8）能否产生稳定、可辨、可复现、且**超出等价自然语言**的额外引导 | 未验证 |
| H2 | 多重动态描述（发丝+披帛+风）会被模型放大为主要叙事 | 未验证，单案例迹象 |
| H3 | 小物件描述**可见光学结果**（无投影/无反射/可见笔触）优于集中式负向排雷 | 未验证 |
| H4 | 局部结果约束（否定紧贴对象）优于集中式负向清单（独立负向框） | 未验证 |

**实验设计**：同一提示词的 A/B 变体（±镜头参数；集中排雷 vs 局部约束），在 2-3 个模型上各出 ≥2 张，只看 raster 直接可验的项目。

**证据独立性规则（治理层已收）**：多个同源 AI 助手的共识计为 1 个证据；同一原稿的衍生版本不构成独立收敛证据（2026-08-18 已两次自我违例后确立）。

## 3. 四层提示词结构（当前最佳形态，待验证）

1. **身份锚点**——定义"还是不是这张图"：人物、发型、服饰、标志性物件（如花钿）。不可随迭代删除
2. **审美骨架**——空间与情绪关系：人物偏侧、暗部留白、视线方向、静/动基调
3. **可见结果**——技术要求的可验收写法：近侧眼最清晰、暗侧三角光斑、花钿无投影无镜面反射
4. **后果上限**——规定不许破坏什么，而非规定数量："面部轮廓和双眼保持可辨"优于"三四缕发丝"

**元规则（预算审计）**：任何一层随迭代膨胀到威胁身份层注意力时，先压缩再追加（64卦 v5 爪部 36% 教训）。

收束公式：**身份靠定义保存，审美靠关系建立，技术靠可见结果验收，失控靠后果上限约束。**

## 4. 领域已知事实速记（公共知识，非本案例发现）

- 伦勃朗布光的签名是**暗侧脸颊的三角形光斑**；"左亮右暗"描述的是 split lighting
- "焦点锁左眼"存在人物左眼 vs 画面左侧之眼的歧义；无歧义写法："靠近镜头的眼睛"
- Kodak Portra 400 的性格是温润肤色与柔和高光；与"冷白皮+高反差"混用是有意调色，非胶片天然结果

## 5. 审美偏好候选（每条带适用边界，防硬化为教条）

- **藏 > 露**——仅限含蓄古典肖像主题；画面该藏该露服务于主题，非普遍真理
- **单一视觉钩子**——大面积暗底中只让一个元素浓（本案例：朱红花钿是唯一暖色钩子）

## 6. 派生规则

- **描述精度不得超过景别分辨率**：胸部以上景别中，眉心花钿占像素极少，要求"可见细笔触"超出该景别可交付的信息量——与"64卦不可数"同族（数量精度陷阱 vs 尺度精度陷阱）
- **画幅由参数控制**：正文画幅声明仅作意图备份，不作验收依据（候选级，2 案例：本案例 + 64卦"画幅先定"）

## 7. 明确不升级为规律（当前证据不足）

- 色彩配额（65/20/10/5）的有效性
- 50mm / f/1.8 的有效或无效
- 15° 角度的无效性（正确表述：未验证）
- 正向物理描述一定优于负向排雷
- Portra 400 与冷白皮必然冲突
- 多助手共识 = 结论接近验证完成
