# 幻墨造像：视觉导演方法提纯 v1.1

本文件收录多类视觉案例复盘中重复出现的高密度方法。当前缺少可公开追溯的独立生成证据链，因此先进入实验层；后续由公开案例验证后再拆分晋升至 methodology。

## 1. 导演表与单图执行卡分离

世界规则、系列变化矩阵和备选构图属于导演表；单图执行时必须消解分支，只保留一种主构图、一种动作、一种自然关系和一个人物规模。

系列一致性不靠每张复制同一模板，而靠共同的色彩、材质、建筑或角色 DNA。

## 2. 镜头几何必须闭合

焦段、机位、拍摄距离、景别、裁切、焦平面与细节可读性必须属于同一观看机制。

常见冲突：

- 手机自拍、镜前自拍与外部摄影机混写；
- 长焦浅景深却要求完整环境和远近细节全部清晰；
- 大特写要求完整道具、远景建筑和多层空间同时可读。

## 3. 主次必须落实为画面变量

“主体重要”不能只靠文字声明，必须落实到面积、明度、对比、饱和、锐度和遮挡关系。

辅助元素退出竞争的方式：

- 减少数量或面积；
- 降低对比、饱和与锐度；
- 让细节随距离衰减；
- 保留一个主光源与一个主要亮度中心。

## 4. 叙事用可见证据成立

文学背景若没有画内证据，不构成视觉叙事。人物可以缺席，但事件必须留下可见后果。

可用证据包括：接触与受力、轮挡、雪壕、湿衣重量、将灭油灯、磨损、遗留物、并置关系、定向碎屑和被排开的云层。

## 5. 单一媒介语体

真人摄影、半写实 CG、水墨、版画、厚涂和硬线漫画应先确定主语体。设备名、引擎名、奖项词、分辨率和“高级感”标签不能替代可见结构。

## 6. 稳定审美基线

- 视觉冲击来自单一主轴、尺度证据与材质对抗，不来自特效平均用力。
- 色彩由环境基底、主体提亮、结构锚点和极少高价值点色组成。
- 人物、服装、道具与环境应存在接触、受力、视线或事件关系。
- 胶片、噪点、失焦、重影和过曝必须有对象、有边界、有叙事价值。
- 光源必须明确来源、方向、软硬与真实后果。

## 7. 生产级提示结构

仅在明确创作任务中启用：

1. 画幅与唯一观看机制；
2. 主体、单一事件与唯一视觉锚点；
3. 构图、尺度链、镜头几何与裁切；
4. 主光来源、环境补光与真实后果；
5. 色彩角色与材质差异；
6. 接触、受力、痕迹或遗留物等可见证据；
7. 只保护高概率失败点的必要负向。

## 当前淘汰项

- 单图保留多套构图、人物规模或动作选项；
- 全域锐利、浅景深与大量远近细节同时成立；
- 多个自发光物、月亮、窗光和粒子平均争夺主光；
- 8K、16K、masterpiece、museum-quality、UE5、Octane 等空洞结果词；
- 用身体等级、瓷器肌肤或模板脸代替人物身份与力量。

## 晋升条件

至少三个可公开追溯、任务条件相互独立的案例验证同一规律；记录输入、生成结果、偏差与单变量修正，再由人类建筑师批准晋升。
