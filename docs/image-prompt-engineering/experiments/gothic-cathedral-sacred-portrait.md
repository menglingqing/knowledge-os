# 哥特教堂神圣感人像：七层执行版

依据[创作复盘](../../aigc-aesthetics/cases/2026-09-25-gothic-cathedral-sacred-portrait.md)整理。以下是下一轮执行建议，尚未生成验证；不是原对话逐轮提示词的还原。

## 使用边界

七层只用于视觉生成执行，不用来强行分类所有审美认知。沿用[既有七层定义](../methodology/seven-layer-architecture.md)：L3 为“空间层”，包含环境及其纵深关系；人物微表情、细部动作归 L2。先决定命题，再用七层检查遗漏，最终提示词按画面优先级组织。

## 七层架构版

| 层级 | 本例执行定义 |
| --- | --- |
| L1 概念 | 仪式已经结束，而她没有离开。安静的停留处于宏大、仍有秩序的神圣空间之中。 |
| L2 主体 | 一位成年、浅色短发、黑色眼罩与黑衣的非人角色，低位坐在石地面上，重心可信，肩颈略松，一只手刚放松；不主动向镜头表演。人物是事件焦点，建筑是秩序载体。 |
| L3 空间 | 完整的哥特教堂，立柱与尖拱向高处连续延伸，高窗、人物与远处祭坛分处不同纵深；湿石地面连接前景与后方。选一个小叙事痕迹，不叠加战损与废墟元素。 |
| L4 构图 | 环境人像，人物略偏左并保留上方空间；身体斜线与建筑竖线形成张力，高窗落光引导视线回到人物。抑制前景肢体透视对建筑的遮蔽。 |
| L5 光影 | 高窗冷白天光为主，斜向体积光显露空间；低位暖烛光仅局部勾边和反射。人物服从环境照明，远处暗而有纵深，光束不覆盖成全场白雾。 |
| L6 材质 | 空间与承重可信优先，其次是石材、黑色织物和皮肤的受光差异，最后才是蕾丝细节。浅色织物低对比，湿地面反射有粗糙度与断续变化。 |
| L7 色彩 | 冷灰和黑色为大色域，冷白集中在高窗与受光处，暖金局限于烛光附近；少量暗红可按叙事需要保留。靠明度和冷暖位置分层。 |

## 简洁执行提示词范式

结构：**一句命题 → 人物状态与空间关系 → 构图尺度 → 主辅光职责 → 材质和色彩优先级 → 一个叙事线索。**

> 仪式已经结束，而她没有离开。一位成年浅发蒙眼的非人角色安静坐在完整而高耸的哥特教堂内，身体自然承重，一只手刚刚松开，像独处时被看见。环境人像构图，人物略偏左，上方保留拱顶与高窗的空间，身体斜线与建筑竖线形成张力。高窗冷白光斜落，薄雾显露纵深，低位暖烛光仅勾出局部轮廓并映在湿石地面。冷灰与黑色主导，浅色蕾丝细腻但低对比，地面反射不均匀。远处仅留一缕熄烛烟作为仪式结束的线索，整体安静、庄严。

这是范式示例，熄烛烟是新提出的创作选择，不是原图既有事实。更换角色时只替换身份锚点；先保住光、尺度和动作关系，再按结果调整。

## 迭代顺序与检查

1. 保留已有效的教堂秩序、高窗冷光和冷暖职责，建立基线。
2. 第一轮只减弱蕾丝／前景的视觉显著性；第二轮可单独试镜头距离；人物动作另作一轮。
3. 每次保存实际提示词、结果和反馈。只问神圣感是否保住、人物行为是否可信、第一视觉焦点是否偏移。

具体原因仍需图像对照；不预先宣布提示词有效，也不以助手之间的重复评价代替验证。按用户要求避免机械式对抗审核，发现实际冲突时直接指出并修正。
