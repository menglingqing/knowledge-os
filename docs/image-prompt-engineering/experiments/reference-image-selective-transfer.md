# 参考图选择性迁移：从视觉诊断到可控编辑

**先确定想借什么，再说明哪些内容必须保留；用最短指令试验，以三图对照检查收获与代价。**

## 来源与证据边界

来源：[参考图迁移方法](https://chatgpt.com/c/6ab60636-6c08-83e8-a2cc-02d8985201a0)中的实践分享及后续讨论（原会话访问可能需要权限）。

原文报告了早期 8 张调色试验，以及同一底图、17 个维度各保留一张结果的正式对照；提到景深迁移伴随背景改变、低机位伴随下装补绘、运动拖影波及静态背景等现象。本条依据会话中的文字记录整理，未取得完整原图、结果图、模型版本及参数，也未独立复跑，不据此推断成功率或跨模型普适性。

“Transfer + Lock”、五个控制域、重建成本与组合策略是对经验的操作性归纳，不是模型内部机制的证明。依照[知识治理](../governance.md)，当前保留为实验性方法；17 项同底图测试不能自动算作 17 个独立验证案例。

## 1. 四个核心原则

| 原则 | 操作方式 | 注意点 |
|---|---|---|
| 选择性迁移 | 把“参考这种风格”拆成光影、色彩、景深等可观察特征 | 参考图是特征来源，不必整体模仿 |
| Transfer + Lock | 同时写明迁移项与保留项 | “锁定”是自然语言约束，不保证像素或身份绝对不变 |
| 作用范围 | 指定作用于人物、背景、某种材质或整幅画面 | “迁移什么”与“作用在哪里”是两个问题 |
| 最小充分提示词 | 短指令 → 检查偏差 → 只补必要约束 | 不预先堆参数；有歧义时仍需明确描述 |

基础句式：**将图一的【目标特征】迁移到图二；保持图二的【必要保留项】。**

短句的实用价值是减少重复描述和无关细节，便于归因；不能据此断言短提示词总优于长提示词，或模型确实“冻结”了某类视觉信息。

## 2. 从 17 个维度归纳为五个控制域

以下是便于检索与选变量的分组，覆盖原文全部 17 项，并非互斥分类或独立滑杆。

| 控制域 | 原始维度 | 主要观察点 |
|---|---|---|
| 光色（4） | ①光线氛围与明暗关系；②色彩倾向与色彩分级；③曝光特征与动态范围；④影调与对比关系 | 受光区域、阴影层次、色彩关系、亮暗细节 |
| 成像（4） | ⑤成像质感；⑥后期处理质感；⑦锐度与细节表现；⑧颗粒与噪点特征 | 细节边缘、扩散、后期痕迹、颗粒尺度 |
| 空间（4） | ⑨景深与焦外特征；⑩镜头成像特征；⑪构图方式；⑫摄影机机位 | 清晰范围、透视、主体占比、观看高度 |
| 动态（1） | ⑬快门与运动模糊特征 | 谁在动、拖影方向、静态区域是否稳定 |
| 表达（4） | ⑭材质与高光表现；⑮空气透视与环境氛围；⑯人物造型风格；⑰媒介、笔触与绘制方式 | 表面响应、远近层次、造型语言、表现媒介 |

表达域是实用归组：材质也受光线影响，空气透视也属于空间问题，媒介变化可能影响整幅图。实际使用时先选控制域，再挑一个最关键的维度；不必每次遍历 17 项。

## 3. 变量耦合与重建成本

**只改一个指令变量，不等于结果只改变一个视觉变量。** 常见连带变化包括：

- 光线变化可能带动曝光、色彩和对比度；应分别检查，不能统称“光影成功”。
- 改焦距时，若同时改变拍摄距离以维持主体大小，透视也会变化；不要把焦距与机位混为一谈。
- 机位或构图改变可能暴露原图不可见的身体和环境；补绘内容只能视为推测。
- 媒介转换会重新解释边缘、材质与细节，难以同时要求所有成像特征不变。

| 重建成本 | 典型操作 | 工作预期 |
|---|---|---|
| 较低 | 不改变场景几何的色调、曝光、颗粒、后期质感调整 | 更适合要求内容保持，但生成式编辑仍可能重绘 |
| 较高 | 大幅改变机位、构图、主体尺度，或涉及空间关系的镜头变化 | 可能重建遮挡和不可见部分；准备角色全身设定、多视角或场景参考 |

成本取决于修改幅度与工具，并非维度的固定属性。景深调整也可能改写背景；“低成本”不代表无副作用。改机位时应保留身份、服装与场景设定，同时允许必要的投影和遮挡变化，避免再要求构图完全不动。

## 4. 三图对照验图法

固定排成 **参考图 → 原图 → 迁移结果**，生成前先写出希望借到的可见证据。

1. **目标是否出现？** 对照参考图看目标特征，如受光位置、暗部关系、焦外形态；不能仅凭“更漂亮”判定。
2. **保留项是否守住？** 对照原图看身份、服装、动作、场景、文字等任务关键内容。
3. **出现了什么代价？** 单列背景替换、结构补绘、材质改变、非目标区域拖影等副作用。
4. **结果能否使用？** 标为“未达目标”“方向可用但需修复”“满足本任务验收”，不要用一个成功/失败掩盖差异。

颗粒、锐度与纹理需在原尺寸、同倍率裁切下检查；全图用于判断构图和关系。比较调色时尽量保持显示条件一致。若目标是严格色值或像素一致，另用测量与确定性编辑验收。

可复用记录：

| 目标特征及可见证据 | 迁移结果 | 保留项偏差 | 连带变化 | 使用判断／下一步 |
|---|---|---|---|---|
| 生成前填写 | 出现／部分／未出现，并说明依据 | 逐项记录 | 写清作用区域 | 接受、局部修复或回退 |

## 5. 组合迁移与推荐工作流

“电影感”等大词可以拆成少数关键变量，但**组合更有效仍是待验证策略**，不是这轮单维度试验已经证明的结论。

推荐顺序：

1. **诊断**：指出参考图最值得借用的一个特征，以及图二必须保留的内容。
2. **定边界**：判断是否涉及空间重建；有冲突时明确迁移项与保留项的优先级。
3. **建基线**：固定参考图、底图、图序、模型版本和可用参数；记录原始指令。
4. **单变量试验**：先用基础句式；有条件时重复生成，避免把单张偶然结果当规律。
5. **三图验收**：记录目标收益、保留偏差和副作用。
6. **针对性修正**：一次只补一项范围或约束；必要时改用局部编辑。
7. **组合复测**：将单项表现可接受的特征逐项组合，每增加一项重新验图；出现冲突就拆开或回退。
8. **沉淀**：保存提示词、输入输出、参数、验收结果与反例，跨任务验证后再讨论晋升。

分步编辑可能累积身份和细节漂移；保留原始底图，避免无限接续重绘。工作流可与[迭代手册](../methodology/iteration-playbook.md)配合。

## 6. 可复用中文提示词

约定：图一为特征参考，图二为待编辑底图。使用前确认上传顺序；括号内容按任务替换，保留项只填写真正必要且不冲突的内容。

**基础迁移**

~~~text
将图一的【对应维度】迁移到图二，保持图二的主体身份与主要内容。
~~~

**带范围与保留项**

~~~text
将图一的【目标特征】迁移到图二的【作用范围】；保持图二的【必要保留项】不变。
~~~

**光影迁移**

~~~text
将图一的光线氛围与明暗关系迁移到图二；保持图二的人物身份、姿态、服装、构图与场景内容。
~~~

**色彩迁移**

~~~text
将图一的色彩倾向与色彩分级迁移到图二；保持图二的主体、构图和场景内容。
~~~

**景深迁移**

~~~text
将图一的景深与焦外特征迁移到图二；保持图二人物清晰，保留人物身份、姿态、服装及背景物体的种类与位置。
~~~

**运动模糊限定范围**

~~~text
将图一的人物运动模糊与快门表现迁移到图二，仅作用于运动中的人物；保持人物身份、服装与动作，背景保持稳定清晰。
~~~

**机位迁移**

~~~text
将图一的摄影机机位与透视关系迁移到图二；保持图二的人物身份、服装、动作与场景设定，允许相应的遮挡和构图变化。
~~~

**组合迁移（单项测试后使用）**

~~~text
将图一的光线氛围、明暗关系、色彩倾向和后期调色质感迁移到图二；保持图二的主体身份、姿态、服装、构图与场景内容。
~~~

模板是测试起点，不是保证。若造型或媒介本身就是迁移目标，应相应放开服装或质感约束。

## 7. 适用边界与下一步验证

- 适用于支持参考图输入与图像编辑的工作流，尤其是方向探索和允许迭代修复的创作；不同模型对多图、图序、范围与约束的响应需实测。
- 不保证精确 LUT 复现、像素级保持、身份绝对一致或严格几何变换。原文早期精确调色目标未达预期，不能把视觉方向接近写成精确色彩匹配。
- 单张参考无法唯一确定镜头参数、真实材质或隐藏空间；避免把视觉猜测写成确定参数。
- 要求准确文字、标志、颜色或固定区域时，优先结合蒙版、分层、调色等确定性工具；重建需求高时补充参考。
- 后续验证应分别比较短句与必要长描述、检查多次生成稳定性，并测试单项到组合的收益和副作用。保留失败结果；至少三个独立案例仍只是晋升必要条件，最终由人类批准。
