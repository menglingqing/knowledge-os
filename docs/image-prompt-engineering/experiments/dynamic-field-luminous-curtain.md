# 动态场提示法：用对冲运动轴与光幕建立静帧速度

## 核心命题

当画面需要强烈运动感时，不应只增加“高速、动态、motion blur”等词，而应先定义**动力场**。

一个有效的最小结构是：

> **主体运动轴 + 环境运动轴 + 受力响应证据**

本实验来自“宇宙骑手”连续生成迭代，目前仍属于单案例实践归纳，待跨题材验证。

## 方法一：双轴对冲

将主体与环境设置为相反方向：

- 主体：右下 → 左上
- 环境：左上 → 右下

这种反向关系会制造视觉阻力，使观众感到主体正在“顶着环境穿行”。

如果主体与环境完全同向，画面更容易顺滑但缺少张力；如果主体保持水平而环境斜向，主体容易重新退化为静态展示。

## 方法二：把“背景”改写成“场”

不要写：

> 人物 / 摩托 + 星空背景。

改写为：

> 一个统一的物理场正在作用于主体、光、粒子、衣物、头发、水面和倒影。

要求每个可见元素给出至少一个“受力证据”：

- 头发后拖；
- 衣物单向拉扯；
- 粒子沿统一方向拉丝；
- 高光形成擦过痕；
- 水面倒影破碎并斜向拖拽。

如果只有背景在动、人物和材质不响应，运动感会断裂。

## 方法三：不可命名结构

超现实环境如果被过早命名为“黑色星球”“银河”“黑洞”，模型会自动补全常见视觉模板。

当目标是陌生、神秘、难以解释时，应使用：

- ambiguous
- unreadable
- non-literal
- partial
- fragmented
- not a planet / sphere / galaxy

其本质是：

> **用视觉证据描述现象，不替模型命名对象。**

## 方法四：光幕三层结构

“光幕”不能只写成一块亮面，否则容易生成能量爆炸或巨大光束。

拆成：

1. **幕面**：大尺度斜向发光区域；
2. **颗粒**：闪烁光斑、碎亮片、粒子簇；
3. **拖尾**：光丝、擦过痕、长曝光粒子雨。

三层同时存在，才能产生“持续通过的发光现象”。

## 方法五：信息损失提升摄影感

强运动场中主动允许：

- 暗部吞没机械细节；
- 局部高光溢出；
- 轮廓被光侵入；
- 倒影不完整；
- 主体局部遮挡或接近画面边缘。

原则：

> **轮廓可读，信息不必完整。**

这是从“产品渲染”转向“瞬间摄影”的关键控制。

## 待验证假设

1. 双轴对冲是否在人物动作、动物、车辆等不同主体上稳定增强运动感；
2. “不可命名结构”是否能降低模型自动生成常见科幻符号的概率；
3. 光幕三层结构是否优于单独使用 light streaks / particle flow；
4. 主动信息损失是否能在不同模型上稳定降低 3D / 产品广告感。
