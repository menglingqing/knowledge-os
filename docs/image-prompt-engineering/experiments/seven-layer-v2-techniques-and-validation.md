# 七层架构 v2.0：技法库与案例验证计划

依据[架构 v2.0 升级](../../aigc-aesthetics/methods/concept-driven-seven-layer-methodology.md#11-v20-升级记录2026-10-13)建立的工作版。以下机制为候选技法与假设，无新增生成结果；不得据此宣称模型效果或普适规律。

## 跨层技法库

| 类别 | 目的与可见机制 | 作用层 | 适用条件与冲突风险 |
|---|---|---|---|
| 风格 | 确定摄影、水墨、版画等主媒介，落实边缘、纹理与细节语法 | L4/L5/L6/L7 | 先选主语体；混合时写清职能，避免标签堆叠 |
| 光效 | 主光塑形、轮廓光分离、体积光显示空间 | L3/L5/L6 | 指定来源、方向、强度和范围；多处高亮可能竞争焦点 |
| 情绪 | 宁静：留白与低刺激；孤寂：距离与稀疏；压迫：包围与尺度差 | L1→L2/L3/L4/L5/L7 | 只是假设性映射；冷色不必然孤独，表情不替代氛围 |
| 真实感 | 接触、受力、光源因果、材质响应、距离衰减与局部不完美 | L2/L3/L4/L5/L6/L7 | 按媒介选用；全域锐利、均匀瑕疵或无因果光效可能破坏成立感 |

技法卡字段：名称／目的／作用层／可见机制／适用对象与范围／冲突项／提示表达／对照变量／输入输出链接／结果与反例／证据状态。当前各类别均为 experimental。

调用过程：由概念选择一至两项主技法 → 指定对象与范围 → 检查视觉竞争和约束 → 输出验收 → 决定保留、限定条件或放弃。技法库不是固定滤镜菜单，也不是独立层级。

既有参考：[导演方法](huanmo-visual-direction-v1.1.md)、[环境人像](environmental-portrait-techniques.md)、[模型适配](../methodology/model-adaptation.md)。引用既有经验不自动构成本次验证证据。

## 待验证假设

| 编号 | 假设 | 对照与可能反证 |
|---|---|---|
| H1 | 明确主次并落实视觉权重，可减少无意的主体竞争 | 同场景比较只列元素与明确主次；若识别无改善或削弱概念，限定条件 |
| H2 | L1 简洁情绪词经可见关系落实，比堆叠情绪词更稳定 | 保持概念与场景，对照情绪词堆叠与具体关系；记录提示长度差异 |
| H3 | 状态动态字段适用于建筑、植物和器物，无需强加生命行为 | 独立非人物任务，观察静止与动态描述是否得到预期形态 |
| H4 | 闭合视角、景别与空间条件，可减少观看机制矛盾 | 相同任务比较冲突组合与闭合组合，检查裁切、尺度和细节 |
| H5 | 按概念选择技法并指定范围，可减少风格／光效争夺注意力 | 保持主语体，对照全局效果与局部效果；检查收益及副作用 |
| H6 | 约束优先级能帮助冲突迭代保留核心表达 | 记录关键证据保留率及被牺牲项；未提高符合度时修订排序 |

## 独立案例验证计划

| 任务 | 核心检验 | 待实施对照 |
|---|---|---|
| 少女与巨大建筑 | 主体主次、叙事主体与视觉焦点、空间尺度 | 分别建立少女主体和建筑主体两个方向；各方向内部单变量对照，方向之间不冒充单变量实验 |
| 花朵或器物 | 非人物主体、形态与状态动态、真实感 | 锁定对象与构图，仅改变状态描述或一项材质因果 |
| 建筑／自然现象 | 视角景别组合、空间关系与约束 | 锁定概念与主次，分别测试一项观看条件或冲突消解 |
| 情绪与技法迁移 | 简洁情绪、跨层协同及反例 | 在独立题材分别测试情绪落实或光效范围，不同时改变多项 |

以上为计划，不填写结果或 evidence。每项记录模型与版本、日期、完整提示词、设置、参考图、种子（若支持）、实际输出、单变量差异与无法控制的混杂。条件允许时每条件至少生成三张，避免把偶然成功视为稳定结果；多张输出不等于多个独立案例。

验收维度：主体识别、关键空间关系、观看机制相容性、概念与情绪可读性、硬约束符合度、技法副作用。评审先看图再看解释，分别记录第一视觉焦点和对叙事主体的判断；保留盲评或用户原始反馈、失败图与替代解释，不仅记录成功图。

依[知识治理](../governance.md)，至少三个独立案例是必要条件，还需可追溯证据、无明显推翻性反例并由人类批准；同项目连续迭代及助手共识不自动计为独立证据。

## 真实感强化修订：A/B 验证计划（2026-10-13）

对应[真实感强化修订与街头示例](../../aigc-aesthetics/methods/concept-driven-seven-layer-methodology.md#12-真实感强化修订因果一致性驱动的视觉生成控制2026-10-13)。追加 H7–H9，保留 H1–H6；没有新增生成结果，evidence 保持为空。

| 编号／原讨论假设 | 待验证主张 | A 条件 | B 条件 | 可能反证 |
|---|---|---|---|---|
| H7／假设 A | 主体行为与环境关系比单纯微观不完美更能提升整体真实感 | 相同街头任务，只增皮肤纹理、轻微噪点等局部细节 | 相同基础任务，改用回头事件、头身方向差与发丝响应 | B 的可信度不提高，或姿态结构更差 |
| H8／假设 B | 光源、遮挡与材质响应一致性比泛化风格词更能改善摄影可信度 | 基础侧光场景＋“电影感、大师摄影” | 基础场景＋明确侧光方向、碎发阴影和针织响应 | B 仍存在光影冲突，或只提升精致感 |
| H9／假设 C | 概念筛选与减少无意义词可能提高表达稳定性 | 保留原始关键词堆叠 | 保留相同核心目标，删除重复与竞争装饰词 | B 在多次输出中无更高符合度或损失关键表达 |

H7/H8 是两种提示策略的对照，多个描述同时变化，不能把差异归因于某一个词。先做策略比较，再做单变量消融：固定同一基线，只加入回头因果、只加入光源方向或只加入局部褶皱，每次测试一项。H9 按“只删重复词 → 单独删一项竞争词”分轮执行，避免同时更换构图、风格和人物。

固定模型与版本、设置、画幅、参考图及基础提示；支持种子时配对使用同一组多个种子，不支持时重复采样并记录。将提示长度、语序和不可控输出差异作为混杂记录；可加近似长度对照，但不能为凑字数引入新的视觉要求。

条件允许时每条件至少三张，并扩展至不同模型及多个独立题材；样本数只是起点，不证明普适效果。随机打乱 A/B 标签，先看图再看提示解释，分别评估：概念表达、主体行为、空间关系、成像相容、光材一致、整体可信度、个人审美偏好和副作用。可用 1–5 分记录各维度，保留原始反馈、失败图、平局和不确定项，不能把“更独特”记成“更真实”。

记录模板：假设／单项或策略变量／完整 A/B 提示／模型设置与种子／输入输出链接／盲评记录／收益与副作用／失败与替代解释／结论适用范围。未实施前不填写结果，不晋升 validated；同一街头任务的不同种子不算多个独立案例。
