# R-002｜动物／观察者视角锚定法（研究与验证）

> Animal / Observer Viewpoint Anchoring · 2026-11-01  
> 评级：**A级实用技法（用户实践正反馈）；S级知识贡献候选，未通过独立对照验证**。  
> [案例与可见图像观察](../../aigc-aesthetics/cases/2026-11-01-observer-viewpoint-portrait-cases.md)

## 核心命题

不是逐个写“极低机位、广角、前景遮挡、景深、观众距离”，而是设定一个具体可想象的**观察者**：它在哪里、身体尺度如何、正在做什么、人物是否察觉。利用场景内部的空间因果，让模型推导镜头关系。

候选链路：

**观察者身份 → 栖息点/所在位置 → 高度/视距/倾角 → 前景与近远尺度 → 人物回应 → 观众的观看体验**

此为提示词设计假设；不能视为已被证明的模型内部工作机制。动物视角不是模拟真实动物的复眼、特殊色觉或生理视觉。

## 关键区别：具象隐喻不是万能镜头参数

- **位置**：蝴蝶在花蕊侧面、猫在路沿、松鼠在树枝、乌鸦在招牌外沿，各自提供场景可解释的机位。
- **行为**：停驻、飞过、躲藏、抬头观察、自拍主动看镜头，会改变透视和情绪。
- **距离**：同一动物可近可远。蝴蝶视角可以低位放大尺度，也可以枝叶窥见人物；乌鸦可斜俯，也可能退化为垂直俯视。
- **遮挡**：花瓣、叶子、建筑灯箱、伸长手臂让机位“有证据”，不保证前景越大越好。
- **媒介**：摄影透视、f 值与动物称谓并无确定映射，精确数值在需要时仍需额外约束。

## 六类已讨论的镜头策略

| 观察者 | 典型位置与机位语义 | 人物摄影的重点 | 风险 |
| --- | --- | --- | --- |
| 蝴蝶 | 花丛内部，极近/低位或花叶遮挡 | 花瓣大前景、浅景深、视线偶遇 | 误变花田全景；脸被遮挡 |
| 猫 | 街道路沿，接近地面的斜仰拍 | 鞋履近大远小、人物低头 | 畸形比例、僵硬摆拍 |
| 松鼠 | 树干侧方枝杈，略高斜俯 | 树皮与枝叶天然框架、人物抬头 | 枝条穿人、面部不可见 |
| 飞鸟（泛称） | 空中或建筑上方高位 | 建筑秩序、尺度、留白 | 无人机式超远俯视 |
| 蠕虫视角自拍 | 人物附近极低位强仰视，非必然贴地 | 身体至面部透视、延伸手臂作为自拍证据 | 腰背不自然、手臂抢焦、夸张衣着走光 |
| 乌鸦 | 城市招牌／窗沿／路灯约 3–8m，高处近距斜俯 | 湿路霓虹、斑马线、灯牌前景、人物抬头 | 被模型误解为无人机/垂直顶拍，招牌夺目 |

鸟类扩展：鹰隼（追踪远距）、鸽子（城市亲近低空）、麻雀（小间隙/栏杆）、猫头鹰（暗处静候）、海鸥（开阔水岸）；这些仅为语义候选，不能当成已验证的固定镜头配置。

## 三个可迁移的子技法

### A. 栖息点锚定（Perch-Based Camera Anchoring）

在动物称谓后明确“停在哪里”。示例：**乌鸦停在二楼霓虹招牌外沿，近距离斜俯雨夜街边的成年女性**。这个具体建筑关系同时约束机位高度、可见前景和灯牌尺度。

### B. 观察者存在感（Observer Presence）

前景并非纯装饰，而是“正在观察”的物理证据。示例：**蝴蝶停在花丛里，失焦叶片在视点上下左右形成不规则缝隙，人物从缝隙中回望**。不应把“蝴蝶视角”机械等同于贴地仰拍。

### C. 自拍者位置证据（Selfie Viewpoint Evidence）

主角主动控制镜头时，可以利用延伸到画外的手臂解释相机位置。要同时设定姿态与比例边界，不能仅用极端广角制造身体局部放大。

### 2026-11-02｜自拍者位置证据的实测补充

[《午夜失焦》V1 自拍图的逐项成图复核](../../aigc-aesthetics/cases/2026-11-02-midnight-out-of-focus-selfie-v1-review.md)已确认：近距离前伸手臂与画面外自拍持握形成强烈的**摄影机位置线索**，并获得用户正向反馈。但**广角自拍感成立不等于“膝部附近低机位仰视”准确实现**；两处强近景（手臂、膝部）仍可能同时抢占面部注意力。此为单次综合成图成功，不独立验证动物视角的语义效应。维持 `experimental`。

## 和现有七层体系的关系

- L1 概念：选择“偶然发现、旁观、跟随、窥见、自我展示”的观看意图。
- L2 主体：人物是否发现视点、如何抬头/低头、身体重心与姿态是否成立。
- L3 环境：为动物/观察者提供可解释的栖息点、遮挡物和真实场景。
- L4 构图：由栖息点推导镜头高度、方向、距离及视觉动线；必要时补充参数。
- L5–L7：光源、材质和色彩仍按同一物理情境工作，不能被“动物视角”替代。
- R-001 注意力与信息密度：遮挡建立观察感的同时，可能抢占面部视觉焦点；需要独立验证最优取舍。

## 2026-11-02｜三种古风人像组合实践：首轮正向反馈

基于此前《眉间朱砂》真人古风 V1（用户反馈效果较好），进一步设计三组跨案例组合：**《花间初见》蝴蝶视角+花瓣前景+俯身含羞**、**《檐上来客》麻雀视角+梅枝高位+抬头好奇**、**《风过回廊》猫视角+湿石低机位+行走回眸**。用户实际生成后，对三张照片整体评价为“效果都是非常好的，控制能力也比较强，然后整体的这个画面质感也非常好”。

**状态调整：首轮实践获得正向反馈。** 这是一轮用户报告的综合效果验收，而非严格对照实验；尚未直接取得可逐张复核的输出图片、原始参数、全部批次和失败样本，因此不把三张作品计作三个独立验证，维持 `status: experimental`。本轮主要支持“组合方案值得保留继续测试”，不支持“动物名独立导致好看”这一因果归因。

详见[2026-11-02 三组古风写真完整案例记录](../../aigc-aesthetics/cases/2026-11-02-classical-portrait-animal-viewpoint-experiment.md)。

## 实验设计（尚未执行严格 A/B）

固定：同一个成年角色、服装、动作基础、场景、模型版本与画幅；若工具支持，固定种子或相同角色参考。每组保存包括失败在内的全部输出。

- **A 参数版**：直接写高度、角度、距离、前景遮挡等，没有动物名。
- **B 语义版**：仅“乌鸦视角／蝴蝶视角”等简短设定，其他摄影条件不指定。
- **C 语义 + 栖息点版**：动物 + 停驻位置 + 人物回应，保留必要的物理和审美上限。

至少跨花园/夜街/室内三个场景，分别记录：机位命中、透视自然度、前景遮挡质量、主体可辨、姿态与身体连接、光源因果、氛围与创新度。若 C 较 A/B 更好，仍须排除提示词长度和信息量的差异；不能直接归因于动物名称。

## 当前沉淀决策

- **记录为 R-002 实验研究项及配套案例集**，不将“动物名=确定焦距/角度”写成规则。
- 当前证据包括：用户对早期四组完整动物视角生图提示词的正向评价；蝴蝶、蠕虫自拍、乌鸦各三张会话展示图的可见观察；2026-11-02 三组古风写真组合实践的总体正向反馈。仍未保存本轮生成图、原始模型设置/完整批次，不满足正式晋升的独立案例要求。
- 暂不升级七层视觉生成架构 v2.0 或七段式生图 Skill。
- 后续需遵循[治理规则](../governance.md)完成可复核对照，并由用户裁决正式晋升。
