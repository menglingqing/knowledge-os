# 室内人像：光学朦胧、面部结构与「写真」风格先验（待验证）

关联案例：[2026-11-02 私密卧室人像 V1–V4](../../aigc-aesthetics/cases/2026-11-02-bedroom-intimate-portrait-v1-v4-series.md)。本页记录可操作实验，不把用户推测、单张成图或多轮同主题抽卡视为充分因果验证。

## 假设

- **H1／语义关联**：中文「写真」可能引导模型使用与商业精修摄影相关的形态与皮肤风格先验，表现为更均匀的肤质或理想化脸型。训练时学到文本—图像关联，不意味着生成时实时抓取训练图库；内部机制与实际影响无法从四张图直接确认。
- **H2／光学朦胧**：模拟「有方向的侧逆光 → 透光碎发与肩背高光 → 有范围的高光扩散」，可保留清晰眼睛和面部结构，相比「全图柔焦／磨皮」更接近优秀参考的真实摄影感。
- **H3／审美优先**：成功参考的姿态、服装、表情与道具支撑先设计好，再调局部皮肤和光学效果，可减少技术修正牺牲总体美感的风险。

## 已有信号

《窗边私语》单次 A/B/C/D 对照：B（去「写真」＋常规柔光）脸部相对最好；去词＋精确光影 D 并未同样成功；包含多处随机脸型、视角、构图混杂。**不能推断「写真」导致脸部塌陷**。《帘隙晨光》V2 改造型后用户反馈大幅改善；V3 去前景且强化俏皮；V4 使用有方向的窗逆光和枕头接触，实际图片可见透光发丝，用户认为不错。以上均是同一主题的连续实践，不够单独晋升规律。

## 可执行的两轮对照

### 轮次一｜词汇（不同时改审美）

在一张**已经有足够审美完成度**的固定主体/姿势/服装/背景/光线基线上，用相同的模型、画幅及可用的相同种子：
- A：仅在开头加入「写真」；B：删除这两个字，其他字句全部相同。
- 至少 3 个种子配对；保留**所有成图**，不只保留最佳图。若不能控种子，按随机分组增加样本、记录设置并降低因果断言。
- 验收拆开：① 眼鼻口/颧颊/下颌结构 ② 皮肤反射与微纹理 ③ 人物神态 ④ 全图审美与构图。对照评价不要把更漂亮等同于更真实。

### 轮次二｜光学辉光 vs 全域柔化

固定人物和布局，比较：
- C：常规自然窗光；D：明确侧后窗光、边缘透光发丝、**只在窗侧亮部有限扩散**，脸部清晰；E：「柔焦、朦胧」泛化描述（作为可能失败对照，非推荐创作）。
- 分别记录高光是否局限、眼周与鼻翼是否保留立体、发丝是否透明/发亮、皮肤是否被全域抹平、整体摄影情绪是否提升。

## 光学转译范例（供后续提示词局部替换，不构成固定配方）

> 窗边侧后方自然光穿过散落碎发，头发边缘有细密透光与轻微辉光；明亮窗侧产生有限的高光扩散，眼睛、鼻梁和脸颊保留清晰微反差；皮肤、丝绸、蕾丝与床单依各自材质反射，整体柔亮但不全域模糊。

使用范围：亲近、清甜、慵懒的晨间人像。高冷硬光、闪光 CCD、夜间低调摄影**不能机械套用同一布光**。

## 晋升边界

遵循 [知识治理](../governance.md)：至少 3 个**独立案例**是必要非充分条件；同一提示词衍生版本算同项目实践，不能凭当前 V1–V4 自评 validated。用户批准之前，只将「风格词先验」「可控辉光」「成功品迁移」放在 experimental 技法与案例，不改正式框架，不将「写真」列为通用禁用词。

**下一步重点**：先复现 V4 的局部辉光并保住面部，再换不同风格（如清冷侧光、夜间暖光）检验适用边界；同时保持服装与姿态审美不降级。
