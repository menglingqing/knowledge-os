# L0｜中美投资认知体系总纲

> **定位**：一个世界模型，两套市场机制，三类投资机会，一套验证系统。
>
> 本体系不是“买什么股票”的答案库，而是一套持续被现实检验、修正和升级的投资操作系统。

## 0. 为什么要先建立认知体系

没有体系时，投资容易变成：
- 涨了以后找理由；
- 跌了以后换理由；
- 今天听政策，明天看业绩，后天看技术面；
- 每次交易似乎都有逻辑，但这些逻辑彼此不属于同一个系统。

有体系以后，投资变成：

```
世界模型
  ↓
形成判断
  ↓
提出假设
  ↓
寻找证据
  ↓
建立仓位
  ↓
现实验证
  ↓
复盘偏差
  ↓
修正模型
```

核心原则：

> **体系负责解释现实，现实负责淘汰体系。**

## 1. 第一性原则：投资赚什么钱

投资收益可拆成三部分：

```
投资收益
≈ 企业内在价值增长
+ 股东现金回报
+ 市场重新定价
```

### 1.1 企业内在价值增长
利润、自由现金流、竞争优势、市场份额、资本回报率持续改善。

### 1.2 股东现金回报
分红、回购、降低杠杆；反面是不断融资、增发、低效扩产和稀释。

### 1.3 市场重新定价
现实优于市场预期，估值从低估回归合理，或者共识形成带来估值提升。

任何投资前都要问：

> **我准备赚哪一种钱？**

如果无法回答，投资逻辑尚未闭环。

```
世界运行系统

                      ↓
                全球产业趋势
                      ↓
            中美产业分工与竞争
                      ↓
       ┌──────────────┴──────────────┐
       ↓                             ↓
   中国市场                       美国市场
 国家战略与产业升级             创新与资本效率
       ↓                             ↓
    产业链                        商业生态
       ↓                             ↓
    企业赢家                      企业赢家
       └──────────────┬──────────────┘
                      ↓
                  股东回报
                      ↓
                  市场定价
                      ↓
                组合与仓位
                      ↓
                实践与复盘
```

## 3. 一个世界模型，两套市场机制

### 中国：国家—产业—企业

中国市场研究时，需要更重视：

```
国家战略
  ↓
资源配置
  ↓
产业升级
  ↓
企业竞争
  ↓
股东回报
  ↓
市场定价
```

第一问不是“哪家公司利润增长最快”，而是：

> **未来 5—10 年，中国有哪些事情必须做成？**

但必须牢记：

```
国家成功
≠ 产业成功
≠ 企业成功
≠ 股东成功
≠ 股票上涨
```

政策只告诉我们战场在哪里，不能直接告诉我们谁能赢、股东能拿到多少、价格是否便宜。

### 美国：创新—企业—资本复利

美国市场研究时，更需要重视：

```
技术 / 商业模式创新
        ↓
     竞争优势
        ↓
      高利润
        ↓
    自由现金流
        ↓
      再投资
        ↓
 更大的竞争优势
        ↓
     长期复利
```

核心问题：

> **哪家公司能够形成长期高 ROIC，并持续把利润投入高回报业务？**

## 4. 三类投资机会

### A. 中国式产业跃迁
国家战略 → 产业投入 → 国产替代 / 出海 / 规模化 → 龙头胜出 → 盈利释放。

核心问题：

> **产业能不能打赢？利润最终流向哪里？**

### B. 美国式资本复利
创新 → 护城河 → 高 ROIC → 自由现金流 → 再投资 → 长期复利。

核心问题：

> **这台赚钱机器还能运行多久？**

### C. 全球结构性机会
同一全球趋势中，同时寻找中国与美国最优资产表达。

核心问题：

> **价值最终沉淀在哪里？应该用哪个市场、哪个公司、什么价格去承接？**

## 5. 投资体系的七层

| 层级 | 模块 | 核心问题 |
|---|---|---|
| L0 | 总纲 | 世界怎么运行？ |
| L1 | 产业与产业链 | 钱往哪里流？ |
| L2 | 公司 | 谁能把钱拿走？ |
| L3 | 估值与预期 | 现在付多少钱？市场已经相信多少？ |
| L4 | 组合与仓位 | 应该押多少？如何避免单点失败？ |
| L5 | 买入、持有与退出 | 何时行动？何时继续？何时认错？ |
| L6 | 复盘与认知迭代 | 为什么对/错？模型如何升级？ |

版本号只用于**模块内部迭代**，不再用版本号代替知识层级。

## 6. 投资前五问

任何机会进入研究前，必须先回答：

1. **世界为什么正在发生这个变化？**
2. **这个变化会让哪个产业的利润池扩大？**
3. **谁最有能力拿走利润？**
4. **利润能否最终变成股东回报？**
5. **市场已经提前计价了多少？**

任何一问说不清楚，都说明研究尚未完成。

## 7. 中美比较原则

中美不是两套彼此孤立的投资方法，而是：

> **同一个世界，两种市场表达。**

任何全球产业都应强制比较：
- 产业链控制权
- 技术壁垒
- 成本优势
- 商业模式
- 利润率
- ROIC
- 自由现金流
- 竞争格局
- 资本开支
- 政策与监管
- 估值
- 股东回报机制

最终只能得到四类结论：
- 投中国
- 投美国
- 两边都投，但赚不同的钱
- 两边都不投

## 8. 可证伪原则

不能只写“我看好”。

必须同时写：
- 核心判断
- 支撑证据
- 关键变量
- 证伪条件
- 降仓/退出条件

> **没有“什么情况下我错了”的观点，不是投资判断，而是信仰。**

## 9. 实践闭环

```
观察世界
  ↓
形成认知
  ↓
提出假设
  ↓
寻找证据
  ↓
建立仓位
  ↓
等待现实验证
  ↓
复盘偏差
  ↓
修正模型
  └────────→ 再次实践
```

最终目标：

> **投资不是证明自己永远正确，而是不断淘汰错误的世界模型。**
