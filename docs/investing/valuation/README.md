# L3｜估值与市场预期

> **任务**：把“好产业、好公司”转化为“好投资”。

好公司不等于好股票。真正决定回报的是：

> **价值、价格与预期之间的关系。**

## 1. 三个对象必须分开

- **企业价值**：未来能创造多少现金流。
- **市场价格**：今天别人愿意付多少钱。
- **市场预期**：当前价格已经隐含了怎样的未来。

投资研究不能只问“公司好不好”，还必须问：

> **市场已经相信多少？**

## 2. 估值方法只是工具

### PE
适合盈利较稳定、利润有代表性的企业。

### PB
更适合金融、资源、重资产等净资产具有解释力的行业。

### EV/EBITDA
适合资本结构差异较大的成熟企业。

### EV/Sales / EV/ARR
适合尚未稳定盈利但收入质量较高的成长企业；必须同时检查毛利和单位经济。

### DCF
适合现金流逻辑相对清晰的企业；最重要的不是精确小数，而是对长期变量的敏感性。

任何估值方法都不能脱离商业模式。

## 3. 反向估值优先

与其问：

> “合理 PE 是多少？”

更有价值的问题是：

> **当前价格要求公司未来做到什么？**

从价格反推：
- 收入增速
- 利润率
- 市占率
- ROIC
- 终值增长率

再判断这些隐含假设是否现实。

## 4. 预期差

股票价格通常不是与现实比较，而是与预期比较。

```
实际结果 > 市场预期 → 正向预期差
实际结果 < 市场预期 → 负向预期差
```

优秀公司如果预期过高，仍可能是差投资；普通公司如果预期极低且现实改善，也可能产生高收益。

## 5. 安全边际

安全边际不仅是“估值便宜”。

至少包括：
- 价格安全边际
- 资产负债表安全边际
- 商业模式安全边际
- 竞争优势安全边际
- 预期安全边际

更高质量的安全边际通常来自：

> **即使部分假设错了，也不至于永久性损失资本。**

## 6. 情景分析

不要只做一个目标价。

至少建立：
- Bear Case
- Base Case
- Bull Case

每个情景明确：
- 收入
- 利润率
- FCF
- 估值倍数/折现率
- 概率

目标不是制造精确，而是暴露关键假设。

## 7. 中国市场估值注意点

额外关注：
- 政策预期切换
- 行业资本开支周期
- 融资与再融资
- 国企治理与分红
- 主题行情与基本面脱节
- 流动性和风险偏好
- A/H 股价差

不要把政策确定性直接等同于估值安全。

## 8. 美国市场估值注意点

额外关注：
- 长期利率
- 股票回购
- 股权激励稀释
- 高增长持续时间
- 超级公司利润集中
- 指数权重和资金集中
- 长久期资产对折现率敏感性

## 9. L3 输出

每个标的必须产出：
- 当前市场隐含预期
- Bear/Base/Bull 三情景
- 可接受买入区间
- 关键估值变量
- 哪个变量最可能导致估值失效

完成 L3 后进入 L4：组合与仓位。
