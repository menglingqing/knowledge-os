# L6｜复盘与认知迭代

> **任务**：让每一次正确和错误都变成可积累的认知资产。

没有复盘，经验只是重复；有结构化复盘，实践才能更新模型。

## 1. 复盘不是看赚没赚钱

必须区分四种情况：

| 结果 | 决策质量 | 含义 |
|---|---|---|
| 赚钱 | 正确 | 最理想 |
| 赚钱 | 错误 | 运气，危险 |
| 亏钱 | 正确 | 可能是概率事件 |
| 亏钱 | 错误 | 需要修正模型 |

所以不能用收益结果直接证明判断质量。

## 2. 错误分类

### 世界模型错误
对宏观、技术、政策、人口、能源等判断错误。

### 产业错误
错判需求、供给、周期、利润池或价值控制点。

### 公司错误
错判竞争优势、管理层、财务质量或资本配置。

### 估值错误
公司没看错，但价格支付过高。

### 仓位错误
判断可接受，但下注过大或相关性过高。

### 执行错误
被情绪、价格波动、追涨杀跌破坏纪律。

### 时间错误
方向正确，但兑现周期判断错误。

## 3. 归因必须落到“哪一层错了”

不要写：
- 市场不讲道理
- 运气不好
- 主力砸盘

而要写：
- 需求判断错了
- 供给扩张快于预期
- 利润池转移
- 公司失去定价权
- 市场早已完全计价
- 仓位与不确定性不匹配

认知分辨率越高，下一次改进越有效。

## 4. 预测记录

每次重要投资都保存“事前判断”，避免事后合理化。

至少记录：
- 我当时相信什么？
- 最关键的 3 个假设是什么？
- 市场当时相信什么？
- 什么数据会证伪？
- 预计多久验证？

## 5. 复盘周期

### 单笔复盘
逻辑证伪、清仓、重大事件后。

### 月度复盘
检查：
- 最大盈亏来源
- 是否有重复错误
- 仓位是否与确定性匹配

### 季度复盘
检查：
- 世界模型
- 产业假设
- 中美配置
- 组合风险因子

### 年度复盘
更新：
- 哪些原则被现实验证
- 哪些原则应该删除
- 哪些新变量必须加入体系

## 6. 模型升级原则

一条经验只有满足以下条件，才值得进入长期认知体系：
1. 能解释多个案例；
2. 有明确边界；
3. 可被证伪；
4. 能改善未来决策；
5. 不是一次偶然结果。

避免把单个案例过度总结成“规律”。

最终目标：

> **每一次亏损，都能更精确地知道自己为什么亏；每一次盈利，也能知道究竟来自能力还是运气。**
