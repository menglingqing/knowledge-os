# L1｜产业与产业链研究

> **任务**：从“世界发生变化”推导到“利润最终流向哪里”。

L1 不负责选公司，先回答：**这个战场值不值得进入？**

## 1. 产业研究总链条

```
世界变化
  ↓
需求产生
  ↓
供给响应
  ↓
供需决定价格
  ↓
产业产生利润
  ↓
利润沿产业链重新分配
  ↓
价值控制点出现
  ↓
中国 / 美国分别承接价值
  ↓
进入公司研究
```

## 2. 产业七问

### 2.1 为什么会发生？
判断驱动力来自：
- 技术进步
- 国家战略
- 成本下降
- 人口变化
- 能源变化
- 制度变化
- 地缘政治变化

优先研究“必然性增长”，而不是只研究热门概念。

一个简单测试：

> **如果股票市场关闭五年，这个产业还会继续发展吗？**

如果答案是“会”，说明我们研究的是现实世界；如果主要依赖资本市场情绪，则需要警惕。

### 2.2 需求从哪里来？
回答四个问题：
1. 谁买？
2. 为什么买？
3. 付多少钱？
4. 能持续多久？

需求主体可能是消费者、企业、政府、军方、医院、云厂商、制造企业等。

需求动机优先级通常为：
刚性安全/生产需求 > 明确降本增效 > 收入增长 > 政策刺激 > 纯偏好。

重点识别**成本临界点**：当新技术总成本低于旧方案时，需求往往从试验进入规模化。

### 2.3 供给增长多快？
看到需求增长时，必须条件反射地问：

> **供给增长多少？**

核心是供需剪刀差：

```
需求增长 > 供给增长 → 价格/利润环境改善
需求增长 < 供给增长 → 价格战/库存/利润恶化
```

重点研究：
- 扩产周期
- 资本开支
- 产能利用率
- 技术门槛
- 关键设备/材料约束
- 人才约束
- 许可与监管约束

### 2.4 利润池在哪里？
产业规模不等于投资价值。

必须画出：

```
原材料 → 核心设备 → 核心零部件 → 制造 → 平台 → 品牌 → 渠道 → 用户
```

并回答：

> **每 100 元终端收入中，利润最终沉淀在哪些环节？**

### 2.5 谁拥有价值控制点？
价值控制点通常拥有：
- 稀缺性
- 不可替代性
- 高切换成本
- 技术壁垒
- 网络效应
- 成本曲线优势
- 标准制定权
- 关键入口/渠道
- 关键资源控制权

产业研究不是“把整条产业链买一遍”，而是寻找**议价权最强的位置**。

### 2.6 处于什么产业周期？

```
技术验证 → 商业导入 → 高速扩张 → 产能过剩/洗牌 → 成熟集中
```

- 技术验证：看技术能否成立。
- 商业导入：看客户是否真正付钱。
- 高速扩张：看量价与利润弹性。
- 过剩洗牌：警惕扩产、融资、库存和价格战。
- 成熟集中：关注集中度、现金流和龙头定价权。

关键提醒：

> **产业最繁荣的时候，可能恰恰是股票最危险的时候。**

### 2.7 中美分别获得什么？
同一趋势必须强制做 China vs USA。

## 3. 中国产业研究：增加“战略必要性”

不要把“政策提及”当成“国家战略”。

可先分四档：

- **S：战略必需**——国家安全、产业安全、能源安全、科技自主。
- **A：长期产业升级**——显著提升生产率、附加值、全球竞争力。
- **B：政策鼓励**——有支持，但战略约束较弱。
- **C：主题政策**——阶段性政策或市场叙事。

中国支线重点研究：
- 国产替代率
- 供应链完整度
- 制造成本曲线
- 产业集群
- 龙头扩产
- 出海竞争力
- 政策资源是否转化为商业回报

## 4. 美国产业研究：增加“利润集中能力”

重点判断产业增长后，利润是否会集中到少数企业。

容易形成利润集中的结构：
- 网络效应
- 平台效应
- 软件低边际成本
- 数据飞轮
- 生态锁定
- 品牌
- 规模经济
- 全球定价权

如果产业增长很快但利润高度分散，投资价值可能弱于表面增速。

## 5. 价值创造 ≠ 价值捕获

必须区分：

- **Value Creation**：为客户、社会、产业创造多少价值。
- **Value Capture**：企业自己能留下多少价值。

一个产业可能创造巨大社会价值，却因竞争激烈只留下极低利润率。

投资更关注：

> **谁能捕获价值。**

## 6. 产业质量模型

可用一个启发式模型：

```
产业质量
≈ 需求确定性
× 供给约束
× 利润池规模
× 价值控制力
× 持续时间
```

它不是数学公式，而是强制检查清单。

任何一项接近零，都可能显著降低投资价值。

## 7. 三种确定性

- **现实确定性**：事情真正发生的概率。
- **产业确定性**：增长能否转化为行业利润。
- **市场确定性**：投资者已经相信了多少。

更理想的状态通常是：

```
现实确定性：高
产业确定性：高
市场确定性：尚未完全形成
```

也就是：

> **现实领先共识。**

## 8. 重点寻找“产业错配”

优先寻找：
- 市场低估需求
- 市场高估供给
- 市场看错利润池
- 市场低估价值控制点
- 市场看错产业周期
- 中美市场对同一产业出现定价差

真正的产业投资机会不是“行业很热门”，而是：

> **现实产业结构与市场认知之间存在可验证的错配。**

## 9. 标准研究模板

```
【产业名称】

01 世界变化
为什么会发生？

02 核心驱动力
技术 / 国家 / 成本 / 人口 / 能源 / 制度？

03 需求
谁买？为什么买？付多少钱？临界点在哪里？

04 供给
谁能生产？扩产多久？供给增速多少？约束是什么？

05 供需剪刀差
未来 3—5 年如何变化？

06 产业周期
验证 / 导入 / 扩张 / 过剩 / 出清 / 成熟？

07 产业链
上游 → 中游 → 下游

08 利润池
利润沉淀在哪些环节？

09 价值控制点
谁最不可替代？谁最有议价权？

10 中国
战略必要性？国产替代？成本？出海？

11 美国
技术壁垒？平台效应？利润集中？全球定价权？

12 中美比较
哪个市场拥有更好的资产表达？

13 市场预期
目前市场相信了多少？

14 核心分歧
我们与市场的真正不同判断是什么？

15 证伪条件
哪些事实出现说明我们错了？
```

完成 L1 后，才进入 L2 公司研究。
