# 投资案例库

> **任务**：用真实案例检验 L0—L6，而不是让体系停留在抽象层面。

案例库不是“牛股收藏夹”，而是认知体系的实验室。

## 1. 案例类型

### 产业案例
验证 L1：
- 需求判断
- 供给判断
- 周期
- 利润池
- 价值控制点
- China vs USA

### 公司案例
验证 L2：
- 商业模式
- 竞争优势
- 财务质量
- 资本配置
- 股东回报

### 估值案例
验证 L3：
- 市场隐含预期
- 预期差
- 安全边际
- 反向估值

### 组合/执行案例
验证 L4—L5：
- 仓位
- 相关性
- 加减仓
- 卖出

### 错误案例
优先收录。
真正高价值的案例往往是：

> **我们当时为什么会相信一个后来被现实证明错误的判断？**

## 3. 案例进入知识体系的规则

一个案例不能因为“故事精彩”就进入长期规则。

只有当它：
- 对某个模型提供验证或反例；
- 可以明确说明适用边界；
- 对未来决策有迁移价值；

才应该上升为长期认知。
