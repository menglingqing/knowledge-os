# L5｜买入、持有与退出

> **任务**：把研究变成有纪律的行动。

## 1. 买入

买入前必须同时存在：
- 逻辑成立
- 关键变量可验证
- 风险可承受
- 估值提供足够赔率
- 仓位与组合匹配

不要因为“好公司”自动买入，也不要因为“跌很多”自动买入。

## 2. 持有

持有不是不操作，而是持续检查：

> **最初的投资逻辑是否仍在兑现？**

持有期间重点跟踪：
- 关键经营指标
- 产业供需
- 竞争格局
- 管理层资本配置
- 财务质量
- 市场预期变化

股价波动本身不是持有理由，也不是卖出理由。

## 3. 加仓

理想加仓来自三种情况：
1. 核心事实被进一步验证；
2. 内在价值上升；
3. 价格下跌但基本面未恶化，赔率提升。

禁止把“越跌越买”当成独立策略。

## 4. 减仓

常见减仓条件：
- 估值透支
- 风险收益比下降
- 组合集中度过高
- 关键变量开始弱化
- 出现更优机会

减仓不等于看空，而可能只是风险管理。

## 5. 卖出

卖出至少有四类原因：

### 逻辑证伪
核心假设被事实推翻。

### 公司变差
竞争优势、现金流、管理层、资本配置恶化。

### 价格过度
未来多年乐观预期已经被充分计价。

### 机会成本
出现明显更优的风险收益比。

## 6. 不应该成为卖出理由的因素

单独来看，以下通常不足以构成卖出理由：
- 短期股价下跌
- 市场情绪悲观
- 一次正常季度波动
- 与基本面无关的噪音

关键仍是：

> **原始投资假设是否发生实质变化。**
