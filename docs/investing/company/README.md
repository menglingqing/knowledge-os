# L2｜公司研究

> **任务**：产业已经选对以后，判断谁是真正的赢家。

L1 解决“战场在哪里”，L2 解决：

> **谁能长期拿走超额利润，并把利润转化为股东回报？**

## 1. 公司研究四大模块

```
商业模式
  ↓
竞争优势
  ↓
财务质量
  ↓
资本配置与股东回报
```

## 2. 商业模式：钱怎么赚

必须回答：
- 客户是谁？
- 客户为什么付钱？
- 收入按什么方式产生？
- 收入是否可重复？
- 单位经济是否成立？
- 规模扩大后毛利和费用率如何变化？
- 增长依赖内生需求还是持续融资？

优先识别：
- 一次性收入 vs 经常性收入
- 高毛利 vs 低毛利
- 轻资产 vs 重资产
- 周期型 vs 结构成长型
- 平台型 vs 制造型
- 资本密集型 vs 知识密集型

## 3. 竞争优势：为什么客户必须选择它

不要停留在“龙头”“护城河”“技术领先”等标签。

真正要回答：

> **为什么客户必须选择它？五年后为什么仍然选择它？**

常见优势来源：
- 成本优势
- 技术领先
- 规模效应
- 网络效应
- 数据优势
- 品牌
- 渠道
- 生态系统
- 切换成本
- 监管牌照
- 稀缺资源
- 供应链整合能力

竞争优势必须具有**持续时间**，否则只是阶段领先。

## 4. 胜率 × 赔率 × 持续时间

一个公司可以：
- 胜率高，但估值过高；
- 赔率高，但胜率极低；
- 当前优势强，但持续时间很短。

因此公司吸引力可用启发式表达：

> **投资吸引力 ≈ 胜率 × 赔率 × 持续时间**

三者必须同时研究。

## 5. 财务质量：利润是真是假

重点检查：

### 收入质量
- 增长来自量、价还是并购？
- 客户集中度如何？
- 应收账款增长是否快于收入？
- 收入是否依赖少数补贴或一次性项目？

### 毛利与费用
- 毛利率是否稳定？
- 规模扩大是否带来经营杠杆？
- 销售、研发、管理费用是否有效？

### 现金流
- 净利润是否能转化为经营现金流？
- 自由现金流是否持续？
- 资本开支是否吞噬现金？

### 资产负债表
- 净现金还是高杠杆？
- 债务期限和利率风险如何？
- 存货是否异常？
- 是否依赖持续融资？

## 6. 资本配置：管理层如何使用赚到的钱

企业赚到 1 元钱以后，大致有五种去向：
1. 再投资主营业务
2. 并购
3. 偿债
4. 分红
5. 回购

判断标准不是“做了什么”，而是：

> **这 1 元钱被放到哪里，能创造最高长期回报？**

重点观察：
- 再投资 ROIC
- 并购纪律
- 是否高位增发、低位回购
- 是否追求规模而牺牲回报
- 管理层是否把每股价值放在重要位置

## 7. 股东回报：公司成功不等于股东成功

必须持续检查：

```
收入增长
→ 利润增长
→ 现金流增长
→ 每股价值增长
```

如果中间被高资本开支、增发、债务、低效并购截断，则公司成长未必转化为股东收益。

核心指标：
- ROIC / ROE
- FCF
- FCF Margin
- 每股 FCF
- 净负债
- 股本变化
- 分红率
- 回购收益率

## 8. 中国公司研究重点

中国企业研究增加以下权重：
- 成本曲线
- 制造效率
- 规模化能力
- 供应链位置
- 国产替代份额
- 产业政策适配度
- 出海能力
- 海外收入质量
- 价格战承受能力
- 国企/民企资本配置差异

核心问题：

> **它是否只是产业增长的参与者，还是能够在价格竞争中留下利润的赢家？**

## 9. 美国公司研究重点

美国企业研究增加以下权重：
- 全球定价权
- 网络效应
- 软件/平台规模效应
- 生态锁定
- 研发效率
- 高毛利与高 FCF
- 长期 ROIC
- 再投资跑道
- 回购质量
- 管理层资本配置

核心问题：

> **这家公司是否是一台可以长期运行的资本复利机器？**

## 10. 公司研究红旗

出现以下情况需要显著提高警惕：
- 收入高速增长但 FCF 长期恶化
- 应收、存货增长显著快于收入
- 长期依赖增发维持增长
- 管理层频繁改变口径
- 并购过多且商誉持续膨胀
- ROIC 长期低于资本成本
- 产业景气高点大规模扩产
- 客户高度集中且缺乏议价权
- 核心产品快速同质化
- 竞争优势只建立在补贴上

## 11. 公司研究标准模板

```
【公司名称】

01 公司到底做什么？
一句话解释商业模式。

02 客户是谁？
谁付钱？为什么付？

03 收入模式
一次性 / 经常性？量价驱动是什么？

04 竞争优势
为什么客户选择它？

05 优势持续时间
五年后为什么仍然成立？

06 产业位置
位于利润池和价值控制点的哪里？

07 财务质量
收入、利润、现金流是否一致？

08 ROIC 与再投资
赚到的钱能否继续高回报投入？

09 资本配置
并购、分红、回购、融资是否理性？

10 股东回报
每股价值是否持续增长？

11 中国/美国特有变量
政策/产业链/出海，或平台/生态/全球定价权。

12 估值前关键变量
未来三年最重要的 3 个驱动因子是什么？

13 核心分歧
我们比市场多知道/不同意什么？

14 证伪条件
什么事实出现说明公司逻辑失效？
```

完成 L2 后进入 L3：估值与市场预期。
