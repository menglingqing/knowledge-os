# L4｜组合与仓位

> **任务**：把“我认为对”转换成“应该押多少”。

投资失败很多时候不是判断完全错误，而是**仓位和风险结构错误**。

## 1. 仓位不是信心表达，而是风险预算

仓位至少由四件事共同决定：

```
仓位
≈ 确定性
× 赔率
× 流动性
÷ 潜在永久损失
```

这是启发式关系，不是机械公式。

## 2. 确定性分层

可以把投资判断拆成：
- 世界趋势确定性
- 产业确定性
- 公司胜率
- 财务确定性
- 估值安全边际
- 事件/政策不确定性

不要把“我很喜欢这家公司”当成确定性。

## 3. 相关性比持股数量更重要

持有 20 只股票并不一定分散。

如果它们都依赖：
- 同一个利率环境
- 同一个政策周期
- 同一个 AI 资本开支
- 同一个出口市场
- 同一个商品价格

本质上仍然是一个大仓位。

因此组合管理必须研究：

> **共同风险因子。**

## 4. 中美组合的意义

中美配置不是为了形式上的“五五开”，而是利用不同收益来源：

- 中国：产业跃迁、制造优势、国产替代、出海。
- 美国：全球平台、技术垄断、资本复利、利润集中。
- 全球：同一趋势的不同价值捕获节点。

## 5. 核心仓 / 机会仓

可以把组合分为：

### 核心仓
逻辑长期、确定性高、能够跨周期持有。

### 机会仓
来自产业周期、预期差、政策变化、阶段性错配。

不同类型不能用同一种持有纪律。

## 6. 单一标的仓位前的检查

必须回答：
- 最差情况是什么？
- 永久性亏损可能来自哪里？
- 需要多久验证？
- 如果错了，能否顺利退出？
- 与现有组合是否高度相关？
- 该逻辑已经被组合中的其他资产重复表达了吗？

## 7. 仓位调整原则

加仓应该来自：
- 事实验证增强
- 风险下降
- 价格下降而内在价值不变/上升

而不是单纯因为：
- 已经亏了很多
- 想降低成本
- 情绪不甘心

减仓应该来自：
- 估值过度透支
- 关键假设弱化
- 组合相关性过高
- 出现更优风险收益比

## 8. L4 输出

每笔投资必须记录：
- 初始仓位
- 最大允许仓位
- 风险因子
- 与组合其他资产的相关性
- 加仓条件
- 减仓条件
- 最坏情景
- 可接受最大永久损失

完成 L4 后进入 L5：执行。
