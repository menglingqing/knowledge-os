# 40 种英文字体与字形风格参考库

面向杂志、海报、AI 生图与网站设计的学习资料。根据用户提供的上下册及本次对话整理，保留字体名、用途、视觉特征提示词，并补充搭配方法。

## 如何使用

1. 先确定内容与气质，再选择主标题方向。
2. 为正文和信息层搭配清楚、稳定的字体；通常先使用两种字体。
3. 需要个人感时，再加入少量手写批注。
4. AI 生图使用下面的视觉描述；网站和正式排版需要实际加载字体。

这是一份创作参考，不是字体厂商的技术规格或授权目录。分类、情绪分组和适用场景是设计建议；具体效果取决于字体版本、字重、宽度和排版。本资料没有附带字体文件，也没有核实逐款授权。不要将提示词生成的近似效果当作真实字形样张。Biro Script 一项仅作为圆珠笔手写方向记录。

## 八种气质索引

- **时尚、精致、有张力**：Didot、Bodoni、PP Editorial New、Playfair Display、Lyon Display、Abril Display。
- **文学、经典、有书卷气**：Tiempos、Cormorant Garamond、Caslon、Garamond。
- **艺术、流动、有表现力**：Canela、Ogg、GT Super、Instrument Serif。
- **温暖、圆润、有复古感**：Fraunces、Recoleta、Circular。
- **理性、克制、秩序清楚**：Helvetica Neue、Neue Haas Grotesk、Graphik、Neue Montreal、Suisse International、Univers、Akzidenz Grotesk。
- **醒目、紧凑、有力量**：GT America、Founders Grotesk、DIN Condensed、Bebas Neue、Franklin Gothic Condensed。
- **几何、现代、轮廓鲜明**：Futura、Avenir、ITC Avant Garde Gothic。
- **手写、自由、有个人痕迹**：Biro Script / 圆珠笔手写方向、Sacramento、Caveat、Allura、Permanent Marker、Rock Salt、SignPainter、Mrs Saint Delafield。
