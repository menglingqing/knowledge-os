# 概念、克制与减法

本方法用于意图选择与画面评判，先于提示词组织。目标是让观众能感到一个明确关系，同时保留感受与故事的开放性。

<a id="concept-entropy"></a>
## 概念熵

“概念熵”是本次对话使用的工作比喻：**多个互相竞争的命题，让画面难以形成一致的理解方向。** 它不是信息论熵，不定义计算公式，也不是经过验证的美学指标。

要区分三种“多”：

| 类型 | 例子 | 是否必然分散概念 |
|---|---|---|
| 物件数量多 | 一片花海有许多花 | 不必然，可能重复同一关系 |
| 感官细节多 | 岩石纹理、冰裂纹、建筑雕饰 | 不必然，可强化同一世界 |
| 独立命题多 | 同时要求鲸鱼奇观、古堡悬疑、篝火团聚与极光神迹 | 容易争夺解释方向，应检查优先级 |

开放叙事也不等于概念熵高。人物是来继承还是告别可以不确定，但“有限的人面对巨大秩序”仍然清楚。概念可以集中，故事可以开放。

<a id="one-core-idea"></a>
## 一个核心创意

先写一句含有关系的命题，再选择元素。关系可以是尺度、时间、冷暖、归属或权力，不必是动作戏。

| 元素清单 | 核心命题示例 |
|---|---|
| 雪山、鲸鱼、海湾 | 巨大寂静里，生命短暂跃出水面 |
| 雪山、河流、火车 | 人类文明从持续存在的自然中经过 |
| 月亮、花、微光 | 地上的生命朝向一轮近乎梦境的巨大月亮 |
| 冰面、房屋、灯 | 寒冷辽阔的世界里，远处仍有一处暖意 |
| 人、王座、圣殿 | 有限的人面对超出个人尺度的秩序 |

“一个”指主导命题，不是只能出现一个对象、一个光点或一种感受。所有次级选择应支持、丰富或必要地限定它；不必把画面压成一句没有余味的标语。

<a id="restraint-subtraction"></a>
## 克制与减法

克制是主动分配注意力。减法是判断保留理由的办法，不是元素越少越好，也不是提示词越短越好。

逐个检查候选元素：它是在建立世界、提供尺度、留下事件证据、集中情绪，还是另起一个故事？然后做三种处理：

1. **保留**：删除后核心关系不成立，例如寒冷环境中的暖窗。
2. **弱化或合并**：功能必要，但对比、数量或叙事权重过大，例如多栋房子作为一个聚落保留。
3. **删除**：去掉后命题更清楚，空间和事件也没有受损，例如只为“更丰富”加入的第二组奇观。

删减同样可以作用于亮度、饱和度、清晰度、动作幅度和解释性文字。冰裂纹有很多细节，却在强化“冷”；把它们全部抹平可能反而损伤作品。

<a id="strong-relations"></a>
## 元素少但关系强

强关系让一个元素改变另一个元素的意义：小屋使山海显大，山海使小屋显得脆弱；寒冷使灯光珍贵，灯光使寒冷获得人的尺度；人物使秩序可感，秩序使站立成为“面对”。

至少回答两个问题：

- 关系的两端是什么，凭什么在画面里被看见？
- 拿走其中一端，哪一种意义会消失？

并列名词不自动构成关系。“人、城堡、月亮”可能只是清单；也可能通过明确的距离、方向、尺度与事件成立。不要只凭名词多少判断概念质量。

## 一次概念审查

1. 用一句话写当前命题，不使用“高级感、震撼、电影感”代替内容。
2. 列出使它成立的两到三个关键关系及可见证据。
3. 找到最抢注意、却不服务命题的选择，先删掉或弱化它。
4. 复看：世界是否仍可信，事件是否可辨，情绪是否更集中？
5. 若删除使画面贫乏或关系不成立，恢复必要证据；记录为何恢复。

这是服务于当前审美方向的工作法，不否定多线叙事、繁复装饰或密集群像。判断标准是任务意图是否清楚，而不是统一追求极简。

选定命题后，进入[如何转化为创作控制](creative-control.md)。自然与诗意两条方向见[自然美感](../principles/natural-beauty.md)，冷暖与权力关系见[尺度与存在](../principles/scale-and-presence.md)。
