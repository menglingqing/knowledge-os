# IP 视觉转译：保留身份，改变语言

IP 设计的核心不是“像不像原角色”，而是：

> **当原本的画风、服装、场景甚至物种都被替换后，角色是否仍然能被认出来。**

## 一、先抽取 Character DNA

每个角色优先保留 3–5 个不可替代的识别锚点：

- 发型／头部几何；
- 核心色；
- 标志服装结构；
- 身份道具；
- 身体比例；
- 性格姿态；
- 专属符号。

例如 Sailor Moon 的强锚点：
- 月牙／月相几何；
- 金色双丸子头；
- 红宝石；
- 金色额饰；
- 白手套。

这些是“身份骨架”，而不是必须原样复制的表面元素。

## 二、身份不等于外形

IP 转译可以分四层：

1. **Identity**：谁。
2. **Personality**：怎样的人。
3. **Ability / Narrative**：能做什么、代表什么。
4. **Visual Language**：用什么视觉系统讲。

真正高质量的转译，是前 3 层保持稳定，第 4 层大胆变化。

## 三、可复用转译算法

> 身份识别 → 核心视觉动词 → 几何压缩 → 材质统一 → 色彩编码 → 版式系统化

### 1. 身份识别
抽出 3–5 个最不可删除的特征。

### 2. 核心视觉动词
确定角色此张图的主势：旋、升、坠、扩、压、裂等。

### 3. 几何压缩
把角色从“写实对象”压缩为轮廓、体块、节奏、方向。

### 4. 材质统一
将不同来源元素转译到同一种媒介中，例如：
- Airbrush；
- Gradient Mesh；
- 旧杂志印刷；
- 树脂／玻璃／薄膜；
- Zine 复印噪点。

### 5. 色彩编码
角色代表色进入整个世界，而不是仅停留在衣服上。

### 6. 版式系统化
把角色变成一个可重复扩展的系列设计，而非一张孤立插画。

## 四、跨物种／错位转译

当角色动物化、灾难化、材质化时，可以使用：

> Character DNA → species re-encoding → facial dissonance → ability-as-disaster → scale shift → communication system

例如“拟人动物 × 昭和特摄灾害海报”：
- 发型 → 耳朵／毛发结构；
- 服装符号 → 斑纹／胸口标志；
- 性格 → 面部比例和表情；
- 技能 → 灾害类型；
- 角色代表色 → 天气／世界色；
- 身份危机 → 公共警报系统。

重点不是“兽化”，而是**重新分配角色信息**。

## 五、角色识别的“硬骨架 + 软外壳”

在 Soft Biomorphism、Gradient Mesh 等抽象系统中，最稳的方法是：

> **硬识别骨架 + 软色场包裹**

即：
- 核心轮廓必须明确；
- 内部体积可以柔化；
- 边缘可以扩散；
- 颜色可以雾化；
- 环境只保留低对比语义锚点。

这能避免角色完全滑向“漂亮但无身份”的抽象图形。

## 六、人格恒量

系列中可以改变：
- 景别；
- 材质；
- 场景；
- 版式；
- 风格。

但需要保持一个“人格恒量”。

例如 Tifa 的系列中：
- 近景负责情绪；
- 全身负责身份；
- 特写负责记忆；
- 凝视与克制始终不变。

统一不是同一滤镜，而是所有视觉选择回答同一命题。

## 七、IP 转译的失败模式

- 保留太多原角色表面细节，导致只是“换风格”。
- 抽象过度，失去核心识别锚点。
- 只保留代表色，人物性格消失。
- 系列统一靠同一滤镜，而没有共同概念。
- 每张图改变的模块过多，无法形成家族关系。

更稳定的系列法：

> 固定身份骨架与外壳系统，每张只更换 1–2 个关键视觉模块。
