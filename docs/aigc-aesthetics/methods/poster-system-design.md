# 海报视觉系统：从单张效果到系列语言

海报设计的核心不是不断添加元素，而是建立一套可扩展的视觉语法。

## 一、七个系统变量

可用以下框架检查一张海报：

> **Concept × Anchor × Scale × Weight × Contrast × Function × Medium**

- **Concept**：唯一核心命题。
- **Anchor**：第一视觉锚点。
- **Scale**：Macro / Meso / Micro 的比例差。
- **Weight**：面积、亮度、色彩、纹理的视觉重量。
- **Contrast**：被控制的反差。
- **Function**：每个元素在结构中承担什么任务。
- **Medium**：摄影、CG、印刷、纸张、喷枪等媒介统一。

## 二、先定义“观看方式”

设计海报前，不要先问“放什么”，先问：

- 观众第一眼看哪里？
- 第二眼如何移动？
- 画面是从远处成立，还是靠近后才成立？
- 主体是一个人、一个符号，还是一块景观？
- 文字是在解释，还是作为构图本体？

## 三、极端微距：局部即景观

一套稳定的可替换主体海报模板：

> 固定 DNA：构图、色场、层级、媒介  
> 开放变量：SUBJECT / DETAIL / WORD

核心机制：

> **局部即景观**

将眼睛、衣料、羽毛、皮肤、金属、装饰等局部极端放大，让观众同时感到：
- 它属于某个角色；
- 它又像一个无法判断尺度的巨大地貌。

视觉语言可包括：
- 9:16 竖版；
- 白边／单色场；
- 极端裁切；
- 巨型字与主体穿插；
- 微型信息；
- 摄影 × 印刷质感。

## 四、Soft Biomorphism 系统

适用于动物、人物、IP、植物等跨主体系列。

稳定 DNA：
- simplified contour；
- continuous curve；
- large color field；
- no-outline shaping；
- Airbrush Gradient；
- Gradient Mesh volume；
- narrow palette；
- 暖白高调背景；
- 低饱和主色 + 克制金属辅色。

方法：

> reality → recognition features → contour / mass / rhythm → Soft Geometry → Gradient Mesh → monochrome unification

重点不是“画得像”，而是保留：
- 不能删除的特征；
- 主运动曲线；
- 轮廓；
- 明度；
- 面积；
- 方向；
- 重量。

### 常见风险
- 滑回“漂亮角色插画”；
- 过度居中；
- 圆形构图重复；
- 每张只换主体和颜色。

改善方式：
- 非对称；
- 极端裁切；
- 双主体；
- 横幅；
- 嵌套；
- 大小尺度切换。

## 五、Brutalist Editorial Character Poster

适用于高识别角色近景海报。

核心：
- oversized typography；
- extreme crop；
- asymmetric grid；
- 黑／暖灰白／单一高饱和强调色；
- 粗黑几何块；
- 极细水平／垂直线；
- 大留白；
- 局部刮痕、喷溅、印刷破坏；
- 巨型字与人物前后穿插。

关键不是“粗野元素堆砌”，而是：
1. 人物脸部作为情绪锚点；
2. 巨型字体成为第二构图主体；
3. 小字承担信息密度；
4. 几何块负责配重；
5. 强调色只承担身份／注意力编码。

## 六、跨风格融合：给每个系统分配职能

跨风格不是把风格词串起来，而是建立“分工”。

示例：

- 90s Editorial：世界／外壳；
- Soft Biomorphism：异常身体；
- Orthopedic Exoskeleton：结构约束；
- Swiss Grid：秩序；
- Psychedelic Symbols：精神层；
- Ink：过渡／污染；
- Architecture：环境。

由此可形成：

> **stable shell × abnormal subject × structural constraint × spiritual symbols**

更深一层的叙事关系是：

> 正常编辑世界 → 身体发生异常 → 文明试图重新控制它

因此不同视觉系统并不是并列装饰，而是共同讲一个事件。

## 七、Punk Zine / Underground Comix

适合荒诞、动作、失控、反精致表达。

核心手段：
- Deliberate Deskilling；
- Ratty Contour Line；
- Flat Spot Color；
- Rubber-Hose Distortion；
- Simultaneous Narrative；
- Extreme Scale Hierarchy；
- 多动作同时发生；
- 复印、错版、脏纸、手写信息。

这里的关键是让“失控感”成为结构，而非简单加脏纹理。

## 八、Dreamcore / High-exposure Solitude

核心不是夜景，也不是 Cosplay。

公式：

> **Tiny Subject × Vast Negative Space**

手段：
- 主体压到底部；
- 收拢／抱膝／蜷缩；
- 高曝光吃掉细节；
- 只保留轮廓与代表色；
- 上方大面积黑场；
- 大量失焦光点；
- 地面少量反射。

视觉重量由“亮度”取代“面积”。

其成立原因是尺度反差：
> 很小的生命信号，对着几乎吞没一切的空间。

系列变化应优先改变空间关系，而不是只换角色与颜色。

## 九、系列设计：母命题先于风格统一

推荐流程：

> 母命题 → 视觉动词 → 识别骨架 → 形态抽象 → 环境同源 → 色彩编码 → 版式统一

例如一组月相人格海报可以固定：
- Pearl / Ruby / Gold / Satin 材质家族；
- 珍珠白、月灰、香槟金、夜黑；
- 少量红色；
- 细衬线、宽字距。

但每张月相不是只改标题，而是让“月”变成：
- 构图；
- 光；
- 轮廓；
- 负空间；
- 几何遮挡；
- 情绪。

## 十、海报系统的最终判断

一套系统是否成熟，可以问：

> 换掉主体后，这套视觉系统还成立吗？  
> 换掉风格名后，我还能解释它为什么成立吗？  
> 每个元素是否承担明确结构功能？  
> 系列中的变化来自叙事与空间，还是只来自颜色？
