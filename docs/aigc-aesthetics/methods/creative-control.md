# 如何转化为创作控制

本页连接上游审美认知与下游视觉生成。下表是待验证的转译建议，不是已测试的模型技巧；先决定表达，再选择需要控制的变量。

## 从意图到可见关系

| 上游意图 | 需要看见的关系 | 可尝试的控制 | 复看问题 |
|---|---|---|---|
| 世界本来就在这里 | 环境有延伸，事件属于其中 | 连续地貌、接触痕迹、日常行为、随距离衰减的细节 | 拿走事件，世界仍可信吗？ |
| Small Subject, Big World | 世界有视觉重量，小主体仍可辨 | 调整主体相对尺度、机位与留给环境的空间 | 主体缩小后，行为还读得出来吗？ |
| 极小人类信号 | 环境与一个可识别的人类痕迹关联 | 保留一处灯光、一个聚落或一次经过 | 信号使环境更可感，还是变成广告主角？ |
| 冷世界／暖房子 | 大范围寒冷与集中暖意 | 暖色范围、局部对比、距离与微弱反射 | 情绪集中了吗，暖光是否过度占据画面？ |
| 诗意提纯的自然 | 一种主导幻想关系 | 强化一个尺度偏离，统一色域，让其他效果支持它 | 是同一个梦境，还是多个奇观争夺注意？ |
| 人在秩序面前 | 人、权力结构、建筑的感知尺度链 | 透视、遮挡、纵向延伸、静止姿态与中轴关系 | 不补背景故事，也能感到“面对”吗？ |
| 克制与低概念竞争 | 次级选择服从主命题 | 删除、弱化、合并；一次调整一个关键变量 | 核心更清楚了吗，必要证据是否被误删？ |

## 进入视觉生成执行

确定命题与关键关系后，可引用[七层架构拆解法](../../image-prompt-engineering/methodology/seven-layer-architecture.md)检查概念、主体、空间、构图、光影、材质与色彩是否一致。七层不反过来决定本模块的审美分类，也无需把每次品鉴重写成七层。

按当前命题选择具体手段。例如，中轴对称有助于圣殿仪式感；不应机械套用其他案例中的“破对称”。同样，诗意花海可采用幻想发光规则，不能套用写实自然的所有限制。

提示词组织可继续引用[视觉导演方法](../../image-prompt-engineering/experiments/huanmo-visual-direction-v1.1.md)、[迭代手册](../../image-prompt-engineering/methodology/iteration-playbook.md)与[模型适配](../../image-prompt-engineering/methodology/model-adaptation.md)。不在这里复制会随工具变化的语法规则。

## 示例：一处暖意的创作简报

以下为本次整理新写的示例，未生成验证，亦非参考图的原始提示词。

> **命题**：寒冷辽阔的世界里，远处仍有一处暖意。
>
> **关键关系**：近处深冷冰面与远处暖窗形成距离；冷色环境拥有主要空间，暖光集中。
>
> **可见证据**：冰裂纹、远山、屋内光与冰上的微弱暖色反射。
>
> **取舍**：保留支持寒冷和距离的纹理；不为丰富画面另加极光、篝火或人物剧情。
>
> **首轮检查**：暖窗能否辨认，环境是否仍辽阔，是否出现多个竞争的暖色中心？

这份简报保留意图和验收问题，再交给所选工具的执行框架。无需提前虚构模型、种子或参数。

## 对照记录与知识回流

先记录基线，再只修改一项：例如在保持其余条件尽量一致时缩小主体，或移除一个竞争的奇观。固定种子等条件仅在工具支持时使用；同时记录随机差异与无法控制的条件，不把一次更好的结果当作因果证明。

每次实验保留：

| 字段 | 应记录什么 |
|---|---|
| 任务与命题 | 要表达什么，引用哪条原则 |
| 输入与条件 | 完整提示词、参考资源、工具／模型版本、可用参数 |
| 基线与变体 | 输出文件或稳定链接；唯一计划改动及其他实际差异 |
| 评价 | 世界可信、事件可读、情绪集中、关系成立各自的依据 |
| 结论与边界 | 有改善／无改善／无法判断；不适用情境和反例 |
| 回流 | 新增案例，修订假设，必要时提出晋升建议 |

把结果加入 `cases/`，更新相关原则的 `evidence` 并写入[认知日志](../ledger/learning-log.md)。复盘支持的是具体假设，不是整套审美自动获得验证。独立案例数量与晋升裁决沿用[维护约定](../README.md#维护与引用约定)。
