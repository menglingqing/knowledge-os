# 传统文化海报系列设计系统 v0.1：从东方神韵到当代视觉语言

> 研究命题：如何让传统文化海报保有东方韵味，同时形成有辨识度的当代设计语言？
>
> 定位：**海报系列设计系统的阶段性研究框架**，不是已经验证的通用风格公式。仅以《北京·立冬》一次项目内的初创与字体实验为证据，状态保持 experimental。

## 1. 认知定位：不是「古风元素 × 现代排版」

传统文化的视觉价值并不等于瓦檐、汉字、篆印、朱红、宣纸等符号相加；当代性也不等于把传统元素摆进网格、叠加大号字体。真正需要回答：

1. **文化内核**：这张作品要传递哪种时间观、生活感、精神或情绪？
2. **可见叙事**：观者能通过哪个具体事件感知它，而不只是读懂标题？
3. **视觉转译**：传统审美的哪些关系（秩序、节奏、虚实、材质、尺度）被转换成当前的设计结构？
4. **原创性**：除传统符号之外，是否形成这套作品独有、可解释的视觉语法？

阶段性假设：**保留神韵，重构关系，而不是复刻表象。** 其效果必须依靠不同主题的独立作品验证，不能仅凭一句概念确立。

## 2. 从单张到系列：稳定 DNA 与可变叙事

系列的统一应来自**视觉语法**，不是每张复制相同画面、更换城市名称或节气标题。

| 设计层 | 稳定 DNA（系列识别） | 变化轴（每张的独特性） |
| --- | --- | --- |
| 母命题 | 时间与生活的关系、文化温度 | 季节情绪、城市记忆、人的处境 |
| 叙事锚点 | 以可感知的生活细节承担文化意义 | 地方日常动作、器物、人物之间的关系 |
| 构图语法 | 大势、观看顺序、字图职能、留白逻辑 | 景别、主次、空间路径、视觉重心 |
| 字体系统 | 标题/信息/注释的角色与字形原则 | 主标题的结构化定制、字间关系 |
| 色彩系统 | 主色/纸色/文字色的职责与关系 | 每个节气或城市可定义差异化色彩编码 |
| 媒介逻辑 | 字、图、纸张具有自洽的制作或印刷逻辑 | 木刻、套印、拓印、实拍或混合媒介，但要解释为什么 |
| 标记与信息 | 日期/地名/节气/祝语/印记的级配规范 | 具体内容、节气知识、地域线索 |

**警惕：**不能为了系列统一，让 24 张作品成为同一个屋顶、同一印章、同一构图的简单换色。统一是语法，变化应来自叙事与空间。

## 3. 一套可执行的设计问题顺序

### 3.1 先明确文化命题，再选择文化符号

用一句话定义「这张作品到底关于什么」，例如《北京·立冬》的候选命题是「寒意初至，城市旧巷仍有微火与归人」。避免把「东方、国风、高级、禅意」当作命题本身。

### 3.2 从抽象概念找到生活证据

优先搜索可见的**行为／物／空间**三者关系。

《北京·立冬》：冬的时间感（概念）→ 胡同（空间）→ 烤薯炉的一炉微火（器物和事件）→ 归家人影（人的关系）。这是一种可讨论的叙事链，不要求每张海报都出现人物或摊位。

### 3.3 把意境翻译成版式关系

不只问「放什么」，还要问：
- 第一眼看什么：地景、主字，还是一块留白？
- 观看动线如何从图像过渡到文字？
- 远看是否成立、近看是否有文化细节？
- 字体是信息标注、视觉锚点，还是构图主体？
- 留白是被动空区，还是承载季节感、呼吸感与节奏？

### 3.4 先设计字形，再设计旧化材质

必须区分：
- **字形结构**：骨架、横竖粗细、笔势、收笔、比例、重心、字距、两个字的性格统一；
- **材质表现**：磨损、纸张吸墨、套印偏差、颗粒、刀刻或压印痕。

判断字体方向差异时，**先在干净单色、同字号、同字框中比较结构**；待结构成立后，再用同一套材质参数叠加观察。不要把「字体磨损更多」误判为「字体设计更新」。

字体与图景应满足情绪一致、视觉重量可控、材质因果一致三条条件；但不排除有目的的冲突，冲突必须能够解释其叙事职能。

### 3.5 媒介一致：纸、画、字共享物理逻辑

版画场景若呈现明显印痕，而巨大标题像干净的数字字形，可能出现视觉脱节；可通过笔画边缘、压印程度和墨色密度调节。但**媒介统一不等于所有元素都要做旧**，信息小字仍须清晰可读。

### 3.6 锁定稳定部分，只实验一项真正的变量

当构图、色彩和叙事已获认可，优先锁定图层和位置。若问题是字体，先做字体样张（同字同字框）；若问题是图文关系，才进入全海报试排。

单变量对照最少要记录：研究问题、冻结项、变化项、评价尺度、观察结果、失败原因、下一步。完整生图多次抽样不能自动当作独立验证。

## 4. 提议中的系列制作流程（待验证）

1. **文化校准**：核验节气日期、地方线索、引用语与文化指代；主观诗意与可核验事实分开。
2. **母命题**：确定系列精神与单张命题的关联。
3. **叙事锚**：选出最具可见性的生活事件；景物、人物、器物有明确职责。
4. **设计语法**：建立大势、留白、视觉重量、信息层级与观察路径。
5. **字形原型**：单独评估中文主标题的结构差异，再决定拉丁文字与信息层配对。
6. **媒介落地**：定义图、字、背景的材质机制，校验可读性。
7. **小批量对照**：尽量保持一致的参考和构图，比较真正被操纵的变量。
8. **系列迁移**：选择另一城市／节气测试 DNA 是否仍有效，同时要求新的叙事不能成为装饰替换。
9. **归档与迭代**：成功条件、失败条件、未验证问题分别记录；达到知识治理要求后再申请晋升。

## 5. 审美评估：至少区分三层

- **基础完成度**：文字正确、可读、构图平衡、层级有序，色彩与媒介关系不冲突。
- **叙事与文化性**：不读题也有生活与季节线索；符号有必要性而非装饰性；地域与时间细节准确。
- **设计原创性**：字形结构有独立设计、图文关系出乎意料但仍合理；系列变化来自概念和叙事，不是模板换皮。

「协调」「成熟」「漂亮」并不能直接推出「原创」「当代」。当代性也不等于一定要用极端字体或冲击性构图。

## 6. 《北京·立冬》的证据与限制

证据详见[案例复盘](../cases/2026-11-08-beijing-lidong-poster-typography-series.md)。

- 初创 9 幅：用户认可整体排版方向，但指出字体还需打磨。
- 字体 3 幅对照：预期比较「古籍刻宋 / 现代高对比宋 / 手工雕版宋」；实际生成更偏向同骨架的清洁程度和旧化程度变化。
- 用户确认更深问题：作品协调、完成度不错，但仍缺少更鲜明的当代设计语言。

**证据边界**：这是同一项目的连续迭代，不是三个独立成功案例；还没有真正完成字体结构层面的严格对照，也没有跨题材的系列可迁移性验证。不得把当前框架标注为 validated。

## 7. 下一阶段的三项研究

- **字体独立实验**：在同字框中设计真正不同的「立冬」字形（古籍刻宋 / 当代东方 / 碑刻古拙），先定骨架，再合成既有海报。
- **跨节气验证**：在同一系列语法下另做一幅不同节气，测试重复的是关系还是模板。
- **传统／当代的可说明性**：分别记录每张作品继承了什么传统审美关系、引入了什么当代结构，以及两者为什么互相需要。
