# 信号损失肖像：从 Glitch Effect 到 Data Corruption

本方法用于创作和判断一类“人物仍然存在，但系统已经无法完整描述人物”的数字解构肖像。它借用 Glitch Art、实验性编辑人像、Digital Deconstruction 与 Analog Decay 的视觉语言，但目标不是制造科技感，而是建立**肉身连续性与数据断裂性之间的冲突**。

核心命题：

> **Human continuity vs Data discontinuity**
>
> 人的连续性 vs 数据的断裂性。

<a id="definition"></a>
## 一、风格定位

可使用的专业描述包括：

- **Glitch Portraiture**：故障肖像；
- **Digital Deconstruction Portraiture**：数字解构肖像；
- **Data Corruption Portraiture**：数据损坏肖像；
- **Experimental Editorial Portrait**：实验性编辑人像。

“故障风”只是形式入口。如果画面只是完整人像上叠加黑条、扫描线或 RGB 偏移，仍属于 **Portrait + Glitch**；更成熟的目标是：

> **Portrait becoming Glitch**
>
> 故障不在人物上面，人物自身正在发生信息损坏。

<a id="core-metaphor"></a>
## 二、核心隐喻：系统无法完整读取人

这类画面的创作灵感可以压缩为一句话：

> **一个真实的人，正在被一个不真实的系统读取。**

可扩展的母题包括身份损坏、记忆缺失、信息失真、错误识别、部分删除、数字身份与肉身之间的偏差。

因此，视觉效果必须回答一个因果问题：**为什么这个地方发生故障？它在表达何种信息损失？**

随机增加 glitch 数量不能替代叙事关系。

<a id="recognizable-incomplete"></a>
## 三、可辨认，但不完整

故障肖像需要维持一个关键阈值：人物必须仍可辨认，同时不能被完整读取。

有效做法：

- 保留一只完整眼睛作为情绪锚点；
- 另一只眼睛只留下部分虹膜、眼睑或位移残片；
- 鼻梁、嘴角、轮廓保留足够信息供观众补全；
- 让缺失发生在身份感最强的区域，而不是平均覆盖全脸。

工作判断：

> **可辨识性负责吸引，缺失性负责停留。**

完全遮掉人物会滑向纯抽象；人物过于完整则容易退回“美女写真 + 故障滤镜”。

<a id="vertical-horizontal"></a>
## 四、构图语法：Vertical Human / Horizontal System

一种稳定而有效的结构是：

- 人物以垂直轴建立身体与身份的连续性；
- 故障以横向扫描、位移、截断建立系统性的破坏。

即：

> **Vertical human / Horizontal system**

这不是必须遵守的形式公式，而是一种具有明确概念因果的构图语法：人的完整性纵向成立，系统以横向力量不断切断它。

<a id="damage-scale"></a>
## 五、故障必须有尺度层级

避免所有 glitch 都是同样宽度、同样密度的矩形块。至少建立三种尺度：

1. **大尺度结构缺失**：真正吞掉一只眼睛、半段轮廓或大面积身份信息；
2. **中尺度结构位移**：眼睛、鼻梁、发丝、脸部边界发生局部水平错位；
3. **微尺度噪声**：扫描线、压缩伪影、字符残留、微像素、打印纹理。

大尺度负责构图，中尺度负责“图像真的坏了”的可信度，微尺度负责媒介质感。

如果只有大黑块，容易像 Photoshop 遮罩；只有微噪声，则容易像滤镜。

<a id="loss-gradient"></a>
## 六、信息损失梯度

不要让全画面均匀故障。建立清晰的状态变化：

**Corrupted → Transitional → Human**

即：

**故障区 → 转化区 → 肉身区**

边界不宜成为简单的垂直渐变。更自然的方式是让损坏出现“侵入—退缩—再侵入”：

- 额头故障深入中线；
- 眼部肉身重新夺回；
- 面颊再次破碎；
- 嘴部恢复；
- 颈肩重新发生严重数据化。

这样故障边界更像潮汐、腐蚀或读取失败，而不是半张脸蒙版。

<a id="corruption-types"></a>
## 七、四种信息错误

只使用“删除”会让语言单一。可把故障拆成四类：

| 错误类型 | 视觉行为 | 表达含义 |
|---|---|---|
| 缺失 Delete | 黑块、透明、局部消失 | 信息不存在 |
| 位移 Offset | 眼、鼻、轮廓水平错位 | 系统读取错误 |
| 重复 Echo | 局部复制、ghost image、frame duplication | 系统重复读取 |
| 转化 Transform | 发丝或轮廓逐渐变扫描线/数据碎片 | 肉身正在变成数据 |

组合使用时，应由概念决定主次，而不是四类平均堆叠。

<a id="analog-decay"></a>
## 八、数字错误 + 物理衰败

纯数字 glitch 容易落入常见赛博美术。加入克制的 Analog Decay，可以让作品更接近实验平面设计：

- aged paper；
- xerox texture；
- photocopy artifact；
- toner dust；
- print noise；
- misregistration；
- scratched paper；
- halftone residue。

关键不是做“复古滤镜”，而是让画面同时存在两种失败：

> **Digital error + Analog decay**

数字系统出错，承载它的物理介质也在老化。

<a id="human-reality"></a>
## 九、真实肉身是故障成立的前提

人物越像标准 AI Beauty Portrait，故障越容易沦为装饰。

应适度保留：

- 眼下真实阴影；
- 鼻翼轻微泛红；
- 毛孔与肤色不均；
- 唇纹；
- 发丝随机性；
- 面部轻微非对称。

目标不是粗糙，而是把 **AI perfect beauty** 降到 **real human beauty**。

> **越真实的肉身，被破坏时越有“损失感”。**

<a id="color-system"></a>
## 十、色彩：异常色必须稀少

推荐基础体系：

- ivory / warm white；
- black；
- gray；
- pale skin tone。

异常色控制在极小比例，可使用 faded gold、dirty ochre 或微量 RGB 数据残色。

工作原则：

> **95% 无彩 / 低彩 + 5% 异常色。**

避免大面积红蓝霓虹、紫色科技光与强 RGB Split，否则容易滑向普通 Cyberpunk Glitch，削弱“人被错误读取”的主题。

<a id="anti-patterns"></a>
## 十一、常见失败模式

### 1. Portrait + Effect
底层是一张完整商业美妆人像，上面覆盖几条黑线。故障可随时删除，主体不受影响。

### 2. 规则矩形过多
中型黑块尺寸相似、边缘整齐，像手工遮罩，不像数据损坏。

### 3. 两只眼睛都完整
身份锚点过强，人物仍被轻易完整读取。

### 4. 故障平均分布
没有损坏梯度、转化区和视觉因果，只剩纹理。

### 5. 赛博朋克替代概念
靠霓虹、RGB 和未来字体制造“高级感”，但没有身份、记忆或读取失败的问题。

### 6. 美妆感压过故障
皮肤、眼线、对称和商业修图过于完美，最终仍像模特写真。

<a id="evaluation"></a>
## 十二、一次快速审查

完成一张图后，检查：

1. 去掉所有 glitch 后，它是否只是普通漂亮人像？
2. 故障是覆盖人物，还是人物自身真的发生结构错误？
3. 是否至少存在一个大结构缺失、一个中尺度错位和一组微噪声？
4. 哪一部分是完整锚点，哪一部分要求观众主动补全？
5. 是否能读到故障区、转化区、肉身区？
6. 异常颜色是否在抢夺概念？
7. 肉身是否足够真实，让“损失”成立？
8. 即使删掉文案，作品的“读取失败”是否仍然存在？

## 十三、系列化方向

“信号损失肖像”可以作为系列母系统，而不是单张风格：

- **LOSS OF SIGNAL — FACE**
- **LOSS OF SIGNAL — MEMORY**
- **LOSS OF SIGNAL — IDENTITY**
- **LOSS OF SIGNAL — BODY**

统一的是视觉语法：真实肉身、信息断裂、编辑构图、模拟介质衰败；变化的是每张作品具体“失去什么”。

因此可用一个公式概括：

> **真实人像 × 信息断裂 × 编辑构图 × 模拟介质衰败**

本方法属于审美与视觉决策层。进入具体生图时，再把选定命题映射到既有七层视觉生成架构；七层架构用于执行，不用于替代这里的概念判断。
