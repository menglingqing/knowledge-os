# 七层视觉生成架构 v2.0：概念驱动的创作、品鉴与证据闭环

**知识标记：SS 级待验证方法论。** SS 表示本次讨论指定的重点研究优先级，不代表已验证、普适性或效果评级。遵循“先吸收后优化”：先准确保存原始主张，再应用、记录反例，最后依据证据修订。

来源：用户在 ChatGPT「主agent」中的概念与七层架构讨论，以及本次明确的沉淀要求。当前只有讨论材料，没有新增图片复核、独立生成实验或用户盲评，故 evidence 为空。下文例子均为说明性假设。

## 1. 核心主张：概念决定表达方向，关系组织表达力量

概念是作品希望观众感受到或理解的核心命题，是视觉创作的组织中心。主体、环境、构图、光影、材质、色彩共同将概念变成可感知的经验。

概念不等于风格标签或元素清单。“赛博、电影感、宏大”没有说明作品表达什么；“一个人的存在正在被庞大的数字系统吞没”则给出了个体与系统之间的关系。

工作法：先写一句关系命题，再列两到三个必要的视觉证据，并明确哪些表达可以弱化。概念可以集中，叙事仍可开放；不要强迫每幅作品只有唯一解释。

## 2. 七层职责与边界

| 层级 | 核心问题 | 可观察、可调的表达维度 |
|---|---|---|
| L1 概念 | 表达什么，希望观众感受到什么？ | 核心概念、简洁情绪调性、表达方向；品鉴时属于待证实的解释 |
| L2 主体 | 谁或什么承载表达，主次如何？ | 主体类型、主次关系、形态特征、状态动态、主体互动；支持非人物主体与关系主体 |
| L3 环境（含空间关系） | 表达发生在什么世界，主体如何处于其中？ | 场景、尺度、距离、纵深、遮挡、包围、人与环境的关系 |
| L4 构图 | 这些关系如何在画框中被组织和看见？ | 视角与景别组合、焦距、透视、画幅、裁切、位置、留白、视觉重量、动线与观看路径 |
| L5 光影 | 哪些部分被显现或隐藏？ | 光源因果、明暗分布、衰减、对比、焦点与情绪 |
| L6 材质 | 世界通过什么质感成立？ | 表面纹理、光学响应、触感、媒介痕迹、真实感 |
| L7 色彩 | 色彩如何参与关系表达？ | 明度、饱和度、冷暖、色彩比例、过渡与注意力 |

L3 关注场景内部的空间关系，L4 关注这些关系如何经视点与画框呈现。同一现象可涉及多层：人物很小可能由真实尺度、距离与构图占比共同造成，不必强行归入唯一层。

与[既有七层架构](../../image-prompt-engineering/methodology/seven-layer-architecture.md)衔接：原文 L3 为“空间层”，本方法称“环境层（含空间关系）”，保留原有纵深、遮挡和尺度职责。原文是案例中的生成执行框架；本文将其扩展到概念驱动的视觉品鉴，这一扩展仍需单独验证，也不替代整个审美知识库的分类体系。

七层是分析与设计维度，不是固定流水线、模型注意力顺序或完整美学定律。创作可往返修订，提示词应按表达重要性组织。

## 3. 层间四种关系

| 关系 | 判断问题 | 假设示例 |
|---|---|---|
| 支撑 | 哪一层为另一层提供成立条件？ | 广阔环境为人物的渺小提供尺度参照 |
| 协同 | 哪些层共同强化同一表达？ | 环境包围、构图挤压与人物局部隐没共同强化被吞没感 |
| 对立 | 冲突是否产生必要的意义？ | 温暖的人类信号与冰冷系统形成生命和系统的张力 |
| 取舍 | 为主导概念，什么应弱化？ | 减少霓虹光效，避免数字压迫变成视觉奇观 |

这些关系可以同时存在。对立不等于错误，统一也不等于有效。判断依据是关系是否使目标表达更清晰、更有力量，而不是各层是否分别“好看”。

可复用句式：
> 因为要表达【概念】，让【层 A 的可见选择】与【层 B 的可见选择】形成【关系】，预期产生【感受】；用【观察或对照】验证。

例如：因要表达个体被系统吞没，让 L2 人物的克制姿态、L3 巨型空间的包围和 L4 边缘位置形成协同；验证观众是否读到力量差异，而非只读到一座漂亮城市。

## 4. 自上而下创作：意图 → 关系 → 选择 → 结果

1. **定义意图**：一句概念、目标观众、用途、约束和不希望产生的误读。
2. **定义关键关系**：选两到三个承载概念的关系，注明支撑、协同、对立或取舍。
3. **翻译七层**：各层写必要的可见选择及其理由，避免所有层争抢注意力。
4. **形成生成控制**：将关键关系写进提示词或制作方案；文字描述不能替代结果验证。
5. **复核实际结果**：检查图像里的证据、整体体验和偏离；成功调用工具不等于表达成功。
6. **针对原因修改**：优先调整最影响概念的一项变量，记录修改前后，再判断是否保留。

概念本身也可被结果启发和修订，但必须记录意图变化，避免事后把任何输出解释成成功。

## 5. 自下而上品鉴：观察 → 关系 → 概念假设 → 验证

先保存直观感受，再记录图中真正看见的事实；之后组织层间关系，提出概念解释。这里“自下而上”指从视觉证据推导意义，并非机械地从 L7 倒数到 L1。

1. **观察**：人物位置、尺寸、姿态、场景距离、亮暗、纹理和色彩是什么？
2. **关系**：哪些选择互相支撑或冲突？观看路径和注意力如何形成？
3. **假设**：提出一个主解释，必要时保留替代解释。
4. **验证**：为解释列支持证据、反证和无法确定之处。
5. **评价**：区分表达是否成立、自己是否喜欢、是否符合任务与观众。
6. **迁移**：只迁移已说明适用条件的关系，不把“冷色＝孤独”等联想当成通用规则。

“看见一个人”是观察；“他很孤独”是解释；“作者意图表达孤独”需要作者材料或额外证据。未知作者意图时应说“可以读作”，不能声称已经理解全部信息。

## 6. 概念假设必须受视觉证据约束

| 记录项 | 填写要求 |
|---|---|
| 概念假设 | 一句话，可被支持或削弱 |
| 可见证据 | 指向画面位置和具体特征，注明涉及层级 |
| 表达机制 | 说明特征如何通过关系产生体验 |
| 反证与替代解释 | 哪些细节不符合？是否也能解释成自由、宁静或壮阔？ |
| 验证动作 | 遮掉焦点、改变一项对比或做并列版本比较 |
| 结论边界 | 观察事实、合理解释与尚未验证的因果分别写清 |

删除测试与单变量对照有助于诊断，但不能单独证明普适因果；生成结果同时变化时应注明混杂因素。观众认同、作者陈述、生成有效性是不同证据，不能互相替代。

## 7. 媒介适用范围

**完整七层仅用于视觉生成与视觉品鉴。** 可以分析视频单帧或网站视觉界面，但不能据此完成整个视频或网站的评价。

上位的“概念驱动原则”可迁移到其他媒介；迁移时必须重建执行维度：
- 视频：时间结构、镜头关系、运动、节奏、声音、叙事和时间因果。
- 网站：用户任务、内容、信息架构、操作路径、交互反馈、可访问性和视觉层级。

例如“平静、可信赖”的网站，除了低刺激的视觉，还需清晰操作与稳定反馈。视觉上的平静不能替代使用体验上的可信赖。

## 8. 先吸收后优化与验证计划

1. **吸收**：按本文保留定义、边界和讨论来源，避免先改成另一套熟悉框架。
2. **应用**：在独立任务中同时做创作和品鉴，记录输入、输出、证据、失败与用户判断。
3. **优化**：用反例决定是修改机制、限定场景还是放弃假设，保留原版本可追溯性。
4. **晋升**：依照[知识治理](../../image-prompt-engineering/governance.md)，至少三个独立案例只是必要条件；还需可追溯证据、无足以推翻的明显反例，并由人类批准。

建议验证三类独立任务：尺度关系图片、通过对立表达概念的图片、存在多个合理解释的图片。分别观察：框架是否提升意图表达；层间分析是否比元素清单更有用；证据检查是否减少过度阐释。说明性例子、同一项目连续迭代和多个助手赞同都不能自动算作独立验证。

## 10. 与 Agent 评估的连接

本方法可作为视觉 Agent 的领域判断输入：概念提供目标，七层帮助定位可调变量，层间关系解释表达机制，证据检查约束评价，用户反馈校准偏好。

“审美判断作为评估体系”仍需区分任务符合度、概念表达、视觉完成度和个人偏好。模型给自己的结果写出动人解释，不构成验证；必须查看实际输出，并结合独立评审或用户反馈。技术执行闭环负责行动可靠，价值判断闭环负责行动是否值得保留，两者通过证据和纠正动作连接。

## 11. v2.0 升级记录（2026-10-13）

本节依据 ChatGPT「提示词冲突分析」的用户提供预览及本次明确的升级要点整理；未取得原聊天完整正文，不作为逐字转录。七层顺序保持 **L1 概念 → L2 主体 → L3 环境 → L4 构图 → L5 光影 → L6 材质 → L7 色彩**。架构职责已确认，新增生成控制机制、技法与效果假设仍待案例验证；保留本文 experimental 与空 evidence，不把讨论认可视为效果验证。

### 11.1 概念与情绪

概念是作品的组织中心，其余六层是实现表达的视觉手段，不要求逐项填满。L1 使用“核心概念＋情绪调性＋表达方向”，情绪词保持简洁，如“宁静、孤寂”；将其翻译成空间、构图、光色等可见选择。情绪调性不等于人物表情，也不要求各层一致，必要的反差可形成张力。

### 11.2 主体、辅助元素与视觉焦点

主体可以是人物、动物、植物、建筑、器物或自然现象；两人互动的关系也可成为核心描绘对象。物体类别、画面体积与主体身份不构成固定对应。

L2 定义叙事主体和主次，L4 组织视觉焦点与观看顺序，L5/L7 参与注意力分配。叙事主体与第一视觉焦点可以不同，但观看路径必须服务概念。辅助元素可承担构图、叙事或尺度参照功能。

- 少女为主体：建筑是环境；通过位置、局部光线和适度景深突出少女，同时保留建筑的尺度证据。
- 建筑为主体：少女是尺度参照和局部视觉锚点；服装颜色或入口位置可引导观看，但不能无意取代建筑的表达。
- “状态动态”适用于非生命对象：花朵盛开或摇曳、建筑静止或崩塌、海浪翻涌、茶壶倾倒；静止物体无需强加行为。

以上是说明性方案，不是已完成生成案例。

### 11.3 L3 空间关系与 L4 观看方式

L3 建立场景世界、前中后景、距离、尺度、纵深、遮挡与主体—环境关系；L4 决定机位、视角、景别、焦距、透视、画幅、裁切、比例、重心与留白。同一视觉结果可由两层共同造成。

视角与景别应组合选择：低机位仰视 × 远景可强调建筑体量；平视 × 中景可强调人物与环境联系；俯视 × 全景可展示空间分布；近景／特写可强调器物或花朵的局部形态。它们是可选策略，不是固定情绪映射。焦距、距离、裁切、景深与细节可读性必须相容，单图执行时只保留一套观看方案。

### 11.4 协同、竞争与冲突

沿用第 3 节的支撑、协同、对立与取舍，并补充执行诊断：

| 类型 | 识别方式 | 处理 |
|---|---|---|
| 协同 | 多层共同强化概念 | 如空间包围、边缘构图、局部阴影共同表现个体渺小 |
| 竞争 | 多个元素同时争夺亮度、色彩、面积或细节注意力 | 指定主导对象，降低辅助元素的对比、锐度、数量或光效 |
| 表达性对立 | 冷暖、尺度或状态差异有明确表达目的 | 保留差异，明确双方职责与观看顺序 |
| 指令冲突 | 同一对象、同一范围要求互不兼容的结果 | 如全域清晰与背景强虚化同时要求；缩小作用范围或选择一项 |

不能把所有反差当错误，也不能用“艺术张力”掩盖不可执行的指令。先检查作用对象、空间范围和观看机制，再判断是否冲突。

### 11.5 约束优先级与执行

每张图先写三档约束：**必须保留、优先实现、可牺牲**。用户明确要求属于必须保留；无法同时满足时记录冲突，不静默改写。

在不违反明确要求的前提下，默认先保护核心概念及其可见证据，再保护主体主次与关键空间关系，其次协调构图／光影／色彩，最后取舍装饰光效与微小材质细节。此顺序是创作决策规则，不是模型内部执行顺序，也不是 L5 永远高于 L6。

冲突记录：冲突项 → 作用对象／范围 → 优先项及理由 → 调整项 → 输出中的验收证据。提示词按任务重要性组织，层级编号保持不变。词序、文字预算和模型支持的权重语法只是控制手段；字数占比不等于可保证的视觉权重。

### 11.6 技法库与验证入口

风格、光效、情绪和真实感作为跨层技法库，按概念需要调用，不新增第八层。见[技法库与案例验证计划](../../image-prompt-engineering/experiments/seven-layer-v2-techniques-and-validation.md)。每条记录目的、作用层、可见机制、适用条件、冲突风险与证据状态；先选择少量技法，再检查组合。

### 11.7 工作闭环

一句概念与简洁情绪 → 主体主次 → 空间关系 → 唯一视角景别组合 → 光影／材质／色彩协同 → 约束冲突检查 → 精简提示词 → 实际图像验收 → 单变量修正与反例记录。框架升级完成；案例验证尚未实施。

## 12. 真实感强化修订：因果一致性驱动的视觉生成控制（2026-10-13）

来源：已读取 ChatGPT「提示词冲突分析」本次真实感强化修订完整文字，并按用户确认内容增量整理。保留第 11 节的历史来源记录；本节不是逐字转录。没有开展新生成实验，图片附件未作为效果证据；保持 experimental、evidence: []。

### 12.1 上位目标与适用边界

**视觉可信度（Visual Credibility）**：主体、环境、观看方式和表现语言之间形成合理、可理解、相互支持的关系，使画面在选定创作规则内成立。精细、高级、独特或漂亮不自动等于可信。

- **物理一致性**：摄影、写实 CG 优先检查结构、受力、接触、空间、光源、遮挡与材质响应；经过设计的电影布光可包含画外光源，但照明条件应能解释画面。
- **风格一致性**：油画、插画、动漫优先检查形态、笔触、边缘、明暗简化和细节密度是否符合所选艺术语言，不强加毛孔或真实相机特征。
- 两者可共存，权重由 L1 的概念、媒介与表达目标确定。超现实作品可有意偏离物理规律，但应建立一致的内部规则。

**因果一致性是跨层关系原则，不增加第八层。** 七层架构组织决策，跨层关系管理协同与取舍，技法库提供方法，实验验证效果；这些是职责分工，不是新层级。

### 12.2 七层分析版：新增控制问题

| 层级 | 保留职责 | 真实感强化问题 |
|---|---|---|
| L1 概念 | 概念、简洁情绪调性、表达方向 | 需要哪种视觉可信度？采用什么媒介及规则？ |
| L2 主体 | 主次、形态、状态动态、互动 | 主体为何呈现此状态？动作、姿态与互动是否相容？ |
| L3 环境 | 场景、空间关系、环境叙事 | 哪些环境条件支持动作、光照及物理现象？ |
| L4 构图 | 视角、景别、焦距、视觉权重 | 机位、距离、透视、取景与景深是否相容？ |
| L5 光影 | 光源、方向、强弱、明暗 | 光源、遮挡、阴影与反射是否可共同解释？ |
| L6 材质 | 材质、纹理、细节 | 表面响应与局部不完美是否有合理成因？ |
| L7 色彩 | 主辅色、冷暖、饱和度 | 色彩是否与环境光、材质及成像方式协调？ |

### 12.3 四类跨层因果关系

| 类别 | 关联层 | 条件 → 可见证据 | 排查重点 |
|---|---|---|---|
| 主体状态因果 | L2 ↔ L3，L4 负责呈现 | 行走中突然回头 → 身体仍朝前、头肩转幅不同、发丝随动作偏移 | 动作动机与结构关系；静止不需强加动态 |
| 光照因果 | L3 ↔ L5 ↔ L6/L7 | 左侧窗光 → 左侧受光、遮挡处阴影、材料产生相应反射 | 避免无来源强光；允许合理画外光和环境反射 |
| 成像因果 | L4 ↔ L5/L6/L7 | 机位、距离、焦距与成像条件 → 相容的视野、透视、清晰范围与色调 | 透视主要由机位决定；焦距改变视野，不能单靠“35mm”保证空间关系 |
| 材质因果 | L2/L3 ↔ L5/L6 | 手臂弯曲 → 肘部压缩褶皱；使用与风化 → 局部磨损；表面状态和光源 → 局部高光 | 细节应对应受力、使用或环境，避免全域均匀瑕疵 |

分析阶段建立因果链，执行阶段写可见结果；不把长篇解释和不可见心理活动塞进提示词。摄影特征还受距离、光圈、传感器与后期等条件影响，不承诺文本参数必然精确实现。

### 12.4 真实感优先排查路径

写实摄影默认按 **主体与行为 → 空间与环境 → 构图与成像 → 光影与材质 → 受控不完美** 排查。

| 顺序 | 典型问题 | 优先动作 |
|---|---|---|
| P1 主体与行为 | 无动机摆姿、头肩或互动不协调 | 明确事件、状态与可见动作证据 |
| P2 空间与环境 | 人物贴背景、尺度和接触不成立 | 修正距离、遮挡、尺度参照与落地关系 |
| P3 构图与成像 | 透视、取景、景深与细节要求冲突 | 统一机位、距离与观看方案 |
| P4 光影与材质 | 受光无因、表面塑料化或过度修饰 | 协调光源、阴影、反射与材料响应 |
| P5 受控不完美 | 褶皱、纹理和局部差异缺失 | 添加少量有原因、有范围的自然特征 |

这是诊断启发式，不能取代概念约束优先级。风格化任务按所选艺术语言调整；明显光照错误可直接先修。整体关系成立后才修局部纹理。

### 12.5 受控不完美与简洁情绪调性

受控不完美是恢复符合情境的自然特征：转头带起少量发丝、弯臂产生局部褶皱、使用区域出现磨损、皮肤保留适量纹理。每项注明对象、范围和成因，避免为“去 AI 味”全图加脏污、噪点或夸张瑕疵。

L1 情绪保持一至两个清楚的词，如“自然、轻微意外”；由姿态、空间、光色落实。情绪调性不等于人物表情，也不必让所有元素同调。是否保留瑕疵或反差，仍由概念及用途决定。

### 12.6 五项约束检查

1. **概念检查**：重要条件是否服务核心概念和目标可信度？
2. **主次检查**：叙事主体、视觉焦点、辅助元素及观看顺序是否明确？
3. **因果检查**：重要动作、光影和材质细节能否合理解释？
4. **一致性检查**：空间、机位、光线、材质、色彩是否遵守同一物理或风格规则？
5. **冗余检查**：是否存在无作用、重复、竞争或同范围冲突的词？

检查在分析阶段完成，整合执行版不逐项输出过程。沿用“必须保留／优先实现／可牺牲”，发现冲突时按概念取舍并记录。

### 12.7 街头人像示例：七层分析版

说明性方案，未生成验证。为闭合回头动作与镜头位置，将摄影师设在人物侧后方。

| 层级 | 分析与可见选择 |
|---|---|
| L1 概念 | 被突然叫住的一瞬间；自然、轻微意外；真实生活中的街头抓拍 |
| L2 主体 | 蓝色针织毛衣的年轻成年女性行走中回头；身体朝原方向，头部转向摄影师，少量发丝随动作偏移 |
| L3 环境 | 午后街边咖啡厅入口，店铺结构和街道纵深可辨；阳光从一侧建筑间隙进入 |
| L4 构图 | 3:4 竖幅，35mm 等效视野；摄影师在侧后方接近视线高度，胸部以上近景；人物略偏中心，保留环境，不额外要求强虚化 |
| L5 光影 | 自然侧向阳光，面部有合理明暗过渡；脸颊附近碎发形成细小阴影，建筑明暗对应光源 |
| L6 材质 | 自然皮肤纹理，针织纤维与随身体扭转形成的局部褶皱；不过度磨皮或刻意加脏污 |
| L7 色彩 | 冷灰街景、蓝色毛衣为色彩锚点，少量暖阳；肤色与环境光协调 |

必须保留：回头事件、身体与头部方向差、可信街道空间。优先实现：侧光与材料响应。可牺牲：具体店铺装饰与微小纤维数量。

### 12.8 精简整合执行版

> 真实街头抓拍，3:4 竖幅，35mm 等效视野。午后街边咖啡厅入口，一位穿蓝色针织毛衣的年轻成年女性行走中被侧后方摄影师叫住，身体仍朝前，头部转向镜头，几缕发丝随转头偏移，神态自然、轻微意外。接近视线高度的胸部以上近景，人物略偏中心，背景保留店铺结构和街道纵深。建筑间隙的侧向阳光形成自然明暗，碎发在脸颊留下细小阴影。自然皮肤纹理、针织纤维和扭身褶皱；冷灰街景、蓝色毛衣与少量暖阳，肤色协调。

通用执行格式：**媒介与画幅／主体及关键状态／环境关系／唯一观看方案／光影／材质／色彩与简洁情绪**。七层分析版负责推理，整合版负责执行，可按重要性调整语序；两版同时保留，不强求格式逐项对应。

### 12.9 验证边界与入口

新增三个假设：主体行为与环境关系比仅加微观不完美更能提高整体真实感；光源、遮挡、材质一致性比泛化风格词更能提高摄影可信度；按概念筛选约束比关键词堆叠更稳定。均为待验证假设，详见[真实感 A/B 方案](../../image-prompt-engineering/experiments/seven-layer-v2-techniques-and-validation.md#真实感强化修订ab-验证计划2026-10-13)。

概念决定视觉要素选择，关系决定它们如何共同表达。独特不等于真实，真实不等于好看；去 AI 味服务作品表达，不替代作品表达。
