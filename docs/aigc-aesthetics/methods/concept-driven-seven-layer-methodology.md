# 概念驱动的七层视觉方法论：创作、品鉴与证据闭环

**知识标记：SS 级待验证方法论。** SS 表示本次讨论指定的重点研究优先级，不代表已验证、普适性或效果评级。遵循“先吸收后优化”：先准确保存原始主张，再应用、记录反例，最后依据证据修订。

来源：用户在 ChatGPT「主agent」中的概念与七层架构讨论，以及本次明确的沉淀要求。当前只有讨论材料，没有新增图片复核、独立生成实验或用户盲评，故 evidence 为空。下文例子均为说明性假设。

## 1. 核心主张：概念决定表达方向，关系组织表达力量

概念是作品希望观众感受到或理解的核心命题，是视觉创作的组织中心。主体、环境、构图、光影、材质、色彩共同将概念变成可感知的经验。

概念不等于风格标签或元素清单。“赛博、电影感、宏大”没有说明作品表达什么；“一个人的存在正在被庞大的数字系统吞没”则给出了个体与系统之间的关系。

工作法：先写一句关系命题，再列两到三个必要的视觉证据，并明确哪些表达可以弱化。概念可以集中，叙事仍可开放；不要强迫每幅作品只有唯一解释。

## 2. 七层职责与边界

| 层级 | 核心问题 | 可观察、可调的表达维度 |
|---|---|---|
| L1 概念 | 想表达什么关系、命题或感受？ | 意图、主导关系、预期观看体验；品鉴时属于待证实的解释 |
| L2 主体 | 谁或什么承载表达？ | 身份、状态、动作、姿态、主体之间的关系 |
| L3 环境（含空间关系） | 表达发生在什么世界，主体如何处于其中？ | 场景、尺度、距离、纵深、遮挡、包围、人与环境的关系 |
| L4 构图 | 这些关系如何在画框中被组织和看见？ | 画幅、裁切、位置、留白、视觉重量、动线、投影与观看路径 |
| L5 光影 | 哪些部分被显现或隐藏？ | 光源因果、明暗分布、衰减、对比、焦点与情绪 |
| L6 材质 | 世界通过什么质感成立？ | 表面纹理、光学响应、触感、媒介痕迹、真实感 |
| L7 色彩 | 色彩如何参与关系表达？ | 明度、饱和度、冷暖、色彩比例、过渡与注意力 |

L3 关注场景内部的空间关系，L4 关注这些关系如何经视点与画框呈现。同一现象可涉及多层：人物很小可能由真实尺度、距离与构图占比共同造成，不必强行归入唯一层。

与[既有七层架构](../../image-prompt-engineering/methodology/seven-layer-architecture.md)衔接：原文 L3 为“空间层”，本方法称“环境层（含空间关系）”，保留原有纵深、遮挡和尺度职责。原文是案例中的生成执行框架；本文将其扩展到概念驱动的视觉品鉴，这一扩展仍需单独验证，也不替代整个审美知识库的分类体系。

七层是分析与设计维度，不是固定流水线、模型注意力顺序或完整美学定律。创作可往返修订，提示词应按表达重要性组织。

## 3. 层间四种关系

| 关系 | 判断问题 | 假设示例 |
|---|---|---|
| 支撑 | 哪一层为另一层提供成立条件？ | 广阔环境为人物的渺小提供尺度参照 |
| 协同 | 哪些层共同强化同一表达？ | 环境包围、构图挤压与人物局部隐没共同强化被吞没感 |
| 对立 | 冲突是否产生必要的意义？ | 温暖的人类信号与冰冷系统形成生命和系统的张力 |
| 取舍 | 为主导概念，什么应弱化？ | 减少霓虹光效，避免数字压迫变成视觉奇观 |

这些关系可以同时存在。对立不等于错误，统一也不等于有效。判断依据是关系是否使目标表达更清晰、更有力量，而不是各层是否分别“好看”。

可复用句式：
> 因为要表达【概念】，让【层 A 的可见选择】与【层 B 的可见选择】形成【关系】，预期产生【感受】；用【观察或对照】验证。

例如：因要表达个体被系统吞没，让 L2 人物的克制姿态、L3 巨型空间的包围和 L4 边缘位置形成协同；验证观众是否读到力量差异，而非只读到一座漂亮城市。

## 4. 自上而下创作：意图 → 关系 → 选择 → 结果

1. **定义意图**：一句概念、目标观众、用途、约束和不希望产生的误读。
2. **定义关键关系**：选两到三个承载概念的关系，注明支撑、协同、对立或取舍。
3. **翻译七层**：各层写必要的可见选择及其理由，避免所有层争抢注意力。
4. **形成生成控制**：将关键关系写进提示词或制作方案；文字描述不能替代结果验证。
5. **复核实际结果**：检查图像里的证据、整体体验和偏离；成功调用工具不等于表达成功。
6. **针对原因修改**：优先调整最影响概念的一项变量，记录修改前后，再判断是否保留。

概念本身也可被结果启发和修订，但必须记录意图变化，避免事后把任何输出解释成成功。

## 5. 自下而上品鉴：观察 → 关系 → 概念假设 → 验证

先保存直观感受，再记录图中真正看见的事实；之后组织层间关系，提出概念解释。这里“自下而上”指从视觉证据推导意义，并非机械地从 L7 倒数到 L1。

1. **观察**：人物位置、尺寸、姿态、场景距离、亮暗、纹理和色彩是什么？
2. **关系**：哪些选择互相支撑或冲突？观看路径和注意力如何形成？
3. **假设**：提出一个主解释，必要时保留替代解释。
4. **验证**：为解释列支持证据、反证和无法确定之处。
5. **评价**：区分表达是否成立、自己是否喜欢、是否符合任务与观众。
6. **迁移**：只迁移已说明适用条件的关系，不把“冷色＝孤独”等联想当成通用规则。

“看见一个人”是观察；“他很孤独”是解释；“作者意图表达孤独”需要作者材料或额外证据。未知作者意图时应说“可以读作”，不能声称已经理解全部信息。

## 6. 概念假设必须受视觉证据约束

| 记录项 | 填写要求 |
|---|---|
| 概念假设 | 一句话，可被支持或削弱 |
| 可见证据 | 指向画面位置和具体特征，注明涉及层级 |
| 表达机制 | 说明特征如何通过关系产生体验 |
| 反证与替代解释 | 哪些细节不符合？是否也能解释成自由、宁静或壮阔？ |
| 验证动作 | 遮掉焦点、改变一项对比或做并列版本比较 |
| 结论边界 | 观察事实、合理解释与尚未验证的因果分别写清 |

删除测试与单变量对照有助于诊断，但不能单独证明普适因果；生成结果同时变化时应注明混杂因素。观众认同、作者陈述、生成有效性是不同证据，不能互相替代。

## 7. 媒介适用范围

**完整七层仅用于视觉生成与视觉品鉴。** 可以分析视频单帧或网站视觉界面，但不能据此完成整个视频或网站的评价。

上位的“概念驱动原则”可迁移到其他媒介；迁移时必须重建执行维度：
- 视频：时间结构、镜头关系、运动、节奏、声音、叙事和时间因果。
- 网站：用户任务、内容、信息架构、操作路径、交互反馈、可访问性和视觉层级。

例如“平静、可信赖”的网站，除了低刺激的视觉，还需清晰操作与稳定反馈。视觉上的平静不能替代使用体验上的可信赖。

## 8. 先吸收后优化与验证计划

1. **吸收**：按本文保留定义、边界和讨论来源，避免先改成另一套熟悉框架。
2. **应用**：在独立任务中同时做创作和品鉴，记录输入、输出、证据、失败与用户判断。
3. **优化**：用反例决定是修改机制、限定场景还是放弃假设，保留原版本可追溯性。
4. **晋升**：依照[知识治理](../../image-prompt-engineering/governance.md)，至少三个独立案例只是必要条件；还需可追溯证据、无足以推翻的明显反例，并由人类批准。

建议验证三类独立任务：尺度关系图片、通过对立表达概念的图片、存在多个合理解释的图片。分别观察：框架是否提升意图表达；层间分析是否比元素清单更有用；证据检查是否减少过度阐释。说明性例子、同一项目连续迭代和多个助手赞同都不能自动算作独立验证。

## 10. 与 Agent 评估的连接

本方法可作为视觉 Agent 的领域判断输入：概念提供目标，七层帮助定位可调变量，层间关系解释表达机制，证据检查约束评价，用户反馈校准偏好。

“审美判断作为评估体系”仍需区分任务符合度、概念表达、视觉完成度和个人偏好。模型给自己的结果写出动人解释，不构成验证；必须查看实际输出，并结合独立评审或用户反馈。技术执行闭环负责行动可靠，价值判断闭环负责行动是否值得保留，两者通过证据和纠正动作连接。
