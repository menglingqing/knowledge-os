# AIGC 审美认知 · AIGC Aesthetics

面向图像、视频与空间创作的审美判断、概念方法与品鉴案例库。

核心命题：**元素可以很少，但关系必须极强。让世界成立，让一个事件或信号获得意义。**

## 定位与阅读路径

本模块回答“为什么被打动、希望表达什么、什么值得保留”。[生图提示词工程](../image-prompt-engineering/README.md)回答“如何把选定意图转化为生成控制”。七层架构是下游视觉生成执行框架，不是本模块的分类法，也不用于给所有审美经验分层。

建议顺序：品鉴案例 → 审美原则 → 概念取舍 → 创作控制 → 生成结果复盘。也可按问题直接引用下列文档。

## 审美原则

- [自然美感与世界主导](principles/natural-beauty.md)——非表演性的自然美、“世界本来就在这里”、自然主导／主体只是事件，以及诗意提纯的自然。
- [尺度与存在](principles/scale-and-presence.md)——Small Subject, Big World、冷暖对立、极小人类信号、尺度等级与“人在秩序面前”。

## 创作方法

- [概念、克制与减法](methods/concept-and-subtraction.md)——概念熵、一个核心创意、元素少但关系强；包含删减判断与反例。
- [如何转化为创作控制](methods/creative-control.md)——从一句命题到可见证据、可调变量和对照复盘；在执行时引用七层架构。

## 案例与认知历史

- [2026-09-20：从自然事件到巨大秩序](cases/2026-09-20-image-appreciation.md)——八张图片的观察、解释、可迁移认知与边界，保留来源和稳定案例编号。
- [认知日志](ledger/learning-log.md)——记录审美认知的形成与修正，避免复述文件修改记录。

## 维护与引用约定

1. 本批内容来自一次连续品鉴及用户明确提出的审美方向。它是一组可修订的创作假设，不是普适美学定律；本次没有进行生成验证。
2. 原则、方法和案例使用最小 frontmatter：`status` 与 `evidence`。当前均为 `experimental`；证据链接指向具体案例锚点。沿用[现有知识治理](../image-prompt-engineering/governance.md)的最小元数据、证据独立性和人类批准晋升规则。
3. 本模块的 `principles/`、`methods/` 表示内容职责，不表示已经验证。审美偏好可以被用户确认；生成控制的有效性仍需独立任务检验。八张参考图不等于八次生成验证。
4. 新品鉴先进入 `cases/`，按“来源与可见观察 → 意境解释 → 可迁移假设 → 边界／反例”记录，再链接已有原则。只在出现新的解释问题时拆新文件，避免按工具或每个近义词重复建页。
5. 生成实验需补充任务、输入、输出、单变量变化与评判结果。满足现有治理的必要条件后，提出晋升建议，由人类裁决；不因助手赞同或重复转述而晋升。
6. 稳定文件路径与显式锚点用于跨文档引用。概念定义保留在原则／方法页，案例只说明应用；移动时更新所有引用。日期由 Git 管理，认知变化另记日志，每条核心经验不超过 50 字。
