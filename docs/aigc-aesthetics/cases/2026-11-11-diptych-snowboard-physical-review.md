# 滑雪双联海报：从排版赞许到摄影结构复核（2026-11-11）

<a id="user-recheck"></a>

## 事件与结论

此前三张原创滑雪双联海报在字体融合、蓝橙色彩与运动叙事方面获得用户正向评价。随后用户放大重新检查，明确提出：
- **第一张**雪板与人物脚部对应关系不正确；
- **第二张**相对好一些，但没有获得严格运动物理无误的认证；
- **第三张**雪板与脚部同样存在问题。

助手此前过分关注巨字、破框、雪雾与视觉冲击，低估了雪靴、固定器、单板和双腿之间的三维连接关系。“看起来真实”并不意味着“具有可信的物理拓扑”。

用户在多轮复查后进一步指出，部分图仅大致正确，后两轮六幅图基本都有问题。模型还多次生成**横向三栏拼贴**、或只输出无字摄影，而非指定的**各自独立上下等幅双联海报**。因此不得把这些尝试纳入成功案例库。

## 技术性观察的边界

单板滑雪不是双脚并排的日常深蹲。两只雪靴必须分别通过固定器连接在同一块雪板的不同纵向位置，身体姿态与脚尖朝向、双膝屈曲、重心、雪板刃边和雪面作用要协调。低机位广角可以夸张近大远小，却不能改变对象之间的连接。关键连接完全被雪雾遮挡时应记为不可核验，不能自动通过。

这项认识指导**真实摄影生成阶段**的验收，不应把完整运动技术细则复制到排版 Skill。详见[摄影结构验收执行源](https://github.com/menglingqing/aigc-framework/blob/main/techniques/photographic-structural-integrity.md)。

## 用户确认的架构修正

用户决定将工作分为：
1. **真实摄影**：现有生图 Skill 负责人物、姿态、器械、物理真实性、机位、光材色；
2. **海报文字排版**：专项 Skill 负责同源上下双联、字体、字形镂空、真实遮挡、留白、色彩与表达增量。

**摄影门禁先于艺术排版**。如果摄影母图失败，返回生图阶段；不以视觉修饰让失败输入伪装成成功海报。海报 Skill 可以提出留白和构图要求，但不修复滑雪姿势。

## 证据等级和后续

- 用户判断和可见结果支持“该组三版排版具有吸引力，但部分摄影物理结构不成立”的有限结论。
- 不是完整受控 A/B；缺少原始生成参数、正式运动专业评估及全部高清结果的仓库存档。不报告成功率或模型内部原因。
- 下一轮只拿摄影阶段**明确通过**的母图做字体排版对照，摄影不动，隔离图形变量。
- 知识评级维持研究候选，不因早期正面反馈晋升为稳定可复现方法。
