# 2026-11-01｜妆造案例：水光狐系红妆

> **归类**：AIGC 人像美妆／人物妆造参考案例；以 L2 主体中的面部造型为主，关联 L5 光影、L6 材质和 L7 色彩。  
> **来源**：2026-11-01「品鉴」对话，用户上传两张近距离真人风格人像，并转述创作者对“妆造篇——水光狐系红妆”的说明。  
> **归档性质**：先学习图片中的可见效果，保留后续反复验证的空间。**尚未进行本妆造的独立生图实验；status: experimental。**  
> **图片材料**：会话附件 `image(20261101-132507).png` 与 `image(20261101-132515).png`；本次 GitHub 归档保存文字观察，**原始图片尚未上传仓库**。本文件不据外观断定照片来源、化妆产品或模特的真实骨相。

## 1. 创作动机

创作者提出：仅用“韩系、白开水、纯欲、千金”等笼统妆名，很难稳定控制惊艳效果；**妆容名称需拆解为可观察、可组合、可验证的视觉特征**，并考虑不同人物脸型、眼型与面部结构的适配。两张参考图使用的名称为**「水光狐系红妆」**。

此处保留该观点作为创作假设，不声称详细描述一定比名称有更高命中率；后续需通过同模型对照实验检验。

## 2. 两张参考图的可见观察

### M-01｜微侧脸、指尖轻触面颊
- **构图**：2:3 竖向极近距离美妆肖像，人物面容占主导，微微偏转，右侧手指抬到脸颊旁；深色长发包围脸部，细碎发丝横贯额前和眼周。
- **眼部**：柔和粉棕／玫瑰调眼影，眼尾向外拉长的黑色细眼线，细密的上下睫毛与眼下轻微晕染；瞳孔有明确反光，整体情绪冷艳但不凶。
- **唇部**：较饱和的樱桃莓红，唇缘相对柔和，中间颜色较浓，唇峰和下唇中央有集中、湿润的镜面高光。
- **皮肤与配饰**：肤面呈高调柔润的精修质感；鼻梁、鼻尖与眼皮有局部反光；红宝石色与金色的长耳坠、项链吊坠和细长浅色美甲互相呼应。
- **作用**：手指靠近脸颊，增加手—脸的互动与观看路径，但手势不遮挡关键五官。

### M-02｜正面眼神、发丝掠过面部
- **构图**：同样为高占比面部近景，脸朝镜头，面部略偏正；几缕长发从额间跨过鼻梁、眼睛和脸颊，手指及耳饰出现在画面右侧边缘。
- **眼部**：眼尾更明显的横向拉伸感；粉红系眼影、较清楚的下睫毛、眼尾细线相互配合，眼神比较平静、克制。
- **唇部**：光泽集中在下唇与唇峰，红唇成为黑发、浅肤色之间的最强颜色焦点。
- **配饰**：细长金色耳饰与红色宝石吊坠均可辨识，但比 M-01 的视觉权重稍弱。
- **作用**：减少手部动作，让眼妆、红唇与自然碎发主导画面。两张不是单变量对照，不能据此断定哪个手势或角度更有效。

## 3. 先把妆名拆成“可见妆造控制点”

| 部位／角色 | 可见特征与可执行的候选描述 | 易失控之处 |
| --- | --- | --- |
| **眼型与眼线（“狐”）** | 重点向外延展的眼尾轮廓，纤细略上扬的眼线；眼睛表现为横向拉长而非圆睁 | 眼尾过粗、过尖；上挑角度过大显凶或动漫化 |
| **眼影与下眼睑** | 低至中饱和的玫瑰粉／粉棕铺色，眼尾加深，眼睑中央微光；下眼睑柔和晕染 | 大片通红造成疲惫或发炎感；过重卧蚕 |
| **睫毛与瞳孔** | 上下睫毛分明但保留不齐整感，睫根明确；瞳孔呈自然深棕与小范围反射 | 美瞳纹理机械重复、睫毛数量夸张、瞳孔异形 |
| **唇色（“红”）** | 深樱桃／莓红色为主焦点，边缘柔和，唇部渐变与饱满玻璃状高光 | 红色铺满整脸、唇部过度膨胀、反光像塑料漆 |
| **肤面（“水光”）** | 偏亮的柔润底妆；鼻梁、鼻尖、眼皮和唇部有**选择性反光**，脸颊光泽较克制 | 全脸油亮、蜡像皮肤、高光失去光源逻辑 |
| **眉与轮廓** | 自然深棕眉毛，眉形偏平缓，和细长眼线形成对比；鼻梁与脸部轮廓过渡柔和 | 夸张鼻影与过度磨皮让五官不真实 |
| **发型／动势** | 深色长发包裹脸部，少量自然细碎发丝掠过额头、眼旁和面颊 | 发丝从眼球或皮肤穿过；乱发遮住情绪焦点 |
| **饰品／美甲** | 金色细长耳饰、少量红宝石色元素、心形或水滴状吊坠、浅色细长甲片 | 饰品多重堆叠抢过眼睛和红唇；手指畸形 |
| **情绪与近景** | 冷静、略带距离感的目光；面部特写中眼睛和红唇清晰，手势克制 | 过度挑逗、做作嘟嘴、相机焦点跑到饰品上 |

**妆造三锚候选**：横向拉长的粉棕狐系眼妆 ／ 深樱桃红水光唇 ／ 选择性面部高光与黑发红金饰品。

这里的“水光”应理解为局部材质与照明共同形成的视觉结果，而不是给全脸增加一样的湿亮滤镜。

## 4. 脸型、眼型与骨相适配：应研究，不能从两张图下定律

当前两张参考图面部表现较接近，不足以代表各种脸型和骨相。**适配建议仅是后续实验变量，不是对图中模特真实骨相的诊断。**

- **偏圆或偏短的脸部**：候选思路是控制眼尾横向延伸、避免脸颊大面积红晕，测试能否让视觉重点向眼尾集中；不能为了“瘦脸”修改身份骨骼。
- **偏长脸型**：可对照缩短眼线外延、调整眼下腮红和唇色的视觉重心，避免全脸垂直拉伸；保持原有面部辨识特征。
- **眼尾本身较上扬**：眼线是否需要更平、较短，避免过度锋利；保留自然眼型而非统一“狐狸眼”模板。
- **眼型较圆或外眼角下垂**：尝试眼尾延伸与细线收尾，评估是否自然，不强行拉扯眼裂。
- **鼻梁、颧骨与面部体积**：光斑位置应遵守光源与实际面部曲面，不使用固定“磨出高鼻梁”的模板。
- **唇形差异**：保留人物原有唇峰、嘴角和唇厚，测试不同红唇边缘柔化和高光比例，而非统一丰唇。

## 5. 与真人摄影表现的关联

这两张作品更接近**精修美妆特写的真人观感**，不能等同无修饰纪实摄影。若迁移到强调“像实拍”的工作流，应避免机械强化毛孔或全局噪点，而是核对：
1. 眼球、睫毛、鼻梁、嘴唇和指甲的反射是否对应同一光源；
2. 皮肤在眼下、鼻翼、嘴角、下颌是否保留合理的形体和局部纹理；
3. 口红高光是否有材质特征，眼影亮片是否只出现于应出现的部位；
4. 细碎发丝遮挡是否符合实际前后关系；
5. 手势、珠宝与脸部注意力是否合理分工。

此处没有记录相机参数、原始妆品或真实布光位置，不能从静态图倒推出精确焦距和照明设备。

## 6. 后续生图验证计划

**不急于直接固化成“水光狐系红妆万能提示词”。** 建议固定同一位成年人物的参考身份与相似构图，采用：
- **A 妆名组**：仅写“水光狐系红妆”。
- **B 特征组**：不使用妆名，只写眼线、眼影、唇色、局部高光与饰品的可见特征。
- **C 组合组**：妆名 + 精简三锚 + 少量需要严格锁定的细节。

随后跨不同眼型／脸型（以角色身份不漂移为前提）、不同光照（柔光、微硬光、室内闪光）重复，并记录所有成功与失败结果。评价：眼妆一致性、真实肤质、红唇材质、角色身份保持、五官适配、发丝/饰品物理关系与总体美感。

如果 B/C 相较 A 更稳定，仍需考虑提示信息量的差异，不可把改进全部归因于“细节写得更长”。

## 7. 认知增量与沉淀决策

- **当前价值**：具备明确可迁移特征的人像妆造参考；先按 **A级候选实用案例** 保存，**未验证其提示词增益**。
- **候选认识**：妆造应由眼部结构、唇色层级、局部材质、人物原有面容及饰物角色共同构成；简单妆名可能不足以锁定结果。
- **局限**：仅两张相近风格案例、缺少原始提示词与完整生成记录，没有脸型适配对照，无法外推所有模特。
- **决策**：归档于 AIGC 审美 `cases/`，不新建正式妆造方法论、不修改七层视觉架构 v2.0 或七段式生图 Skill。后续经实测再完善。
