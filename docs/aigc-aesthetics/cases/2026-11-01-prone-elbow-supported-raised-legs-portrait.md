# 2026-11-01｜人物姿态案例：俯卧撑起上半身，屈膝自然翘脚

## 一、姿态定义：不是笼统的“趴着翘腿”

**俯卧支撑上身 + 髋腹贴床 + 双膝自然弯曲 + 小腿与脚向后上方抬起**。

- **身体接触与受力**：腹部、髋部及部分大腿与床面接触；双肘／前臂承接上半身部分重量，肩颈放松，不用腰椎强行后折撑高。
- **躯干关系**：胸肩自然抬离床面，肩线轻微倾斜或转动，背部保持舒展；不必追求从肩到膝的僵硬直线。
- **下肢关系**：双膝保持弯曲，小腿向后上方抬起，两只脚可略有高度差、自然交错，踝关节放松；不追求对称、笔直或过分翘高。
- **头面与手势**：面部朝向镜头，眨眼、噘嘴、笑容或侧视可独立变化；双手既可随前臂自然放在床上，也可以轻触两颊或向镜头伸出，不得牺牲手臂支撑的合理性。

**一句话的姿态目标**：人物是舒适地趴在床上与镜头互动，而不是为了拍照刻意反弓身体、用力踢起双腿。

## 二、三张图片逐张观察

### P-01｜淡紫居家套装：wink 与自然支撑

会话附件：`image(20261101-131913).png`，竖幅。

- **可见动作**：成年女性俯卧在浅色床单上，双肘/前臂在身体前方支撑，上身自然抬起；双膝弯曲，脚在身后上方交错或错位；一只眼睛眨起，嘴唇轻抿。
- **机位与空间**：近距离床面视角，面部与双臂占前中景，后方翘起的脚和床边小型置物架构成纵深；图像边缘有明显暗角。
- **值得借鉴**：动作简洁，表情和整体姿态互相配合；床单受压褶皱与前臂落点提供接触证据。
- **待核验边界**：皮肤、面部具有美妆精修表现，不能仅凭画面断定摄影方式或生成模型。

### P-02｜室内夜景：表情、双手与双脚联动

会话附件：`image(20261101-131846).png`，竖幅。

- **可见动作**：女性腹部贴床、上半身抬起，双肘/前臂靠近面部支撑；双手弯曲，在脸颊旁形成俏皮框架；笑着眨眼、露齿，双腿在身后屈膝抬起。

- **值得借鉴**：从同一基础俯卧动作出发，通过手势和笑容改变气质；双脚在远处提供活泼的第二动作层。
- **待核验边界**：多处手指靠近脸部，生成时须检查手指数量、指尖接触、肘部支撑与颈肩放松是否同时成立。

### P-03｜黑色街头装：动作不变、风格改变

会话附件：`image(20261101-131915).png`，竖幅。

- **可见动作**：女性穿宽松黑色上衣，在床上俯卧并抬起头肩，前臂朝镜头方向延展；一只眼睛微眯/眨眼，后方腿部屈膝，鞋底在上方背景可见。
- **机位与空间**：人物脸部在前景偏上，靠近镜头的手和前臂形成向画外的视觉延伸；后方鞋履、床品与明亮房间拉开近远层次。
- **值得借鉴**：相同的身体支撑结构能转为休闲街头气质，不限于家居睡衣场景。
- **待核验边界**：手臂朝前延伸与脚在后方抬起会增加透视和解剖难度，需要保留肩—肘—腕、臀—膝—踝的真实连接。

## 三、这组三图的共性：动作骨架固定，气质随其他变量变化

| 维度 | 共性／变化 |
| --- | --- |
| 固定骨架 | 俯卧床面、上半身由前臂支撑、双膝后屈、脚自然抬起 |
| 面部情绪 | 眨眼浅笑／开心大笑／略带俏皮的冷感表情 |
| 手部变化 | 前臂自然落床／双手轻框脸颊／手臂向镜头延伸 |
| 镜头层次 | 近景脸和手／中景躯干／后景翘起的小腿与脚 |
| 媒介与环境 | 室内近距离人像、床单压痕、暗部/闪光或日光的差异 |
| 服装风格 | 居家淡紫、浅色吊带、宽松黑色街头服装 |

**可迁移观察**：无需改变核心俯卧支撑关系，也能通过表情、手势、服装和光源组合，生成不同的人物气质。这是案例观察，不等于已经验证了单变量的有效性。

## 四、与既有研究的联系与限制

- **L2 主体**：先明确受力和骨架，再描述具体表情与微动作，避免动作词彼此冲突。
- **L4 构图**：面部处于近处，抬起的脚位于后景；镜头高度、前臂与床褥形成观看深度。镜头与肢体应相互解释。
- **颜文字情绪锚定法**：可作为下一次实验的可选控制变量，观察同一姿势中表情如何变化；当前三图不证明颜文字曾参与生成。
- **观察者视角锚定法**：可单独改变观察者身份/镜头距离研究不同观看关系；此处不把俯卧姿态混同为动物视角。
- **真实感边界**：床面承压、肘部接触、衣料褶皱、腰背舒展、腿脚相对距离应同时成立。不要把夸张身体曲线当成唯一目标。

## 五、建议后续验证（当前未执行）

1. **动作骨架复现**：固定成人角色、床品、服装、环境、画幅，测试仅用简短动作短语，是否稳定出现前臂支撑、腹髋贴床、双膝弯曲与双脚抬起。
2. **表情变化**：保持动作及机位，分别用眨眼、自然微笑、张嘴笑、轻微侧视等变化，评估表情与肢体是否协调；必要时与颜文字情绪锚点做 A/B 对照。
3. **手势变化**：固定其他条件，比较手自然落床、轻触脸颊、前伸三种手势，检查手部解剖和受力是否自然。
4. **机位变化**：在床面高度、略高斜俯、近距离广角之间比较，观察前景手臂是否抢占面部视觉中心，以及远景脚是否被误生成额外肢体。
5. **评价维度**：动作自然度、人体结构/承重点、手与脸的互动、表情感染力、景深与透视、床褥/服饰的真实受力；保存完整生成结果而非只挑最佳。
