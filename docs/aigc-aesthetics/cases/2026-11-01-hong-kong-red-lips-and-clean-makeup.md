# 2026-11-01｜妆造对照：港风红唇妆 × 白开水妆容；从文字控制转向参考图锚定

## 1. 核心研究问题

如果只提供「港风红唇妆」「白开水妆容」等名称，模型有较大的自主解释空间。即使人物、光线或其他文字锚点相似，图像生成仍可能出现面部细节、妆色与质感差异。创作者报告：对其使用的 GPT 与被称为「香蕉」的图像工具而言，后者在该类妆容控制上体验更佳；这是**创作者的个人反馈**，不是模型间经过同条件测量的性能结论。

创作者推荐两条路径：

1. **探索发现式**：用多次出图（“抽卡”）找到满意妆容，然后将满意成图作为参考，继续锚定并迁移。
2. **目标逆向式**：手头已有喜欢的妆容时，先从图中拆出眼妆、唇色、底妆、光泽与光线等可见特征，再采用**参考图 + 文字约束**进行上妆。

这两条路径的共同点是：**用可见目标图确定审美方向，文字承担选择性锁定、局部修正与适配，而不是仅靠妆名期望复现相同结果。**

## 2. 参考图 01：港风红唇妆

- **构图**：2:3 竖幅面部大特写，女性正对镜头，黑色长发与少量碎发围绕面部；深黑背景压低环境信息，酒红色衣领进入画面底部。
- **眼妆**：深棕眉、较细的黑色上眼线并向眼尾小幅拉长；暖棕/淡玫瑰色眼影与较清晰上下睫毛共同强化眼型，目光沉静、有距离感。
- **唇妆**：浓郁莓红／酒红唇色，颜色边界相对清楚；唇纹可见、反光克制，**更接近缎面柔光红唇**而非玻璃状果冻唇。
- **面部与肤质**：肤色被明显提亮，但保留鼻翼、脸颊、下颌的明暗体积；眼下与鼻梁局部受光更强。
- **配饰与色彩**：深红衣装、红色耳饰、浓郁红唇属于同一色彩家族，黑发/黑背景提供高对比基底；红色是强视觉主轴。
- **摄影情境**：面部有明确方向性的亮部与阴影，深背景隔离主体。**“港风感”由妆容、服饰、发型、布光与对比一起产生**，不能将所有效果都归因于口红颜色。

**可借鉴三锚**：缎面莓酒红唇／略拉长的暖棕眼妆／深背景与酒红服装形成的高反差人像气质。

## 3. 参考图 02：白开水妆容

- **构图**：2:3 竖幅面部近景，黑色长直发、些许掠过鼻梁/脸颊的细发丝，人物微微张唇看向镜头；浅灰背景，衣领仅有极少露出。
- **眼妆**：眼皮颜色非常接近本身肤色，仅有浅淡杏棕层次，眼线紧贴睫毛根部；睫毛相对自然，眼下影调低对比，没有突出的眼尾上挑或厚重卧蚕。
- **唇妆**：低饱和粉裸色，柔和唇缘、局部细腻湿润光泽；没有明显的高浓度唇色边界。
- **面部与肤质**：整体亮度较高，面部明暗过渡细腻、皮肤视觉平滑；不过“白开水”在此代表**低妆感的精修审美**，并不意味着图中完全没化妆或未经后期处理。
- **摄影情境**：浅中性背景与柔和、较均匀的光线共同强化通透感；眼睛与柔亮唇部成为视觉重点。

**可借鉴三锚**：低饱和粉裸唇／轻薄近肤色眼妆／柔和高调光线与自然碎发。

## 4. 核心对比：不要把摄影变量误当成妆容变量

| 维度 | 港风红唇妆 | 白开水妆容 |
| --- | --- | --- |
| 视觉情绪 | 冷艳、复古、成熟 | 干净、克制、亲近、松弛 |
| 色彩焦点 | 中高饱和酒红唇、红色配饰 | 低饱和粉裸唇、肤色与黑发 |
| 眼周层次 | 暖棕色与眼尾拉长更明确 | 靠近自然肤色与睫毛根部的细薄处理 |
| 唇部质地 | 缎面/柔光，颜色相对厚实 | 微湿润，边缘柔和 |
| 皮肤表达 | 保留局部明暗体积 | 高调低对比、柔雾细腻 |
| 环境与布光 | 深色背景、方向性光线 | 浅灰背景、柔和光线 |
| 注意力 | 眼睛与红唇；红色服饰呼应 | 眼神、淡唇、面部整体干净度 |

**重要边界**：这不是同一人物、同场景、同光线的单变量妆容实验。图一与图二的服装、发型、光源对比、背景、细节强度均不同。不能据此断言两种妆容本身必然引发特定人物气质。

## 5. 候选方法：妆造的双路径参考锚定

### 路径 A：生成探索 → 参考图固定

1. 确定人物整体身份、真人摄影媒介及希望探索的妆造方向，允许模型探索不同妆容；
2. 保存全部有代表性的成图，选择满意结果，而非只记住提示词；
3. 将满意成图作为**妆造参考**，与身份参考和场景参考做职责区分：人物身份不能被妆容图替换；
4. 用短文字注明**必须保留**（眼线形态、唇色、材质、妆面层次）和**可以变化**（表情、姿态、背景、光源）；
5. 迁移到新的场景并检查面容一致性、妆面保留、光线适配与细节漂移。

### 路径 B：目标参考 → 逆向视觉拆解 → 文字锁定

1. 已有喜欢的妆造图，先拆出眼、眉、唇、底妆、腮红、修容、肤质、发型与饰品；不能从图中确定的成分、品牌、产品型号不杜撰；
2. 将整体风格名保留为情绪摘要，但把关键控制换成**可见结果**，例如「唇色的饱和度、边缘、光泽与唇纹」；
3. 为妆容参考图单独限定责任，明确保留目标人物的五官比例与身份特征；
4. 结合新人物原有眼型、唇形、肤色及新的光源，允许效果发生符合物理条件的变化；
5. 输出后逐项复核“保留项/偏差项/失败模式”，用局部修正而不是重写所有提示词。

**为什么可能有效**（假设）：参考图提供高信息密度的具体视觉样例，文字负责减少歧义并声明迁移边界。此举可能降低文字妆名的解释自由度，但也会带来身份泄漏、背景混入与参考图过度复制等副作用。

## 6. 重要的迁移限制

- **身份不是妆容**：若把妆容参考图的脸型、瞳距、唇厚也一起带入，会损害目标模特一致性。
- **骨相/肤色适配**：相同眼线长度、卧蚕厚度、唇形处理在不同成年人面部可能有不同效果。应保留原有五官比例，调整妆效与光泽而不是强制“捏同一张脸”。
- **光线不是妆容**：同一哑光/缎面红唇在硬光、柔光、色温不同的环境中有不同反射；参考图不能要求跨光线保持每个像素不变。
- **景别决定细节预算**：特写可以交付细微唇纹、细眼线、睫毛层次；全身景不应强行要求同样的微观清晰度。
- **精修真人感与纪实真实感不同**：两张都呈现一定程度的皮肤润饰；“像实拍”还需检验毛发、肤理、脸部体积和光源因果。
- **模型差异需单独测**：作者说“GPT 与香蕉有差距”只记录为原始主观意见。需要同提示、同图像参考、相近采样预算与盲评才能量化。

## 7. 后续可复核的对照方案

固定同一位**成年**模特（身份参考）、摄影景别、姿态、背景、布光、画幅与生成模型版本；每组进行重复生成并保留失败图。

- **A：妆名文字**——只用「港风红唇妆」或「白开水妆容」。
- **B：视觉拆解文字**——不用风格名称，逐项写可观察眼唇肤质特征。
- **C：妆造参考图 + 同量精简文字**——将妆造参考限定为“只保留妆容，身份由另一张参考锁定”。
- **D：满意成图二次参考**——先从 A/B 输出中选择满意妆容，再跨表情、机位、光线重用该成图作为妆造参考。

比较：妆容相似性、身份保持、不同光照下合理的材质变化、整体真实感、失败率、编辑成本与审美完成度。**不同组字数和图像信息量不相等时，不能简单把差异全部归因于模型能力。**
