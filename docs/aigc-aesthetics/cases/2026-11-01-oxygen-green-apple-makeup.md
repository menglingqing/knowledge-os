# 2026-11-01｜妆造案例：氧气青苹果妆

> **分类**：人物妆造／高调清新美妆肖像（L2 主体，关联 L5 光影、L6 材质、L7 色彩）  
> **来源**：2026-11-01「品鉴」对话；用户提供两张真人风格近景图片、妆造名称与关键词。  
> **创作方原始定义**：骨相「清纯幼态骨相」；妆容「氧气青苹果妆」；关键词「冷白奶雾肌｜浅粉杏眼影｜自然放大眼型｜饱满卧蚕｜淡粉果汁唇｜青苹果清新感」；气质「清甜、氧气感、幼态、无辜、元气」。  
> **验证状态**：案例收录，未进行本妆造名称与具体提示词的独立 A/B 生成测试。造型术语“幼态”描述视觉语言，**不据照片判断人物真实年龄或骨骼构造**；后续用于人物生图时以成年模特为前提。

## 一、两张图片的可见证据

### A-01｜正面微张唇的清透特写

- **画面与人物**：2:3 竖幅近距离脸部肖像，乌黑顺直长发、中分发缝，右侧淡青绿色发夹，浅青绿色针织衣物进入画面下缘。脸部占画面主体，眼睛直视镜头，嘴唇轻轻张开；细发丝自然拂过额头及脸颊。
- **眼妆**：眼型视觉上偏圆润开阔，浅粉／柔杏色眼影非常克制；睫毛根根分明，细长眼线沿睫毛线自然收尾而不强烈上扬；下睫毛和眼下卧蚕有轻微阴影、柔亮过渡，眼眶周围带淡粉调。
- **唇妆**：低饱和淡粉，柔和唇缘，唇面有小范围水润反光，饱满感主要来自自然唇形与光泽而非深色勾勒。
- **肤质与光**：面部表现为非常明亮、低对比、偏冷白的柔雾底妆视觉；鼻梁和唇面仍有克制高光，脸颊不明显油亮。背景浅冷灰，光线较均匀。
- **视觉作用**：颜色强度很低，主视觉由清晰眼睛、黑发与浅亮肤色形成。需注意皮肤较平滑、具有高程度美妆精修感，不宜误写成“完全无修饰纪实摄影”。

### A-02｜手持青苹果的浅笑特写

- **画面与人物**：与 A-01 相近的深色长直发、淡绿色发夹和浅绿色衣饰；人物露出轻柔闭唇笑意，一只手把浅青绿色苹果举到脸旁，苹果表面有细密水珠。
- **妆容变化**：眼部仍以淡粉杏调、柔和眼线、清晰睫毛与卧蚕为主；唇色是偏粉的柔亮光泽，整体仍低饱和、低对比。对比 A-01，表情更主动且亲切。
- **色彩联系**：苹果、发夹、衣服同属浅嫩绿色系，形成具象的“青苹果”提示；黑发作为深色边界，肤色、背景和绿色道具维持明亮清新的总体色调。
- **视觉作用**：苹果不只是手持物品，还把抽象的“清新、果汁感”转化为可见的色彩与场景线索；手—苹果—面部形成次级视觉路径。
- **边界**：两张图片相近但不能仅凭外观证明严格角色身份一致；也不能认定新增苹果就是妆容更清新的单独原因。

## 二、拆解“氧气青苹果妆”的候选可控组件

| 模块 | 参考图可见特征／候选描述 | 生成风险与边界 |
| --- | --- | --- |
| 妆造气质 | 清甜、清透、元气、亲近，克制的“幼态感”面容设计语言 | 避免将“幼态”写成未成年人；不应强制改变成年角色脸部身份 |
| 肤面 | 偏冷的明亮奶雾肌、柔和漫反射，鼻梁与唇面少量自然高光 | 过度磨皮、蜡像白、鼻部高光失真、全脸失去真实纹理 |
| 眼影 | 低饱和浅粉与柔杏色，边缘薄透渐变，不加大片浓重阴影 | 眼圈过红、粉色堆积、“病弱感”取代清甜感 |
| 眼线与眼型 | 细线顺应眼形，眼尾小幅延伸；通过睫毛与眼周提亮让眼睛显得自然开阔 | 生硬圆眼放大、过粗翘眼线、美瞳/瞳孔比例异常 |
| 卧蚕与下眼睑 | 眼下有轻柔饱满光带和极浅阴影过渡，下睫毛清晰 | 卧蚕画成白色硬条、眼袋显著、下眼线过重 |
| 唇妆 | 淡粉/蜜桃粉果汁色，柔和边缘、少量透明湿润光泽 | 唇体被夸张放大，荧光粉、塑料镜面高光 |
| 眉形 | 自然平缓柔眉，发色一致的深灰棕/深棕，不抢眼 | 眉形过硬、过粗、强烈锐角 |
| 发型与配饰 | 乌黑直长发、微松散额前碎发、浅绿色细发夹 | 发丝穿透脸部、发夹悬浮、头发完全像头盔 |
| 色彩与道具 | 冷白肤色、淡粉妆面、嫩绿苹果/发夹/衣物的有限呼应 | “所有物件都染绿”、道具反客为主、背景过度花哨 |

**候选三锚**：冷白柔雾底妆（局部真实微光）／淡粉杏眼影与自然放大眼型、柔和卧蚕／淡粉果汁唇与少量青苹果嫩绿呼应。

关键区别：**这里的“果汁感”不是让整张脸变得油亮，而是把较湿润的唇部与整体柔雾肤面形成局部材质反差。**

## 三、与“水光狐系红妆”的比较：妆造不是只换颜色

| 维度 | 氧气青苹果妆 | 水光狐系红妆 |
| --- | --- | --- |
| 情绪取向 | 清甜、无辜感、亲近、轻元气 | 冷艳、成熟精致、略带魅惑 |
| 眼部策略 | 自然开阔、眼线细柔、卧蚕更显眼 | 眼尾横向延伸、粉棕深浅与眼线共同拉长眼型 |
| 唇色及光泽 | 低饱和淡粉，透明果汁光 | 高饱和莓／樱桃红，镜面高光更强 |
| 皮肤角色 | 高调柔雾奶白，局部光泽 | 选择性水光与更鲜明的妆面层次 |
| 色彩锚点 | 浅嫩绿配饰与青苹果；粉色仅微弱点缀 | 金色、红宝石与红唇，深发作对比 |
| 人物互动 | 正面眼神、浅笑、手持水果 | 冷静眼神、面部发丝、手指靠近脸部 |

这说明**妆造可以被看成“面部结构处理 + 色彩关系 + 材质分工 + 情绪／道具叙事”的协同系统**。这个描述是对两组图的归纳，并非被证明普适的生成机制。

## 四、“清纯幼态骨相”应如何研究适配

“骨相”是创作方的风格描述，无法仅凭两张图直接确认真实骨性结构。后续以**保留成年模特原有身份和五官**为前提，研究不同脸型／眼型适配，不应统一捏成一张“童颜模板”。

- **眼型偏细长**：尝试更轻的眼尾线与下眼睑层次，测试是否能带来自然开阔感，不强制生成巨大圆眼。
- **眼型偏圆**：保持原有形态，避免重复放大瞳孔和卧蚕造成卡通化。
- **面部轮廓偏长／偏圆**：在腮红位置与阴影强度上做小幅实验，避免把生成的脸型改变当成“化妆成功”。
- **肤色不同**：测试“奶雾”作为柔焦、低对比的材质语言，而非固定强制冷白肤色；让人像保持自然肤色层次。
- **年龄表达**：清甜、无辜感和元气可以通过表情、眼周明暗和色彩完成，不必改变角色实际年龄。

## 五、与镜头、真实感、注意力的关系

1. **近景面部占比**使细眼线、卧蚕阴影、唇部高光成为可交付的可见细节；较远环境人像则不宜机械写同样精度。
2. **高调柔光**服务浅粉眼妆与奶雾肤面，不应靠全局过曝丢失鼻翼、唇部及发丝层次。
3. **绿苹果是跨层呼应**：L2 手持行为、L3 可见道具、L4 手—苹果—脸动线、L7 绿色点缀共同形成完整主题，而非独立堆元素。
4. **真实性与精修审美区分**：参考图具有显著皮肤平滑处理的美妆视觉，若日后要求“像真实相机拍摄”，需另行核对微观皮肤、发丝、反射与材质因果。

## 六、后续测试：先判断“妆名”是否足够，再检验细节和适配

固定成年角色参考、景别、光线、服装、面容和背景，设置：
- **A 妆名版**：仅“氧气青苹果妆”加固定人像条件；
- **B 特征版**：不用妆名，仅描述奶雾肤质、浅粉杏眼影、自然眼型、卧蚕、淡粉果汁唇；
- **C 组合版**：妆名 + 精简三锚。

**道具要单独控制**：在 A/B/C 的同等条件下统一“不使用苹果”，再另做“有／无青苹果”对照，避免把道具带来的清新感误归因于妆容变化。记录所有结果，评估眼形身份保持、眼影和卧蚕细节、肤面真实度、唇妆材质、绿色分布与情绪可信度。

第二阶段跨脸型、肤色、镜头距离、室内/户外光源迁移；只有出现稳定效果并满足[治理要求](../../image-prompt-engineering/governance.md)后再提议方法论晋升。

## 七、知识贡献与沉淀决策

- **初评**：A级候选案例（基于可见参考图的结构价值），**生成控制增益未独立验证**，不直接作为 S 级新方法论。
- **边界**：两张相近视觉风格的照片，缺少完整原始生图提示词、模型设置和不同脸型对照。
- **决策**：仅存入案例库 `cases/`，不修改七层视觉架构 v2.0、七段式执行提示词 Skill 或正式妆造公式。
