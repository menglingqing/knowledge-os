# 40 种英文字体：从名称清单到创作参考

<a id="source"></a>

## 来源与可见材料

用户在 2026-09-26 的对话中提供《40 种适合杂志、海报与 AI 生图的英文字体图鉴（附提示词）》上下册。上册以消息形式提供 01–20；下册以粘贴文本附件提供 21–40、三层搭配逻辑及完整海报提示词。未提供原始发布链接、字体文件或实际字形图片。

当前[字体参考库](../references/typography/README.md)是便于检索的整理版本，包含少量分类澄清，不是原文逐字存档或厂商规格。Founders Grotesk 的窄体描述限定为样式方向；Biro Script 明确作为圆珠笔手写方向；Canela 避免严格归为传统衬线。字体名、版本和授权仍需在实际选用时向相应来源核实。

用户明确提出：“我希望我们以后在设计图片或者网站等产品时，能够借鉴这些艺术字，以增强视觉效果。”随后指定将材料补充到 GitHub 的 knowledge-os 项目，用于后续使用和学习。

## 创作意图

字体不只负责传递文字，也可以建立时尚、文学、工业、复古或手写的性格。用户确认的是主动参考多样字形的偏好，并未要求固定某一种字体，也未要求所有项目都采用杂志风格。

## 可迁移假设

- 先判断内容气质，再选择主标题、信息层与可选手写点缀。
- 主标题承担表现力，正文与交互文字保持清楚；通常先从两种字体开始。
- 组合效果来自字体、尺度、字距、留白与图片关系，而不仅是字体名称。
- AI 生图用视觉特征表达意图，网页使用实际字体资产和明确的后备方案。

使用方法与完整提示词见[搭配指南](../references/typography/GUIDE.md)，版式关系参考[海报视觉系统](../methods/poster-system-design.md)。

## 边界与反例

本次没有检查真实字形样张、生成图像或实现网页。因此不能声称这些提示词已验证稳定、组合已验证好看，或商业字体已获授权。手写、超窄体和极细高反差字形可能不适合小字号信息。中文页面需要独立考虑中文字体与中英文协调。

后续应在固定内容和版式下完成对比，记录真实结果，再按[治理规则](../../image-prompt-engineering/governance.md)讨论晋升。
