## 一、创作者给出的原始提示词（原样存档）

> 2:3，户外夏日氛围写真，中国少女，甜美，麻花辫、蓬松、自然碎发、白色小雏菊发饰、清透白开水妆，低饱和粉调腮红，弱化眼妆、保留原生皮肤质感，氛围感自然温柔。  气质：清甜、氧气感、幼态、无辜、元气  斑驳光影打在身上，浅景深。  浅黄色细吊带碎花短裙、领口带荷叶边+抽绳设计、修身版型。

原始文本中的“少女、幼态”是创作者对画面气质的用语，并不支持推断图中人物实际年龄。日后以此生成人像时，可改用**成年年轻女性**并保留清甜、元气等审美方向。

创作者同时提出两点实践感受：① 不必在每次人像提示词中列出相机机型；② 大段描述有时存在指令冲突、画面平均化或风格化风险。这是值得验证的经验，**不是“长提示必坏、短提示必好”的通用定律**；“GPT 本质是从随机噪点出发”也不足以单独解释所有产品的具体生成算法或复现能力。

## 二、三张图的可见观察

### S-01｜林荫步道中的转身回眸

- **动作**：人物身体向侧后方旋转，头部回望镜头并自然露齿微笑；两条麻花辫呈一定摆动，浅黄色碎花裙摆向外展开。身体转动、头发、裙摆有同方向的动态线索。
- **构图**：竖幅中近全身景，人物位于中间偏左，花裙轮廓占下方大区域；小路的虚化纵深与绿色树冠形成环境层次。
- **光色**：明亮日光穿过绿荫，发丝有边缘透光，地面与衣裙出现不规则日照块；黄绿为主要色调，皮肤相对明亮。
- **可迁移点**：**不是单独要求“裙摆飘起来”，而是借转身动作让衣裙与发丝动态具有共同动因**。
- **边界**：局部高光较亮；单帧不能证明镜头或运动的物理参数。

### S-02｜雏菊花地里的持辫近景

- **动作**：人物头部略倾，目光直视；一只手轻握胸前一条麻花辫，表情安静克制，区别于 S-01 的明显笑容与动态。
- **构图**：胸部以上至腰部附近的中近景，人物占据主要视觉面积；大片白色小花、深浅绿叶构成柔焦背景，少量花朵位于发侧。
- **光色**：较为柔和的自然侧光，皮肤与花朵亮、植被暗，浅黄碎花裙与肤色形成温柔的亮部集中。
- **可迁移点**：同样的服装发型与环境 DNA，在更近的景别下把视觉焦点从裙摆动态移到眼神、面部和轻微手势。
- **边界**：脸部、妆容与发型细节和其他两张并非可以严格确认同一身份；不要把风格相似误当成角色锁脸成功。

### S-03｜草地野餐的坐姿互动

- **动作**：人物坐在浅色野餐布上，双臂向前自然支撑／放置，肩线略有倾斜，脸微抬与镜头建立平静交流；双腿和裙摆形成更大面积的近景形态。
- **构图**：镜头略高，能看到野餐布、花篮、草地与小雏菊；人物居中，环境依然简洁，不抢人物面部。
- **光色**：枝叶投下明暗斑块，草地绿色为中暗部，裙装米黄与皮肤为亮部。这里的斑驳阳光更接近“日常自然环境的真实遮挡”。
- **可迁移点**：同一系列视觉世界不必全部站立或同一景别；坐姿与野餐道具丰富叙事，但主要服装、发饰和主色没有改变。
- **边界**：仅可据图讨论外观及受力，无法确认是否有后期精修或摄影真实模型；人物脸部一致性需要独立检查。

## 三、短提示词为什么可能有效：不在长度，而在锚点的角色分工

原始短 prompt 虽然篇幅少，却覆盖了相对完整的**系列视觉 DNA**：

| 功能 | 已提供的控制信息 | 生成画面中的主要作用 |
| --- | --- | --- |
| 世界与情绪 | 夏日、户外、自然温柔、清甜元气 | 限定观看情境，不同镜头仍有共同氛围 |
| 身份外观线索 | 蓬松麻花辫、自然碎发、白雏菊发饰 | 强化发型和人物气质的系列识别 |
| 服装锚 | 浅黄细吊带碎花短裙、荷叶边、抽绳、修身 | 保持稳定、容易识别的衣装轮廓和颜色 |
| 妆容锚 | 白开水妆、低饱和粉腮红、弱眼妆、原生质感 | 减少浓妆与衣装的竞争，让脸部清新 |
| 光线与媒介 | 斑驳光影、浅景深 | 通过光斑和背景退后建立季节感与层次 |
| 技术边界 | 2:3 竖幅 | 统一系列海报式画幅，但不能替代工具输出参数 |

**候选解释**：这些锚点具有相对清楚的职责分工，而不是大量不相容的镜头、情绪和材质要求。模型仍可自由设计动作、景别和环境，呈现“同一夏日世界，不同摄影瞬间”。

但三张图的**人物五官与身份未被严格锁定**；相同发型、花饰和服装不等于可用于连载故事的同一人物。稳定**系列风格**和稳定**角色身份**要分别验收。

## 四、同一系列的三个摄影层次

- **动态建立**（S-01）：转身回眸，裙摆与发丝共同运动；最大亮点是动作因果和裙摆形状。
- **情绪靠近**（S-02）：景别变近，手握发辫，视线和淡妆成为主视觉；柔和而不激烈。
- **环境停驻**（S-03）：坐姿、野餐布和花篮建立日常事件，人物与环境关系更完整。

这组照片的可复用结构是：**统一世界观／色彩与服装 DNA + 变化的动作／景别／观看关系**。不是以“每张都一样”为系列成功条件。

## 五、关于“短提示 vs 长提示”的证据边界

创作者说长提示有时互相冲突、出图平均化，值得记录，但从现有三张图**不能**推导出：
- 文字越短，成图必然越真实；
- 相机参数没有作用或永远无需指定；
- GPT 所有模型都按同一个具体生成机制工作；
- 三张图来自完全相同输入、没有种子/参考图/挑选/后期差异；
- 所有同类图片都能够稳定复现同一张脸。

更精确的工作假设是：**对于创意探索，少量互不竞争的高价值视觉锚点可能为模型保留有效的构图与微动作探索空间；对于严格身份、镜头和服装复现，仍需要参考图和必要的局部约束。**

## 六、后续验证建议：以“系列稳定性”而非单张惊艳为目标

1. **A：原始短提示词**；同模型固定画幅与可用生成参数，重复出三张及以上，不事后删掉失败结果。
2. **B：等价视觉目标的七段式执行版**；保持概念、衣装、发型、妆容、光色相同，只增加身体动作、三层空间、镜头关系等可见约束。
3. **C：短提示 + 单条镜头行为**；分别指定转身回望、手握麻花辫近景、坐在野餐布等，测试是否足以稳定组织“三镜头系列”。
4. **D：短提示 + 人物身份参考图**；检验在不降低夏日自然感的前提下，能否显著提升同一模特的身份一致性。
5. **检验指标**：单图美感、系列色彩/服装/发型一致性、脸部身份一致性、动作自然度、物理光源因果、背景重复与 AI 过度平滑风险；记录所有输出与提示词。

这些分组是后续方案，**尚未实施**。需要注意 B 对比 A 时同时提高了信息量和约束数量；若结果更好或更差，也不能仅归因于提示词字数。

## 七、与认知框架的关系与收录结论

- **L1**：确定夏日清甜的情绪与观看感受；**L2**：年轻成年角色、自然表情、发型/服装与动作；**L3**：树荫小路、花地、野餐草地；**L4**：从转身中全景到近景、坐姿的景别组织；**L5**：斑驳自然光；**L6**：碎发、织物、真实皮肤；**L7**：浅黄、奶白、草绿与低饱和粉。

- **知识贡献初评**：A级可用案例，关于“少量视觉 DNA 约束足以支持系列探索”的稳定性和可迁移增益待验证；不直接上升为 SS 或正式方法论。
