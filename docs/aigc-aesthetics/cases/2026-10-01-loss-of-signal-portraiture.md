# 2026-10-01：信号损失肖像——从故障滤镜到数字解构

<a id="source"></a>
## 来源与任务

本次连续品鉴从一张黑白偏米色的 Glitch Portrait 参考图开始，随后进行了多轮 AI 生图迭代。讨论重点逐步从“这种故障风叫什么”转向“为什么某些作品像故障滤镜，而另一些作品像人物自身正在失去完整性”。

用户最终明确认为已经找到这一画风的创作灵感，因此将本次经验整理为可复用方法。

## 一、参考图真正成立的原因

参考图并不是因为黑条多而成立，而是因为它同时满足：

- 人物仍然可辨认；
- 人脸关键区域被故意打断；
- 横向 glitch 与纵向人像构成方向冲突；
- 黑、灰、米白和肤色保持克制；
- 文案与视觉“破碎”形成语义闭环；
- 大黑块、中型结构和微扫描噪声具有尺度差异。

由此得到第一条判断：

> **破坏主体，不等于消灭主体。**

以及：

> **可辨识性负责吸引，缺失性负责停留。**

## 二、第一轮生成：Portrait + Glitch

最初两张生成已经建立了米白背景、黑色高领、正面人物和横向故障，但存在典型问题：

- 人脸过于完整；
- glitch 主要位于人物表面；
- 黑色矩形块尺度过于接近；
- 人物仍像商业美妆肖像；
- 故障“漂亮”，却缺少发生原因。

这类结果可以概括为：

> **Portrait + Glitch**

即人物和故障仍是两套可以拆开的系统。

## 三、第二轮生成：开始出现 Data Corruption

后续两张把故障集中到人物左半脸，并形成“头发—额头—眼睛—面颊—下颌—高领”的连续损坏区域。

其中较有效的变化是：

- 左侧轮廓不再只是被遮挡，而开始瓦解；
- 出现故障区、转化区与完整肉身区；
- 微量 RGB 残色没有破坏整体克制；
- 人物自身开始成为 glitch 的材料。

这标志着方向从：

> **Portrait + Glitch**

逐步进入：

> **Portrait → Data Corruption**

也即：

> **Portrait becoming Glitch**

## 四、仍然暴露的问题

### 规则矩形感
部分中尺度矩形仍然过于整齐，使结果接近 pixel block mask，而不是真实图像损坏。

### 完整身份锚点过多
当两只眼睛都保持完整时，人物仍可被快速完整读取，缺失性不足。

### 损坏边界过直
“左侧坏、右侧正常”的处理虽然清晰，但容易形成半脸蒙版，需要让边界发生侵入、退缩和再侵入。

### AI Beauty 残留
眉形、眼线、皮肤、唇部与对称性仍偏商业美妆，削弱肉身与数据之间的冲突。

## 五、关键修正方向

本次讨论形成五条优先修正：

1. 完整眼睛只保留一只；
2. 减少规则中型矩形块；
3. 增加面部真实结构位移，而不是只做遮挡；
4. 让故障边界呈潮汐式侵入与退缩；
5. 降低 AI 美妆感，增加真实皮肤与发丝随机性。

同时明确不应破坏的方向：

- 米白旧纸背景；
- 黑色高领；
- 近单色体系；
- 正面静态人物；
- 横向故障语言；
- 极少量异常色。

## 六、从“删除”扩展到“错误读取”

本次进一步意识到，故障不应只有“缺失”，还可加入：

- **Offset**：局部水平错位；
- **Echo**：眼睛、鼻梁、嘴角的错误复制与 ghost image；
- **Frame duplication**：局部重复帧；
- **Transform**：发丝、轮廓逐渐转化为扫描数据。

这让故障语言从“信息消失”扩展为“系统读取错误”。

## 七、最终创作母题

本次经验最终沉淀为：

> **一个真实的人，正在被一个不真实的系统读取。**

更抽象的视觉矛盾是：

> **Human continuity vs Data discontinuity**

风格因此不再以“炫酷技术故障”为目的，而是可以承载：

- identity loss；
- signal loss；
- data corruption；
- memory distortion；
- incomplete reading；
- partial deletion；
- misrecognition。

## 八、可迁移结论

<a id="portrait-becoming-glitch"></a>
### 故障必须进入主体结构
不是在脸上贴效果，而是让脸、头发、眼睛、轮廓自身出现信息错误。

<a id="loss-gradient"></a>
### 建立信息损失梯度
故障区、转化区、肉身区应有明确状态差异，同时避免机械的半脸渐变。

<a id="real-body"></a>
### 真实肉身提高损失感
越真实、越不完美的皮肤和头发，越能与数字损坏形成有效冲突。

<a id="analog-digital"></a>
### 数字错误和模拟衰败可以共存
Glitch 与旧纸、复印、墨粉、错版、印刷噪声结合，比纯赛博故障更接近实验编辑视觉。

<a id="restraint"></a>
### 克制比炫技重要
大面积霓虹和 RGB Split 很容易把主题改写成“未来科技”；异常色应作为极小的数据泄漏。

## 九、证据边界

本次已经进行了连续生成与对比，但属于同一任务链条，尚不能证明方法对不同人物、不同构图和不同模型都稳定有效。

因此方法页保持 `experimental`。后续若在不同任务中重复验证“Portrait becoming Glitch”“损失梯度”“一只完整眼睛”“数字错误 + 模拟衰败”等控制仍能稳定提升结果，再考虑晋升。
