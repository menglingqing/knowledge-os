## N01 · 鲸类跃水与雪山海湾

**可见观察**：两只鲸类在海面跃起，水花局部明亮；山体、森林、雪峰及水域占据主要空间，动物相对显小。具体物种未确认。

**意境解释**：世界先在那里，观看者恰好遇到生命显露的一瞬。“巨大寂静”是整体氛围，不否认跃水动作本身的力量。

**可迁移假设**：让环境承担视觉重量，让局部生命行为承担叙事重量；通过距离与尺度保留偶遇感。参见[自然主导](../principles/natural-beauty.md#world-led)。

**边界／反例**：主体若缩到动作不可读，事件就消失；鲸鱼特写也可成立，但表达的是另一种观看关系。两只鲸鱼仍可组成同一个事件，无需机械删成一只。

<a id="case-n02"></a>
## N02 · 雪山河谷与火车

**可见观察**：远山受暖光，林带相对暗；深色列车横跨河谷，河流弯曲并带反光，前景存在模糊枝叶与栏杆状痕迹。静帧不提供列车速度证据。

**意境解释**：山与河所暗示的长期自然过程，和火车所暗示的一次经过并置。文明拥有位置，却未夺走自然的主导权。

**可迁移假设**：小型人造物可以让自然风景出现人的时间；人工横线与地貌曲线也可增强关系。参见[世界与事件](../principles/natural-beauty.md#world-led)。

**边界／反例**：本图无法证明山龄或列车正在运动；“永恒的山”是诗性表达。若将火车强化成产品主角，原命题会改变。光线分配支持意境，不替代意境。

<a id="case-n03"></a>
## N03 · 海岸峭壁

**可见观察**：水面之上是大面积岩壁，林木附着山体，远处接续雪峰与天空；未见明确的人或动物主角。

**意境解释**：地貌的上升形态、体量与空间层次已经足够。世界无需额外事件来证明自己值得观看。

**可迁移假设**：围绕一个强自然形态组织画面，用水面与岩壁的关系建立宏大感。参见[克制与减法](../methods/concept-and-subtraction.md#restraint-subtraction)。

**边界／反例**：这不是“小主体大世界”的必选配方，而是“可以没有事件主体”的补充。添加人物有时能帮助尺度判断，应按任务决定，不能一概禁止。

<a id="case-n04"></a>
## N04 · 熊涉水

**可见观察**：熊位于前景水中，腿部附近有水花，背后依次出现草地、森林与雪山。熊占据显著面积，并非一个微小点。

**意境解释**：画面不仅让人看到一只熊，也让人感到它生活于这样一个世界。涉水的状态比独立展示姿态更容易带出环境归属。

**可迁移假设**：环境中的动物或人物应与所在空间发生关系；可以用行为、接触和地貌连续性建立归属。参见[非表演性](../principles/natural-beauty.md#non-performative)。

**边界／反例**：不能仅凭静帧断言动物完全没有看向镜头。环境主导是程度关系，不必把所有案例解释成极端小主体。

<a id="case-p01"></a>
## P01 · 巨月与花海

**可见观察**：巨大月亮位于花群之后，蓝紫、月白与淡粉统一画面；花瓣与花间存在微光和亮点，近花与远月形成空间对照。

**意境解释**：地面生命朝向天上柔光，世界像处于安静的等待中。月亮可以被读为照拂或精神性存在；这是联想，不是图内事实。

**可迁移假设**：以一个主导的幻想关系组织尺度、色彩与微光，使自然被诗意提纯。参见[诗意提纯的自然](../principles/natural-beauty.md#poetic-nature)。

**边界／反例**：月亮异常尺度是主导创意，但并非唯一的幻想处理，花间发光也参与其中。“一个核心”允许多个支持效果；若新效果形成另一个独立奇观，再考虑删减。

<a id="case-l01"></a>
## L01 · Lofoten 山海与红色聚落

**可见观察**：红色房屋聚落依附岩岸，巨大山体立于其后，前景海浪与白色水沫形成运动纹理，整体偏冷灰。

**意境解释**：自然巨大，人类栖居仍然存在。海浪、聚落和山体可分别唤起瞬间、人类生活与地质过程的不同时间感，不代表测得了房龄或山龄。

**可迁移假设**：少量人类色彩信号可以使自然的尺度与冷峻更可感；聚落作为一个整体承担“这里有人生活”的意义。参见[极小人类信号](../principles/scale-and-presence.md#human-signal)。

**边界／反例**：红色的意义来自栖居语境，不只是颜色本身；这里的“对抗”也可理解为依附与共存，不能直接推断居民生活状态。

<a id="case-l02"></a>
## L02 · Lofoten 冰面与暖屋

**可见观察**：大面积深冷色冰面及裂纹占据前景，远处积雪与山体延伸；右侧房屋的窗和屋檐附近发暖光，冰面上有少量暖色反射，左侧另有暗屋。

**意境解释**：寒冷辽阔的世界中，远处一处暖意可能带来归处或庇护的联想，也可以带出不可抵达的距离感。

**可迁移假设**：通过暖色的稀缺、集中与环境关系建立情绪终点。参见[冷暖对立](../principles/scale-and-presence.md#warm-cold)。

**边界／反例**：“一处暖意”不等于画面里只有一栋房子。冰裂纹虽然丰富，却支持寒冷与距离的命题；减法不应自动抹除这些细节。

<a id="case-o01"></a>
## O01 · 人物、岩体王座与圣殿

**可见观察**：中央披袍背影面对台阶与岩体，岩体内有座椅，上部有冠架状装饰；高窗、拱廊与殿堂包围整体。人物位于近景，座椅位于远处；画面采用强中轴结构。

**意境解释**：人面对由王座、岩体与建筑共同具象化的巨大秩序。“权力已经变成地貌”概括岩体与权力符号的融合；觐见、继承或审判都是开放读法。

**可迁移假设**：用人—权力结构—建筑的尺度等级建立敬畏与压迫，站立面对即可产生张力。参见[人在秩序面前](../principles/scale-and-presence.md#person-before-order)。

**边界／反例**：尺度链不是对座椅和人物投影大小的排序，也不能推断真实建筑尺寸。复杂雕饰可以服从同一命题；强对称服务仪式感，无需为“避免居中”而破坏它。

## 本轮认知修正与待验证项

- 从“光线与构图如何做”回到“画面为什么有意义”：执行手段必须服务概念和意境。
- 从“把主体做小”修正为“让世界有主导权，同时保留事件可读性”。
- 从“只允许一个元素或效果”修正为“多个选择共同服务一个核心命题”。
- 自然宏大与秩序宏大共享尺度机制，但情绪与叙事含义需要分开解释。

尚未验证：缩小主体、集中暖光或减少独立奇观，是否在具体生成任务中改善预定表达。后续按[创作控制与对照记录](../methods/creative-control.md#comparison-record)补充实验，不把本轮品鉴直接升级成模型通用规律。
