# 七层创作认知框架 v2.1：IP Visual DNA / 视觉语法

> 状态：Experimental → Core Candidate  
> 来源：2026-11-08《白蛇传》四幅作品品鉴与 IP 元素分析  
> 目的：补足“单张图像成立”与“系列 / IP 持续成立”之间的认知缺口。

## 1. 为什么升级

七层架构 v2.0 已能稳定处理单张图像的概念、主体、环境、构图、光影、材质与色彩，并通过“跨层因果一致性”提升真实感与去 AI 味。

但在系列化与 IP 化创作中，出现一个长期问题：

> 当人物、场景、服装、机位都变化时，什么东西必须保持稳定，才能让作品仍然属于同一个 IP 与同一个世界？

《白蛇传》案例表明，答案不是固定的物体清单，而是一套可跨层迁移、可被不同视觉元素反复实现的“生成语法”。

因此 v2.1 不增加 L8，而是在 L1 与 L2–L7 之间加入“IP Visual DNA / 视觉语法”这一中间约束层。

---

## 2. v2.1 结构

**L1 核心概念 / IP 本质**  
↓  
**IP Visual DNA / 视觉语法**  
↓  
**L2 主体 → L3 环境 → L4 构图 → L5 光影 → L6 材质 → L7 色彩**

### 各层职责

- **L1 核心概念 / IP 本质**：回答“它是谁、它的情绪与精神是什么”。
- **IP Visual DNA / 视觉语法**：回答“无论怎么变化，怎样仍然让人感觉是它”。
- **L2–L7**：回答“这一张具体如何实现”。

IP Visual DNA 不是新的画面层级，不应写成 L8。它是一组跨层持续生效的约束与转译规则。

---

## 3. 核心原则一：IP 不是元素集合，而是生成语法

低阶做法：

> 白蛇 = 白衣 + 蛇 + 西湖 + 油纸伞 + 古装

高级做法：

> 提炼 IP 的核心语义，再将语义跨层转译成构图、光影、材质、色彩、环境与主体行为。

《白蛇传》案例中，可暂时提炼为：

- 白
- 柔
- 冷
- 流

这些不是“关键词装饰”，而是可以进入不同层级的生成规则。

例如“流”可以表现为：
- 发丝运动
- 衣带走势
- S 形构图
- 水纹
- 雾线
- 排版路径
- 人物姿态

只要语义保持，具体物体允许变化。

---

## 4. 核心原则二：优先保留语义，不必保留物体

显性符号可以被转译为隐性语法。

### 白蛇案例

| 显性符号 | 可转译语法 |
|---|---|
| 蛇 | S 形曲线、蛇影、倒影、水纹、发丝动线、衣带路径 |
| 白衣 | 留白、高调空间、象牙白材质、低饱和环境 |
| 妖性 / 非人感 | 半透明材质、雾、折射、非实体轮廓、异常但克制的光 |
| 水 | 镜面、涟漪、反射、折射、潮湿质感、漂浮感 |
| 冷 | 青玉、雾灰、冷白光、低饱和肤色、疏离表情 |
| 玉饰 | 冷、润、半透的材质锚点 |
| 伞 / 桥 / 塔 | 二级叙事元素，不作为一级 IP DNA 强制出现 |

原则：

> **符号可以消失，语义不能消失。**

---

## 5. 核心原则三：一级 IP DNA 与二级叙事元素分离

### 一级：IP Visual DNA

决定“它是谁”。

包括：
- 核心气质
- 结构曲线
- 色彩 DNA
- 材质语言
- 光影倾向
- 空间与留白方式
- 动态方式
- 隐性身份提示

这些应在系列中保持高稳定性。

### 二级：Narrative Props / 叙事元素

决定“这一张讲什么”。

例如：
- 伞
- 桥
- 湖
- 塔
- 船
- 雨
- 某个具体服装
- 某段剧情场景

二级元素可以频繁变化，不能反过来定义 IP。

---

## 6. 核心原则四：气质识别优先于符号识别

新的判断标准：

> **IP 创作不追求“元素像”，而追求“气质像”；不靠符号证明身份，而靠整个画面的视觉逻辑让身份自然成立。**

最高级的测试是：

> **去掉最明显的 IP 标志后，这张作品是否仍然属于那个世界？**

如果答案是否定的，说明作品主要依赖符号识别，尚未形成稳定的 IP 视觉系统。

---

## 7. 核心原则五：跨层转译

一个真正稳定的 IP DNA，必须可以同时进入多个层级，而不是只停留在 L2 主体。

示例：“白蛇 / 小白”

- **L1 概念**：冷、柔、克制、介于人 / 妖与现实 / 传说之间。
- **Visual DNA**：白、柔、冷、流；水感；半透明；蛇形动线；玉；若隐若现。
- **L2 主体**：黑发、青白玉饰、克制神情、轻微非人感。
- **L3 环境**：水、雾、亮场、低信息空间、反射。
- **L4 构图**：偏置、大留白、遮挡、极端裁切、S 形视觉流。
- **L5 光影**：高调环境 + 局部方向光 + 柔和阴影衰减。
- **L6 材质**：薄纱、玉、水膜、湿润发丝、柔亮丝绸。
- **L7 色彩**：象牙白 / 雾灰 / 墨黑 / 极浅青玉色。

这使 IP 从“人物设定”升级为“整套画面都属于它”。

---

## 8. 对系列创作流程的升级

以后做系列 / IP 创作，先完成以下顺序：

1. **确定 L1：角色 / 世界的本质**
2. **提炼 3–5 个 Visual DNA 核心词**
3. **定义一级 IP 元素**
4. **定义二级叙事元素**
5. **建立跨层转译表**
6. **建立色彩 DNA**
7. **建立材质 DNA**
8. **建立构图与动态语法**
9. **再进入单张图的 L2–L7 设计**
10. **用“去符号测试”检查是否真正属于该 IP**

---

## 9. 防止 AI 模板化的新规则

《白蛇传》案例也暴露出一个风险：

当“白皮肤 + 黑发 + 古装 + 冷眼 + 玉饰 + 薄纱”被反复机械复制时，很容易滑向成熟但可替代的 AI 古风模板。

因此：

- 不把人物美型程度当成主要升级方向。
- 不通过增加装饰解决内容不足。
- 不机械复用固定物体。
- 优先增加世界观中的独有关系：影子、倒影、材质反应、环境痕迹、行为逻辑。
- 同一 Visual DNA 要允许不同视觉实现，避免“模板即风格”。

## 10. 当前验证状态

### 已完成
- 白蛇 / 小白：首个完整验证案例。

### 待跨题材验证
- 敦煌
- 玄奘
- 天宫

验证重点：

1. Visual DNA 是否能稳定提炼？
2. 是否能跨 L2–L7 转译？
3. 去掉显性符号后是否仍有 IP 归属感？
4. 是否降低模板化与元素堆砌？
5. 是否提高系列一致性同时保留单张差异？

若跨题材验证持续成立，则该模块从 **Experimental / Core Candidate** 升级为稳定 Core 方法论。

---

## 11. 当前结论

这次升级不是增加更多提示词技巧，而是补上：

> **单图创作 → 系列创作 → IP 世界观创作**

之间缺失的桥梁。

最终公式：

> **核心语义 → IP Visual DNA → 跨层转译 → 七层实现 → 系列一致性 → 去符号验证**

最重要的原则：

> **IP 不是“你画了什么”，而是“这些东西为什么只能属于这个世界”。**
